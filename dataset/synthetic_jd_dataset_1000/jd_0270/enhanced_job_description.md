## Job Title
Senior Cybersecurity Analyst

## Location
Paris, France

## Client Industry
FMCG

## Detailed Responsibilities
- Monitor security events and alerts using SIEM tools and respond to incidents.
- Conduct vulnerability assessments and penetration testing on systems and applications.
- Investigate security breaches and coordinate incident response activities.
- Implement and maintain security controls across network and cloud environments.
- Perform risk assessments and develop mitigation strategies.
- Develop and deliver security awareness training for employees.
- Ensure compliance with security standards including ISO 27001 and NIST.
- Collaborate with IT teams to embed security-by-design principles.

## Skill Requirements
**Must Have:**
- SIEM.
- OWASP.
- Incident Response.
- Vulnerability Assessment.
- Network Security.

**Good to Have:**
- Penetration Testing.
- Splunk.
- ISO 27001.
- NIST Framework.
- Cloud Security.

**Educational Qualifications:**
- Bachelor's degree in Computer Science, Information Security, or related field.

**Experience:**
- 4-7 years of relevant professional experience.

## Other Requirements
- CISSP, CEH, or CompTIA Security+ certification preferred.
- Experience with cloud security (AWS Security Hub, Azure Sentinel).
- Familiarity with GDPR and data protection regulations.
