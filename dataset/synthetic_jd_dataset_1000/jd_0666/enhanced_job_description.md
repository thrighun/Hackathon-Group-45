## Job Title
Senior DevOps Engineer

## Location
Pune, India

## Client Industry
Construction

## Detailed Responsibilities
- Design and maintain scalable, secure cloud infrastructure on AWS/GCP/Azure.
- Build and manage CI/CD pipelines for automated testing and deployment.
- Implement infrastructure as code using Terraform and Ansible.
- Monitor system performance and reliability using Prometheus, Grafana, and alerting tools.
- Collaborate with development teams to improve deployment frequency and reduce lead time.
- Manage containerised workloads using Docker and Kubernetes.
- Ensure security best practices are embedded into all infrastructure components.
- Conduct capacity planning and cost optimisation across cloud environments.

## Skill Requirements
**Must Have:**
- Kubernetes.
- Terraform.
- CI/CD.
- Docker.
- AWS/GCP/Azure.

**Good to Have:**
- Helm.
- Python scripting.
- Ansible.
- Grafana.
- Prometheus.

**Educational Qualifications:**
- Bachelor's degree in Computer Science, Engineering, or related field.

**Experience:**
- 4-7 years of relevant professional experience.

## Other Requirements
- AWS/GCP/Azure certifications preferred.
- Experience with service mesh (Istio, Linkerd) is a plus.
- Familiarity with GitOps workflows.
