- Develop and maintain scalable web applications using Java for back-end services and Angular for front-end features.
- Collaborate with UX/UI designers to translate designs into functional applications and enhance user experience.
- Lead code reviews, provide mentoring to junior developers, and ensure best practices in coding and design.
- Implement unit and integration tests to ensure high-quality software delivery.
- Work closely with DevOps teams to automate deployment processes and improve CI/CD pipelines.
- Integrate external APIs and services to expand application functionality.
- Analyze and optimize application performance, ensuring high responsiveness and availability across multiple platforms.
- Stay abreast of industry trends and advancements in technology to drive continuous improvement in software development practices.

- Bachelor's degree in Computer Science or a related field.
- 5+ years of experience in software development with a strong focus on Java and Angular.
