## Job Title
Lead API Engineer (Django/REST)

## Location
Remote or Hybrid Options Available

## Client Industry
Information Technology / Software Development

## Detailed Responsibilities
- Design and implement scalable backend architectures utilizing Django to build secure and efficient RESTful APIs for diverse application needs.
- Collaborate with product managers and frontend teams to define API specifications and create comprehensive documentation for integration purposes.
- Optimize database design and manage MySQL schemas to ensure fast access times and maintain data integrity.
- Conduct performance tuning and load testing on backend services to validate reliability under various scenarios.
- Mentor junior developers on best coding practices, code review processes, and contribute to fostering a collaborative team environment.
- Ensure adherence to security protocols and standards across all backend solutions and API interactions.
- Stay current with industry trends and lead the integration of new technologies to enhance development efficiency and system capabilities.

## Skill Requirements
- Bachelor’s degree in Software Engineering, Computer Science, or a related technical discipline.
- Minimum of 6 years of experience in backend development with a strong focus on Django framework.
- Extensive knowledge of RESTful API development and microservices design principles.
- Proficient in MySQL database management and optimization strategies.
- Experience with software versioning tools (e.g., Git) and agile project management frameworks.
- Strong analytical skills, attention to detail, and a passion for problem-solving.
- Excellent communication skills and a proven ability to work within team-oriented environments.

## Other Requirements
- Familiarity with DevOps practices and CI/CD pipeline tools.
- Experience with cloud service providers (AWS, Azure, or GCP).
- Understanding of container orchestration tools like Docker or Kubernetes is a plus.
- Contributions to open-source projects or community-driven initiatives are highly valued.
- Previous experience in Agile/Scrum methodologies is preferred.
