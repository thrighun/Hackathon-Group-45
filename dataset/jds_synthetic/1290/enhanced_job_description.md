- Design and develop scalable full-stack applications using JavaScript, Node.js, and Python.
- Implement high-performance back-end services to support front-end applications and user interactions.
- Collaborate with UI/UX designers to ensure seamless integration of visual elements with server-side logic.
- Conduct thorough code reviews and ensure adherence to best coding practices, improving overall code quality.
- Identify and resolve performance bottlenecks and security vulnerabilities throughout the application stack.
- Actively engage in agile development processes, including sprint planning, daily stand-ups, and backlog grooming.
- Document development processes, code changes, and system architecture for future reference and onboarding.
