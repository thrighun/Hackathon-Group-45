## Job Title
Frontend Web Engineer - Angular & TypeScript Specialist

## Location
Remote

## Client Industry
Multinational Technology Provider

## Detailed Responsibilities
- Design and develop scalable web applications using Angular and TypeScript to enhance user experience.
- Collaborate with UX/UI designers to create intuitive and attractive user interfaces.
- Participate in architectural discussions to ensure optimal performance and security of applications.
- Write clean, maintainable, and efficient code while adhering to coding standards.
- Implement unit and end-to-end testing to ensure high-quality deliverables.
- Conduct regular performance tuning and optimization for existing web applications.
- Mentor junior developers and conduct knowledge-sharing sessions within the team.

## Skill Requirements
- 3-6 years of experience in frontend development, specifically with Angular and TypeScript.
- Strong knowledge of JavaScript, HTML5, and CSS3, including pre-processors like SASS or LESS.
- Familiarity with RESTful services and asynchronous programming.
- Experience with Agile methodologies and participating in Scrum processes.
- Proficient in version control systems such as Git and managing collaborative environments.
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- Excellent analytical and problem-solving skills with a focus on user-centric design.

## Other Requirements
- Knowledge of Progressive Web Apps (PWAs) and mobile-first design principles.
- Familiarity with cloud services like AWS or Azure for deploying applications.
- Experience with state management libraries like NgRx or Redux.
- Strong verbal and written communication skills to effectively collaborate with teams.
