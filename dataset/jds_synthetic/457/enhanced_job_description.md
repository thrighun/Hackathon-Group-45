## Detailed Responsibilities
- Design and implement robust testing strategies, including comprehensive test plans and scenarios to cover various software projects.
- Lead black box and gray box testing efforts to validate software functionality against business requirements.
- Collaborate with project stakeholders to gather and analyze user requirements, translating them into actionable testing criteria.
- Conduct performance testing using tools such as LoadRunner or JMeter to ensure application scalability and reliability.
- Oversee web application testing, including mobile app testing, ensuring compatibility and responsiveness across devices and browsers.
- Implement and manage continuous integration and delivery processes within a DevOps environment, facilitating seamless software releases.
- Work closely with development teams to foster a quality-driven culture, providing feedback and suggestions for product improvements.

## Skill Requirements
- 7+ years of experience in quality assurance and software testing, with a focus on eCommerce applications.
- Proficient in performance testing tools such as LoadRunner, JMeter, or similar.
- Strong knowledge of web technologies including HTML, CSS, JavaScript, and RESTful APIs.
- Familiarity with Agile methodologies (Scrum, Kanban) and their application in testing processes.
- Excellent analytical skills with the ability to translate business requirements into technical testing specifications.
- Strong communication and collaboration skills to work effectively with cross-functional teams.

## Other Requirements
- Experience with mobile application testing is a plus.
- Knowledge of software quality metrics and best practices in QA processes is beneficial.
- Understanding of automation testing tools and frameworks is desirable but not mandatory.
