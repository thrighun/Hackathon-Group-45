## Job Title

## Location
N/A

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Lead the design and implementation of cloud-native applications using .NET technologies to enhance scalability and performance.
- Work closely with business stakeholders to gather requirements and translate them into technical specifications for development.
- Architect serverless solutions for various use cases, optimizing for cost and efficiency.
- Collaborate with DevOps teams to establish and maintain CI/CD pipelines for smooth software delivery.
- Conduct code reviews, establish best practices, and ensure adherence to coding standards across the team.
- Provide mentorship and technical guidance to junior developers, fostering a culture of learning and development.
- Analyze system performance and resolve any bottlenecks to ensure optimal user experience.
- Document system architecture, processes, and any changes to the software ecosystem for future reference.

- Proven experience in developing cloud-native applications, particularly using Azure or AWS.
- Strong understanding of serverless architecture and related services (e.g., AWS Lambda, Azure Functions).
- Excellent skills in C#, ASP.NET, and web API development.
- Experience with Agile software development methodologies and leading agile teams.
- Familiar with version control systems like Git and CI/CD tools.
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- Strong analytical and problem-solving abilities.
- Excellent communication skills and ability to work collaboratively within a team.

## Other Requirements
