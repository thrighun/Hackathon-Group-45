## Job Title
Data Scientist – Machine Learning & Data Analysis

## Location
N/A

## Client Industry
Information Technology (Multinational Technology Provider)

## Detailed Responsibilities
- Develop and implement machine learning models to extract insights from large data sets and enhance business decision-making.
- Collaborate with data engineers and software developers to ensure seamless integration of models into existing applications.
- Conduct comprehensive data analysis to identify patterns and trends, providing actionable recommendations based on findings.
- Design and execute experiments to validate model performance and improve prediction accuracy.
- Create compelling data visualizations and reports to communicate insights to stakeholders.
- Stay updated on emerging trends and technologies in machine learning, data science, and data engineering.
- Participate in peer code reviews and mentoring sessions to foster knowledge sharing within the team.

## Skill Requirements
- Bachelor’s or Master’s degree in Data Science, Computer Science, Statistics, or a related field.
- Proven experience (2+ years) in data analysis and machine learning, with proficiency in programming languages such as Python or R.
- Hands-on experience with machine learning libraries such as Scikit-learn, Keras, or TensorFlow.
- Strong understanding of statistical methods and data analysis techniques, including regression, classification, and clustering.
- Excellent problem-solving skills and the ability to work effectively in a collaborative, team-oriented environment.
- Strong communication skills, with the ability to present complex data insights in a clear and concise manner.

## Other Requirements
- Familiarity with data visualization tools such as Tableau, Power BI, or similar.
- Experience with big data technologies (Hadoop, Spark) and cloud platforms (AWS, Azure).
- Knowledge of database management systems (SQL, NoSQL) for data retrieval and manipulation.
- Relevant industry certifications in Data Science, Machine Learning, or Statistical Analysis.
