## Job Title
QA Automation Specialist

## Location
N/A

## Client Industry
Technology

## Detailed Responsibilities
- Design, develop, and execute automated test scripts for backend systems and APIs using Java and frameworks such as RestAssured and Postman.
- Collaborate with developers and product managers to define test requirements and ensure comprehensive test coverage for all features.
- Integrate automated testing within CI/CD pipelines utilizing tools like Jenkins to enhance deployment efficiency.
- Document and analyze test results, providing clear reporting on quality metrics and defect trends to stakeholders.
- Identify and troubleshoot issues within the automation framework and collaborate with development teams for resolution.
- Actively participate in Agile ceremonies, contributing to sprint planning and reviews to align testing efforts with development cycles.
- Stay updated on industry best practices and emerging tools to continuously improve the automation testing processes.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- Proven experience with Java programming and API testing using automation tools like Postman and RestAssured.
- Proficiency in using test management tools such as JIRA and TestRail for tracking and managing test cases and defects.
- Strong understanding of software testing methodologies, including functional, performance, and regression testing.
- Excellent communication skills and ability to work collaboratively in a fast-paced team environment.
- Familiarity with CI/CD practices and tools, such as Jenkins or GitLab CI.

## Other Requirements
- Industry certifications in software testing (e.g., ISTQB, Certified Selenium Tester) are advantageous.
- Experience with containerization technologies like Docker and orchestration tools such as Kubernetes is a plus.
- Exposure to performance testing tools like JMeter or LoadRunner.
- Understanding of secure coding practices and security testing principles.
