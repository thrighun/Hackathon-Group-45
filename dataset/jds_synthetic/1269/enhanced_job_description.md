## Job Title
Full Stack Developer with Angular and Node.js

## Location
N/A

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Design, build, and maintain robust and scalable web applications utilizing Angular for the front-end and Node.js for the back-end.
- Work collaboratively with cross-functional teams including designers, business analysts, and other developers to translate client requirements into technical solutions.
- Write high-quality, clean code and perform thorough testing to ensure application functionality and performance.
- Implement security and data protection measures to safeguard applications and user data.
- Participate in code reviews to enhance code quality and foster knowledge sharing within the team.
- Debug and resolve bugs and performance issues across all platforms.
- Remain informed on emerging technologies and industry trends that can enhance application development.
- Prepare technical documentation and user manuals for applications developed.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- 3+ years of experience in full stack development with a strong focus on Angular and Node.js.
- Proficiency in TypeScript, JavaScript (ES6+), HTML5, and CSS3.
- Experience with database management systems, both SQL (e.g., MySQL, PostgreSQL) and NoSQL (e.g., MongoDB).
- Familiarity with RESTful API integration and experience in designing API architectures.
- Knowledgeable about version control systems, mainly Git, and deployment workflows.
- Understanding of responsive design, mobile-first development, and cross-browser compatibility.
- Strong analytical skills and a detail-oriented mindset, with an emphasis on teamwork and collaboration.
- Effective written and verbal communication skills for interacting with team members and stakeholders.

## Other Requirements
- Experience with Docker, Kubernetes, or other containerization technologies.
- Familiarity with cloud services such as AWS, Azure, or Google Cloud Platform for application deployment.
- Understanding of Agile methodologies, with a preference for experience in Scrum teams.
- Exposure to automated testing tools and CI/CD processes to ensure streamlined deployment.
- Involvement in open-source projects or personal coding projects that highlight full stack capabilities.
