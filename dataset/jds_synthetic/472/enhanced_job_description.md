## Job Title
Mobile App Developer (React Native)

## Location
Remote/Flexible

## Client Industry
Information Technology / Mobile App Development

## Detailed Responsibilities
- Design, develop, and maintain cross-platform mobile applications using React Native and JavaScript.
- Collaborate with UX/UI designers to create intuitive and engaging user interfaces that enhance user experience.
- Integrate with backend services and RESTful APIs to deliver a seamless user experience.
- Participate in all stages of the software development lifecycle, including planning, coding, testing, and deployment.
- Conduct code reviews and provide mentorship to junior developers, ensuring adherence to coding standards.
- Troubleshoot and debug applications to optimize performance and stability.
- Stay informed on the latest trends in mobile development and emerging technologies in the React Native ecosystem.
- Document development processes, code changes, and technical specifications for future reference.
- Actively contribute to agile ceremonies including sprint planning, retrospectives, and daily stand-ups.

## Skill Requirements
- Strong proficiency in React Native and JavaScript for mobile application development.
- Experience with mobile interface design principles and best practices.
- Familiarity with backend technologies, preferably Python or Node.js.
- Understanding of agile methodologies and experience working in cross-functional teams.
- Knowledge of state management libraries like Redux or Context API.
- Bachelor’s degree in Computer Science, Software Engineering, or a related field (or equivalent experience).
- Minimum 3 years of experience with mobile app development in a collaborative environment.
- Excellent analytical and problem-solving skills with a keen attention to detail.
- Strong interpersonal and communication skills to work effectively within a team.

## Other Requirements
- Experience with version control systems like Git and CI/CD practices.
- Knowledge of testing frameworks and processes for mobile applications.
- Previous published projects on the Apple App Store or Google Play Store are preferred.
- Familiarity with cloud services and mobile data storage solutions.
- Understanding of security best practices in mobile application development.
