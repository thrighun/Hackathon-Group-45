## Job Title
Full Stack Developer (Node.js & Tailwind CSS)

## Location
N/A

## Client Industry
Retail

## Detailed Responsibilities
- Design, develop, and deploy full-stack web applications using Node.js for backend and Tailwind CSS for front-end development.
- Collaborate with cross-functional teams including UX/UI designers, product managers, and other stakeholders to ensure user requirements are met effectively.
- Create and maintain RESTful APIs to facilitate seamless data exchange between front-end and back-end systems.
- Implement responsive web designs and ensure high performance across different devices and browsers.
- Conduct thorough testing and debugging of applications to deliver high-quality software solutions.
- Participate in daily stand-ups and sprint planning sessions as part of the Agile development methodology.
- Monitor application health, identify performance bottlenecks, and implement solutions to optimize application efficiency.
- Contribute to technical documentation and assist in mentoring junior developers in best coding practices.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- 3+ years of experience in full stack web development with a focus on Node.js and JavaScript frameworks.
- Proficiency in Tailwind CSS for crafting responsive layouts and user interfaces.
- In-depth knowledge of HTML5, CSS3, and modern JavaScript (ES6+).
- Familiarity with database technologies such as MongoDB or SQL for data management.
- Experience with Git for version control and collaboration in a team environment.
- Strong analytical and problem-solving skills with a keen attention to detail.
- Excellent communication skills to coordinate effectively within a development team.

## Other Requirements
- Knowledge of cloud platforms (AWS, Azure) for deployment and scalability solutions.
- Understanding of microservices architecture and containerization (Docker).
- Familiarity with testing frameworks such as Mocha or Jasmine for unit and integration testing.
- Exposure to user analytics tools to track application usage and enhance user experience.
- Previous work experience in the retail or e-commerce sector is highly desirable.
