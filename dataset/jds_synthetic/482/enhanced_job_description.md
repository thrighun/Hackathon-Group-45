## Job Title
Senior Software Engineer - Java Microservices Developer

## Location
Remote

## Client Industry
Information Technology / Technology Services

## Detailed Responsibilities
- Architect, design, and implement scalable microservices using Java and Spring Cloud to support enterprise-level applications.
- Collaborate closely with product owners, UI/UX designers, and cross-functional teams to define application features and functionality.
- Develop robust APIs and services that facilitate seamless integration with front-end applications and external systems.
- Optimize existing microservices for performance, reliability, and security, while ensuring smooth deployments in cloud environments.
- Lead code reviews and mentor junior developers in best practices for coding, testing, and deployment processes.
- Utilize container orchestration tools to manage microservice deployments and enhance application scalability.
- Monitor application performance and troubleshoot issues to maintain high reliability in production systems.
- Stay abreast of industry trends and emerging technologies, proactively suggesting paths for innovation within the development team.
- Ensure adherence to security standards and industry best practices in all development activities.

## Skill Requirements
- At least 6 years of professional experience in Java application development, specifically with microservices architecture.
- Strong expertise in Java, Spring Boot, and building RESTful services.
- Experience with cloud infrastructure (e.g., AWS, Azure) and deploying applications within cloud environments.
- Proficiency in containerization technologies, particularly Docker and Kubernetes, for application deployment.
- Familiarity with front-end frameworks (e.g., React, Angular) and understanding of full-stack development concepts is a plus.
- Solid understanding of CI/CD practices and tools (e.g., Jenkins, GitLab CI).
- Bachelor’s degree in Computer Science, Engineering, or a related discipline.
- Excellent analytical, problem-solving, and interpersonal communication skills.

## Other Requirements
- Experience with API management tools and service meshes for microservices communication.
- Knowledge of infrastructure as code (IaC) tools such as Terraform or CloudFormation is desirable.
- Relevant certifications in Java, cloud technologies, or microservices architecture will be considered an advantage.
- Prior experience in agile environments and working with automated testing frameworks is beneficial.
