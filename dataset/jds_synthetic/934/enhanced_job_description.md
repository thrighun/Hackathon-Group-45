## Job Title
Senior Frontend Engineer (Vue.js)

## Location
Remote/On-site options available

## Client Industry
Technology

## Detailed Responsibilities
- Architect and implement responsive web applications using Vue.js that offer exceptional user experiences on mobile devices.
- Collaborate closely with UX/UI designers and backend developers to translate design wireframes into high-quality code.
- Conduct performance tuning and optimization to improve application speed and efficiency on various devices.
- Write robust, maintainable code and document features for internal and external use.
- Participate actively in code reviews and foster a culture of knowledge sharing within the team.
- Identify and resolve frontend-related issues, ensuring high performance and responsiveness of applications.
- Research and integrate cutting-edge technologies to continuously enhance the frontend stack.

## Skill Requirements
- Bachelor's degree in Software Engineering, Computer Science, or a related field.
- Minimum 5 years of experience working with Vue.js and modern JavaScript frameworks.
- Strong understanding of Vue.js and its ecosystem (Vue Router, Vuex).
- Experience with mobile-first design principles and responsive design.
- Proficient in JavaScript, including ES6+ syntax and features.
- Knowledge of API integration and asynchronous request handling.
- Familiarity with frontend build tools like Grunt, Gulp, or Webpack.
- Excellent problem-solving abilities and attention to detail.
- Strong communication and collaboration skills within a team environment.

## Other Requirements
- Experience with TypeScript and its use in Vue.js applications.
- Knowledge of Progressive Web Apps (PWAs) best practices.
- Familiarity with testing libraries such as Cypress or Jasmine.
- Understanding of Agile and DevOps methodologies for efficient development workflows.
