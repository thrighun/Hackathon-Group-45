- Design and implement user interfaces using Angular for web applications.
- Collaborate closely with UX/UI designers and back-end engineers to create seamless and functional products.
- Develop reusable components and libraries for efficient and consistent development.
- Ensure applications are optimized for maximum speed and scalability across different devices.
- Conduct code reviews and provide constructive feedback to maintain high standards of code quality.
- Participate in agile development processes, including sprint planning and daily stand-ups.
- Maintain up-to-date knowledge of industry trends and emerging technologies to drive innovation.

- Familiarity with front-end build tools such as Angular CLI, Webpack, and npm.
- Knowledge of HTML5 and CSS3, including pre-processing platforms like SASS or LESS.
- Understanding of RESTful services and APIs for back-end integration.
- Ability to troubleshoot and resolve issues across the full stack of web applications.
- Excellent understanding of responsive design principles.
- Bachelor’s degree in Computer Science, Software Engineering, or a related field preferred.
- Minimum of 3 years experience in front-end application development.

- Strong analytical skills and attention to detail.
