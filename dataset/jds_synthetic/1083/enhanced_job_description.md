## Job Title
Node.js Backend Developer

## Location
N/A

## Client Industry
Technology

## Detailed Responsibilities
- Design, implement, and optimize scalable backend services using Node.js and the Express framework.
- Develop and maintain RESTful APIs to facilitate data exchange between client-side applications and backend services.
- Collaborate closely with product designers, front-end developers, and data engineers to create cohesive application architectures.
- Conduct code reviews and provide constructive feedback to ensure code quality and adherence to coding standards.
- Identify and resolve performance bottlenecks and troubleshoot production issues in a timely manner.
- Document technical specifications and system designs to support team alignment and future development.
- Ensure compliance with security protocols and data privacy regulations.
- Participate in the deployment and monitoring of applications in both cloud and on-premise environments.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related discipline.
- 3-5 years of experience in backend development using Node.js.
- Proficiency in the Express framework for building RESTful APIs.
- Solid understanding of asynchronous programming and design patterns.
- Familiarity with Git or other version control systems.
- Experience working with both SQL and NoSQL databases.
- Strong problem-solving skills and ability to thrive in a collaborative environment.

## Other Requirements
- Experience with container orchestration tools like Docker and Kubernetes.
- Knowledge of cloud services such as AWS, Azure, or Google Cloud Platform.
- Familiarity with CI/CD practices and tools for continuous integration and deployment.
- Understanding of testing frameworks and methodologies, such as Mocha or Jest, is a plus.
- Relevant certifications in Node.js or backend development are advantageous.
