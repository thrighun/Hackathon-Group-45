## Detailed Responsibilities
- Design, build, and maintain scalable data pipelines to facilitate the extraction, transformation, and loading (ETL) of complex datasets from various sources.
- Implement data warehousing solutions to ensure efficient storage and retrieval of structured and unstructured data.
- Collaborate with data analysts and data scientists to meet data needs and ensure data quality across all projects.
- Optimize data processing frameworks for performance, scalability, and resource management in cloud environments.
- Monitor and troubleshoot data pipeline performance, ensuring high availability and minimizing downtime.
- Document data architecture, data flow diagrams, and best practices for data management and governance.
- Stay abreast of emerging technologies in big data and cloud computing, evaluating their potential application within the organization.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Information Technology, or a related field.
- Proven experience in developing and managing data pipelines and data warehousing solutions.
- Strong programming skills in languages such as Python, Java, or Scala and experience with big data frameworks like Apache Spark or Hadoop.
- Proficiency in using ETL tools (e.g., Talend, Apache Nifi, or Informatica) for effective data integration.
- Familiarity with cloud data warehousing solutions, such as AWS Redshift, Google BigQuery, or Snowflake.
- Solid understanding of SQL and NoSQL databases, data modeling, and data governance practices.
- Excellent analytical and problem-solving skills, with a strong attention to detail.
- Strong communication skills and the ability to work effectively in cross-functional teams.

## Other Requirements
- Experience with orchestration tools such as Apache Airflow or Prefect for managing data workflows.
- Knowledge of data security and compliance standards relevant to data handling and storage.
- Experience in real-time data processing and streaming technologies (e.g., Apache Kafka) is a plus.
- Contributions to open-source data engineering projects or relevant technical publications.
