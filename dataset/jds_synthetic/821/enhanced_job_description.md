## Job Title
Data Engineer – Cloud Computing & Big Data Processing

## Location
Remote

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Design, implement, and maintain scalable data pipelines to process large volumes of data using cloud-based technologies.
- Collaborate with data scientists and analysts to ensure data availability and reliability for analytics and reporting.
- Optimize data architecture and warehouse solutions for performance and storage efficiency.
- Develop ETL (Extract, Transform, Load) processes to integrate disparate data sources into cohesive datasets.
- Monitor data processes and troubleshoot any issues to maintain data integrity and quality.
- Create and maintain documentation for data models, processes, and systems architecture.
- Engage in code reviews and provide mentorship to junior team members on best data engineering practices.
- Stay updated on industry trends in data engineering and cloud services to leverage new technologies effectively.

## Skill Requirements
- Strong proficiency in Python or Scala for data manipulation and processing.
- Solid understanding of cloud platforms (AWS, Azure, or Google Cloud), particularly in data services like Redshift, BigQuery, or Data Lakes.
- Experience with big data technologies such as Apache Hadoop, Spark, or Kafka for batch and stream processing.
- Knowledge of database technologies (both SQL and NoSQL) and data warehousing concepts.
- Familiarity with data modeling techniques and tools.
- Excellent problem-solving skills with a focus on performance tuning and optimization.

## Other Requirements
- Experience with data governance and security best practices is a plus.
- Knowledge of containerization technologies like Docker or Kubernetes is highly desirable.
- Familiarity with CI/CD practices for data pipeline deployments is an advantage.
- Previous experience in a fast-paced, agile work environment is preferred.
- A degree in Computer Science, Data Science, or a related field is required.
