## Job Title
Frontend Engineer (Vue.js & Bootstrap CSS)

## Location
Remote

## Client Industry
E-commerce (Global Online Retailer)

## Detailed Responsibilities
- Design, develop, and maintain user-friendly web applications using Vue.js and Bootstrap CSS to enhance the e-commerce experience.
- Collaborate with product owners, designers, and backend developers to develop features that meet business needs and improve customer engagement.
- Optimize website performance by implementing best practices for speed, scalability, and SEO.
- Create and manage component libraries to ensure consistency and reusability across various applications.
- Conduct thorough testing and debugging of applications to ensure high-quality code and flawless user experiences.
- Engage in code reviews and provide constructive feedback to peers to foster a collaborative development environment.
- Remain informed about the latest trends in web development, suggesting innovative solutions to enhance functionality and user satisfaction.

## Skill Requirements
- Bachelor’s degree in a related field such as Computer Science, Software Engineering, or similar disciplines.
- Minimum 2 years of experience in front-end development using Vue.js.
- Strong skills in Bootstrap CSS and familiarity with responsive design frameworks.
- Proficient in HTML5, CSS3, and JavaScript (ES6+).
- Experience with RESTful APIs and version control systems such as Git.
- Understanding of modern development practices like Agile methodologies.
- Excellent communication and collaboration skills to work effectively in a team environment.

## Other Requirements
- Knowledge of TypeScript, Vuex, or similar state management libraries is a plus.
- Familiarity with CI/CD tools, testing frameworks, or cloud services such as AWS or GCP would be advantageous.
- Experience in the e-commerce sector or with large-scale web applications is preferred.
- Relevant certifications in front-end technologies or software engineering principles are a bonus.
