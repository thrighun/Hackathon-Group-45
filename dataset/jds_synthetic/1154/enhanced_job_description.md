## Detailed Responsibilities
- Design and implement rich client applications using Java and the Eclipse RCP (Rich Client Platform).
- Collaborate with product managers and UX designers to translate user requirements into functional specifications.
- Develop and maintain high-quality, scalable, and secure code for desktop applications.

- Proficient in Eclipse RCP and SWT.
- Strong command of the Java programming language with an understanding of object-oriented design principles.

- Bachelor's degree in Computer Science, Software Engineering, or a related discipline.
- Excellent analytical skills with a focus on detail-oriented solutions.
- Strong communication skills and the ability to work effectively in a team environment.

- Experience with cloud integration and RESTful services.
