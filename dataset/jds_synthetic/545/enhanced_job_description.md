## Detailed Responsibilities
- Develop and maintain comprehensive Java applications with a focus on backend and frontend integration.
- Collaborate with cross-functional teams including product managers and designers to gather requirements and design optimal software solutions.
- Design, build, and deploy RESTful APIs and microservices that integrate seamlessly with user interfaces.
- Optimize web applications for performance, scalability, and responsiveness across various devices.
- Participate actively in Agile ceremonies, contributing to sprint planning and retrospectives.
- Conduct thorough code reviews and provide constructive feedback to enhance code quality and maintainability.
- Document software designs, processes, and best practices to facilitate knowledge sharing within the team.
- Lead efforts in deploying applications on cloud platforms, ensuring best practices for cloud architecture are followed.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- Minimum 4 years of experience in Java development, with proficiency in Java frameworks like Spring Boot.
- Strong knowledge of frontend technologies, including HTML5, CSS3, JavaScript, and frameworks such as React or Angular.
- Experience with cloud service providers (AWS, Azure, or Google Cloud) for application deployment.
- Familiarity with containerization and orchestration technologies (Docker and Kubernetes).
- Understanding of relational databases and proficiency with SQL.
- Ability to work independently and as part of a team in a fast-paced, Agile environment.
- Excellent analytical, problem-solving, and debugging skills.

## Other Requirements
- Advanced certifications in cloud technologies or full stack development.
- Experience with CI/CD tools for automated testing and deployment.
- Knowledge of software testing frameworks to ensure code quality and reliability.
- Previous involvement in large-scale software projects within an enterprise environment is a plus.
