## Job Title
Embedded Software Engineer - IoT Systems

## Location
Bangalore or Bengaluru

## Client Industry
Technology

## Detailed Responsibilities
- Develop and implement software solutions for Internet of Things (IoT) devices using C and C++ programming languages.
- Design and optimize firmware for low-power, high-efficiency embedded systems.
- Collaborate with product managers and hardware teams to define system requirements and specifications for new IoT products.
- Conduct thorough testing and validation of software components to ensure reliability and performance in real-world applications.
- Participate in code reviews and provide mentorship to junior developers in best practices for embedded software development.
- Create and maintain comprehensive documentation of software architecture, design, and test cases.
- Engage in troubleshooting and resolving issues reported in deployed IoT solutions to enhance user experience.

## Skill Requirements
- Bachelor's degree in Computer Engineering, Software Engineering, or relevant technical field.
- 3-5 years of experience in embedded software development with a strong emphasis on C and C++.
- Solid knowledge of IoT communication protocols such as MQTT, CoAP, or Bluetooth.
- Experience with low-level programming and understanding of hardware interfaces like SPI, I2C, and UART.
- Familiarity with continuous integration and testing practices within embedded systems.
- Strong analytical skills and ability to work in fast-paced, innovative team environments.
- Excellent communication skills to interact effectively with cross-functional teams.

## Other Requirements
- Experience with cloud platforms like AWS IoT or Azure IoT.
- Knowledge of security practices for IoT systems.
- Familiarity with Agile/Scrum methodologies.
- Relevant certifications in embedded systems or IoT technologies.
