- Collaborate with UX/UI designers to implement intuitive and engaging interfaces.
- Optimize applications for maximum speed, performance, and scalability.
- Maintain and refactor existing applications to improve functionality and user experience.

- Familiarity with responsive design principles and mobile-first development.
- Strong debugging and problem-solving skills with keen attention to detail.
- Ability to thrive in a fast-paced, team-oriented environment.
