## Job Title
Full Stack Java Developer

## Location
N/A

## Client Industry
Software Development

## Detailed Responsibilities
- Design, develop, and deploy full-stack Java applications leveraging microservices architecture.
- Collaborate with product managers and UI/UX designers to define application requirements.
- Implement back-end services using Spring Boot and connect them with front-end frameworks.
- Ensure application responsiveness and optimize performance for both web and mobile platforms.
- Conduct rigorous testing, debugging, and troubleshooting to maintain application quality.
- Participate actively in Agile/Scrum ceremonies, promoting a collaborative work environment.
- Stay abreast of technological advancements and incorporate them into development practices.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- Minimum of 3+ years of experience in full-stack Java development.
- Proficiency in building microservices with Spring Boot and REST APIs.
- Strong knowledge of front-end technologies, including React, Angular, or Vue.js, along with HTML, CSS, and JavaScript.
- Excellent analytical thinking and problem-solving skills.
- Solid experience with version control systems, preferably Git.
- Strong interpersonal skills to work effectively in a team setting.

## Other Requirements
- Familiarity with containerization technologies like Docker and orchestration tools like Kubernetes is a plus.
- Experience with cloud services such as AWS, Google Cloud, or Azure.
- Understanding of database management systems, including SQL and NoSQL databases.
