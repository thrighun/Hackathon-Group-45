## Job Title
Frontend Engineer

## Location
Remote

## Client Industry
Software Development Firm

## Detailed Responsibilities
- Build and maintain dynamic web applications using Vue.js and Bootstrap frameworks.
- Create intuitive and visually appealing user interfaces that enhance user engagement.
- Collaborate with cross-functional teams, including back-end developers and project managers, to define and implement project requirements.
- Ensure the technical feasibility of UI/UX designs and optimize application performance for various devices and browsers.
- Conduct thorough testing and debugging of applications to ensure high-quality deliverables.
- Mentor junior developers and facilitate knowledge transfer sessions within the team.
- Research and integrate new technologies and tools that can improve development workflows and application performance.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- 3-6 years of hands-on experience with Vue.js for frontend development.
- Strong knowledge of HTML5, CSS3, and Bootstrap for responsive design.
- Experience with state management libraries, such as Vuex.
- Familiarity with RESTful APIs and modern web development practices.
- Understanding of security best practices in web applications.
- Strong analytical and problem-solving abilities, with a keen eye for detail.

## Other Requirements
- Experience with testing frameworks like Cypress or Mocha.
- Proficiency in version control systems such as Git and GitHub workflows.
- Experience working within Agile/Scrum methodologies and familiarity with tools like Jira.
