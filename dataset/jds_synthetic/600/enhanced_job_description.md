## Job Title
Frontend Developer (Vue.js)

## Location
N/A

## Client Industry
Technology Provider

## Detailed Responsibilities
- Design and implement user interfaces using Vue.js, creating component-driven applications.
- Collaborate with UX/UI designers to enhance user experience by translating design wireframes into high-quality code.
- Participate in architectural discussions and contribute to improving front-end architecture and modularity.
- Optimize web applications for performance across various devices and browsers.
- Perform thorough testing and debugging to ensure high-quality deliverables.
- Work closely with backend developers to integrate APIs and enhance application functionality.
- Mentor junior developers and promote best coding practices within the team.

## Skill Requirements
- Bachelor's degree in Computer Science, Information Technology, or related field.
- Minimum of 4 years of experience in frontend development, specifically with Vue.js.
- Strong knowledge of modern JavaScript (ES6+), HTML5, and CSS3.
- Experience with state management libraries such as Vuex.
- Familiarity with RESTful APIs and asynchronous programming patterns.
- Proficient using version control systems, particularly Git.
- Strong analytical skills and a keen eye for detail.
- Excellent teamwork and communication skills.

## Other Requirements
- Experience with TypeScript and its integration into Vue applications.
- Understanding of server-side rendering (SSR) and static site generation.
- Familiarity with build tools and task runners like Webpack or Gulp.
- Experience with Agile methodologies and participating in daily stand-ups.
