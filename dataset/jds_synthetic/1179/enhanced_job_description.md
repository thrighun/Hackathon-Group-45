## Detailed Responsibilities
- Design, develop, and implement automated test scripts for web and mobile applications.
- Collaborate with development teams to understand product requirements and translate them into effective automated tests.
- Maintain and update existing automation frameworks and test cases to accommodate new features and functionality.
- Execute automated tests and analyze results to identify any issues or discrepancies.
- Participate in code reviews and contribute to improving the test automation process.
- Engage in performance testing to ensure applications can handle required loads.

## Skill Requirements
- Strong analytical and troubleshooting skills.
- Proficiency in programming languages such as Java, Python, or C#.
- Excellent communication and interpersonal skills.
- Familiarity with Agile methodologies and the software development lifecycle.

## Other Requirements
- Experience with continuous integration and delivery tools such as Jenkins or Bamboo.
- Knowledge of containerization technologies like Docker.
- Understanding of test management tools such as TestRail or JIRA.
