## Detailed Responsibilities
- Develop and manage scalable backend services using Java with a focus on Spring Boot frameworks.
- Collaborate with data scientists to effectively integrate machine learning models into backend systems.
- Design and implement NoSQL database solutions using MongoDB and Redis for efficient data handling.
- Ensure robust security measures and data integrity across all backend operations.
- Work with cross-functional teams to create user-friendly RESTful APIs for frontend integration.
- Troubleshoot and resolve production issues while maintaining performance metrics and service reliability.
- Engage in regular architectural discussions and code reviews to promote best practices in software development.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- Solid experience in backend development using Java and Spring Boot.
- Proficiency in NoSQL databases, especially MongoDB and Redis.
- Familiarity with machine learning model integration and data processing techniques.
- Strong understanding of API design and microservices architecture.
- Ability to work collaboratively in agile teams and communicate effectively with technical and non-technical stakeholders.

## Other Requirements
- Experience with cloud service providers like AWS or Azure for deploying backend applications.
- Familiarity with containerization tools such as Docker and orchestration platforms like Kubernetes.
- Contributions to technical documentation and software development methodologies.
- Knowledge of CI/CD practices and tools to enhance deployment and testing workflows.
- Understanding of front-end technologies to assist in full-stack project collaboration.
