## Job Title
JavaScript Frontend Developer

## Location
Remote

## Client Industry
Information Technology / Software Development Services

## Detailed Responsibilities
- Develop and maintain responsive user interfaces leveraging JavaScript frameworks, primarily React.
- Collaborate with UX/UI designers and backend developers to create seamless, high-performance web applications.
- Implement and manage RESTful APIs and real-time data exchange using Node.js.
- Design and integrate database solutions using MongoDB, ensuring efficient data retrieval and management.
- Deploy applications on AWS and utilize cloud services to enhance scalability and performance.
- Work on the development and integration of machine learning features and chatbot solutions to improve user interaction and functionality.
- Write clear, maintainable, and well-documented code, following best practices and coding standards.
- Participate in agile development practices, including sprint planning, code reviews, and retrospectives.
- Stay abreast of emerging trends in web technologies and proactively suggest enhancements for continuous improvement.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related discipline.
- Minimum of 3 years of experience in frontend development using JavaScript and React.
- Strong knowledge of server-side JavaScript with Node.js and experience with MongoDB.
- Practical experience deploying and scaling applications on AWS cloud platform.
- Familiarity with machine learning concepts and chatbot frameworks.
- Solid understanding of web performance optimization techniques and responsive design principles.
- Excellent problem-solving skills, with attention to detail and a collaborative working style.

## Other Requirements
- Experience with containerization tools such as Docker is a plus.
- Familiarity with CI/CD pipelines and version control systems (e.g., Git).
- Knowledge of additional cloud services (GCP, Azure) is an advantage.
- Strong verbal and written communication skills, with a team-oriented mindset.
