- Lead user acceptance and performance testing initiatives for enterprise-level web applications.
- Develop and implement testing frameworks and automation tools to optimize testing efficiency.
- Collaborate closely with product managers, developers, and UX designers to establish clear test criteria and requirements.
- Analyze testing metrics and provide regular reports to stakeholders, proposing actionable improvements.
- Contribute to the integration of QA processes within CI/CD pipelines for accelerating delivery cycles.

- Extensive experience in both manual and automated testing, with a focus on web applications.
- Proficient in programming languages such as Python and frameworks like Selenium.
- Strong understanding of performance testing, especially with tools like JMeter.

## Other Requirements
- Experience in working within Agile teams in a fast-paced environment.
- Knowledge of cloud services, particularly within the Google Cloud ecosystem.
