## Job Title
Java Microservices Developer

## Location
N/A

## Client Industry
Information Technology / Multinational Technology Solutions Provider

## Detailed Responsibilities
- Design, develop, and optimize microservices-based applications using Java with Spring Boot framework.
- Collaborate effectively with product management and UI/UX teams to create seamless, user-friendly experiences while ensuring robust backend performance.
- Implement and maintain NoSQL databases, focusing primarily on MongoDB, to enhance data retrieval and storage capabilities.
- Deploy and manage applications on Amazon Web Services (AWS), utilizing cloud architecture best practices for scalability and security.
- Work on the integration of artificial intelligence solutions, collaborating with data engineers to ensure smooth data flow and processing.
- Write efficient, reusable, and well-documented code, following best practices and coding standards in the industry.
- Engage in code reviews, unit testing, and performance optimization to ensure high-quality application delivery.
- Stay informed about industry trends and emerging technologies to propose innovative improvements to existing systems.
- Partner with DevOps teams to enhance CI/CD processes and automate deployment pipelines.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Software Engineering, or a related field.
- Proven experience (3+ years) in backend development using Java with Spring Boot.
- Strong proficiency with NoSQL databases, particularly MongoDB.
- Hands-on experience deploying and managing applications on Amazon Web Services (AWS).
- Familiarity with artificial intelligence and machine learning concepts as they pertain to application development.
- Solid grasp of microservices architecture, RESTful APIs, and cloud-native applications.
- Strong analytical skills, attention to detail, and ability to work both independently and within a team.

## Other Requirements
- Experience with container technologies (Docker, Kubernetes) is a plus.
- Understanding of CI/CD best practices and automated testing frameworks.
- Knowledge of additional cloud services (Azure, GCP) or hybrid solutions.
- Strong communication skills and a collaborative, innovative mentality.
