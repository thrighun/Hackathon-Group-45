## Detailed Responsibilities
- Design and implement microservices that support enterprise-level applications, ensuring scalability and maintainability.
- Develop and manage APIs for seamless integration between frontend and backend systems.
- Utilize container orchestration tools (like Kubernetes) to deploy and manage services in a cloud infrastructure.
- Collaborate with architecture teams to create robust service frameworks and guidelines.
- Monitor and optimize service performance through observability tools and metrics analysis.
- Engage in code reviews and implement best practices to enhance code quality and team productivity.
- Troubleshoot complex issues across the application stack, from database queries to user interface interactions.

## Skill Requirements
- Bachelor's or Master's degree in Computer Science, Information Technology, or a related field.
- 6-12 years of experience in software engineering, particularly with microservices and cloud-native solutions.
- Proficiency in backend technologies such as Go, Ruby, or similar programming languages.
- Experience with API management tools and practices.
- Deep understanding of database technologies, both SQL and NoSQL, and their integration with microservices.
- Strong familiarity with containerization technologies (Docker) and orchestration frameworks (Kubernetes, OpenShift).
- Experience deploying applications in cloud environments (AWS, Azure, or Google Cloud).
- Excellent analytical skills with a problem-solving mindset.
- Strong interpersonal and communication skills for effective team collaboration.

## Other Requirements
- Experience with continuous integration and continuous deployment (CI/CD) practices.
- Knowledge of service mesh technologies and distributed tracing tools.
- Familiarity with Agile and DevOps methodologies in software development.
