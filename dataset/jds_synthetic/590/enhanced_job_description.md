## Detailed Responsibilities
- Develop low-level firmware for embedded systems in telecommunications and IoT applications using C and C++.
- Collaborate with hardware engineers to define integration requirements and ensure optimal interoperability between software and hardware components.
- Create detailed documentation for firmware designs, including specifications, architecture, and user manuals.
- Conduct rigorous unit and integration testing to identify bugs and performance bottlenecks, ensuring reliability and security of the firmware.
- Implement real-time data processing algorithms to enhance system efficiency and responsiveness.
- Stay abreast of industry trends and emerging technologies in embedded systems and telecommunications to inform product development.

## Skill Requirements
- Bachelor's degree in Computer Engineering, Software Engineering, or a related technical field.
- 4-6 years of practical experience in embedded systems software development, particularly with C and C++.
- Deep understanding of embedded firmware architecture and design principles.
- Experience with real-time data processing and performance optimization techniques.
- Familiarity with communication protocols used in IoT and telecommunications, such as MQTT, CoAP, or TCP/IP.
- Strong analytical and troubleshooting skills with attention to detail.

## Other Requirements
- Experience using development tools such as IDEs, debuggers, and performance analyzers.
- Knowledge of scripting languages like Python for automation tasks.
- Familiarity with Agile and DevOps methodologies in software development.
- Excellent written and verbal communication skills to effectively collaborate with team members and stakeholders.
