- Design, develop, and maintain web applications using Vue.js, Nuxt.js, and Bootstrap.
- Lead frontend development projects, ensuring that best practices and coding standards are met.
- Collaborate closely with backend teams to implement clean and efficient API integrations.
- Conduct code reviews and provide constructive feedback to improve team performance and code quality.
- Optimize web applications for performance and scalability while ensuring cross-browser compatibility.
- Mentor and support junior developers in their professional growth and technical skills.
- Document processes, technical specifications, and new features as part of the project lifecycle.
- Stay informed about emerging trends in frontend development and introduce new tools and practices to the team.

- Bachelor's degree in Computer Science or a related field, or equivalent practical experience.
- Extensive experience with Vue.js framework and familiarity with Nuxt.js and Bootstrap.

- Proven experience in developing responsive and accessible web applications.
- Knowledge of RESTful services and API integration.
- Familiarity with version control systems, particularly Git.
- Strong attention to detail and effective problem-solving skills.
- Excellent communication and teamwork capabilities.
