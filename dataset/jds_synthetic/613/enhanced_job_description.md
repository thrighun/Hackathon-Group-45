## Job Title
Embedded Software Engineer - IoT Applications

## Location
N/A

## Client Industry
Internet of Things (IoT)

## Detailed Responsibilities
- Design and implement software solutions for IoT devices leveraging Python and C++.
- Collaborate with product managers to gather and define software requirements for IoT applications.
- Develop and optimize communication protocols for efficient data transmission in IoT networks.
- Execute testing and validation processes to ensure functionality and reliability of IoT software.
- Participate in daily stand-ups and collaborative sprint planning within Agile teams.
- Provide technical mentorship and peer reviews to foster a culture of quality in software development.
- Engage with security teams to integrate robust security measures in IoT software.
- Create comprehensive documentation for codebases to facilitate knowledge sharing and compliance.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- 4+ years of experience in software development for IoT applications using Python and C++.
- Strong familiarity with IoT protocols such as MQTT, CoAP, and HTTP.
- Experience with cloud platforms and their integration with IoT devices (e.g., AWS, Azure).
- Proficient in using debugging tools and methodologies specific to embedded and IoT systems.
- Knowledge of continuous integration and continuous deployment (CI/CD) practices.
- Strong analytical and critical thinking skills to resolve complex technical issues.

## Other Requirements
- Familiarity with database technologies like SQL or NoSQL for handling IoT data.
- Understanding of low-power computing and energy-efficient design principles.
- Experience with Agile methodologies and tools like JIRA or Trello.
- Certifications in IoT or related fields are preferred.
