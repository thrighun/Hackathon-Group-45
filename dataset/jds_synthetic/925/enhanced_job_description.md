## Job Title
Frontend Engineer (Vue.js & Bootstrap)

## Location
Remote

## Client Industry
Information Technology / Technology Solutions

## Detailed Responsibilities
- Develop and maintain dynamic web applications using Vue.js and Bootstrap for responsive designs.
- Collaborate with product managers and graphic designers to create user-centric web experiences.
- Optimize web applications for performance, scalability, and cross-browser compatibility.
- Participate in design and code review processes, offering insights and suggestions to enhance code quality.
- Translate mockups and wireframes into high-quality, reusable code in an agile software development environment.
- Research and implement new front-end technologies and methodologies to improve system functionality and user experience.
- Identify and resolve technical issues through debugging and troubleshooting techniques.
- Assist in writing comprehensive documentation for both development processes and user guides.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related discipline, or equivalent practical experience.
- Demonstrated experience with Vue.js, Bootstrap, and modern JavaScript frameworks.
- Proficiency in JavaScript (ES6+), HTML5, CSS3, and familiarity with front-end tooling (Webpack, Babel).
- Understanding of API integration and state management techniques (Vuex).
- Experience using version control systems like Git and familiarity with collaborative workflows.
- Strong analytical and problem-solving abilities, with a keen eye for design and user experience.
- Outstanding verbal and written communication skills to promote collaboration within a team.

## Other Requirements
- Previous experience with TypeScript and testing tools (Cypress, Mocha) is an advantage.
- Knowledge of DevOps practices and experience with containerization (Docker) is a plus.
- Familiarity with Agile methodologies and version control and issue tracking tools (JIRA, Trello).
- Demonstrated portfolio showcasing past work and contributions to personal or open-source projects.
