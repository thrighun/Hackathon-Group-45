## Job Title
Senior Full-Stack JavaScript Developer

## Location
N/A

## Client Industry
Technology

## Detailed Responsibilities
- Design, develop, and maintain web applications using React for the front end and Node.js for the back end.
- Collaborate with UI/UX designers to create dynamic and user-friendly interfaces.
- Optimize application performance and ensure scalability of web solutions.
- Implement server-side business logic and database interactions.
- Conduct code reviews to maintain high coding standards and facilitate team learning.
- Work closely with DevOps teams to manage deployments and monitor application health.
- Create and maintain comprehensive documentation for application architectures and processes.

## Skill Requirements
- Minimum of 6+ years of experience in full-stack web development.
- Proficiency in React and Node.js, as well as familiarity with Express.js framework.
- Strong understanding of RESTful APIs, GraphQL, and web services.
- Experience with database technologies such as MongoDB or PostgreSQL.
- Knowledge of version control systems like Git and continuous integration/continuous deployment (CI/CD) practices.
- Bachelor’s degree in Computer Science, Software Engineering, or a related discipline.
- Exceptional analytical and problem-solving skills.

## Other Requirements
- Familiarity with cloud platforms (e.g., AWS, Azure) for application deployment.
- Experience with unit testing and test-driven development (TDD).
- Knowledge of Agile methodologies and proficiency in using project management tools like Jira or Trello.
