## Detailed Responsibilities
- Architect, develop, and optimize Progressive Web Applications (PWAs) using React.
- Work closely with UI/UX designers to implement engaging and responsive user interfaces.
- Collaborate with backend developers to integrate APIs and enhance application functionality.
- Conduct performance testing and optimization to ensure high-quality user experiences.
- Troubleshoot and debug applications to improve overall performance and user satisfaction.
- Maintain comprehensive documentation and participate in project planning sessions.
- Keep abreast of the latest innovations in web technologies and frameworks to continually enhance development practices.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Software Engineering, or a related discipline.
- 3-6 years of experience in front-end development, primarily with React and PWA technologies.
- Proficiency in JavaScript, HTML5, CSS3, and modern front-end frameworks.
- Familiarity with state management libraries such as Redux or MobX.
- Strong understanding of RESTful services and API integration.
- Excellent analytical skills and a detail-oriented mindset.
- Proven ability to work independently as well as collaboratively within a team.

## Other Requirements
- Experience with Agile/Scrum methodologies and version control systems like Git.
- Knowledge of testing frameworks such as Jest or Mocha.
- Familiarity with continuous integration and continuous deployment practices.
- Strong written and verbal communication skills, with the ability to convey complex concepts to various audiences.
