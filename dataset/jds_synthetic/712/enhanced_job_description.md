## Detailed Responsibilities
- Build and optimize data pipelines for analytics and operational data processing.
- Collaborate with data scientists and analysts to understand data requirements and transform raw data into usable formats.
- Develop and maintain data warehouse solutions for efficient data retrieval and reporting.
- Implement data quality measures and ensure compliance with data governance policies.
- Create automated data integration solutions, including ETL processes.
- Monitor and troubleshoot data pipeline performance and reliability.
- Evaluate and integrate new data management technologies.
- Document data processes and workflows for reference and training purposes.

## Skill Requirements
- Proficiency in programming languages such as Python, Java, or Scala for data processing tasks.
- Extensive experience with ETL tools and data warehousing solutions.
- Familiarity with SQL and NoSQL databases (e.g., PostgreSQL, MongoDB).
- Solid understanding of data modeling and data architecture principles.
- Knowledge of cloud data platforms, such as AWS Redshift or Google BigQuery.

## Other Requirements
- Experience with Big Data technologies such as Hadoop or Spark.
- Familiarity with data visualization tools (e.g., Tableau, Power BI).
- Understanding of data governance and compliance regulations.
- Ability to work collaboratively in cross-functional teams and communicate technical concepts to non-technical stakeholders.
