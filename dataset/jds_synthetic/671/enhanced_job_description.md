- Collaborate with designers and product managers to define project requirements and deliverables.
- Perform thorough testing and debugging to ensure compatibility across multiple devices and browsers.
- Create reusable code libraries and components to enhance development efficiency.
- Participate in code reviews, providing constructive feedback and sharing knowledge with team members.
- Optimize application performance and usability through best coding practices.
- Document development processes, methodologies, and project details for team reference and training.
- Stay current with industry trends and emerging technologies to recommend innovative solutions.

- Bachelor’s degree in Computer Science, Web Development, or a related field.
- 3+ years of front-end development experience with a strong focus on Vue.js.
- Proven expertise with the Vuetify UI framework and its components.
- Solid understanding of HTML5, CSS3, and modern JavaScript (ES6+).
- Familiarity with RESTful APIs and experience integrating front-end solutions with backend services.
- Experience using version control systems, particularly Git.
- Strong knowledge of responsive design principles and mobile-first development.
- Excellent communication skills and a collaborative team mindset.
