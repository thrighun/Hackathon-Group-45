- Develop interactive and visually appealing user interfaces using Vue.js, ensuring they are responsive and user-friendly.
- Collaborate with design and UX teams to translate visual designs into functional code while maintaining aesthetic integrity.
- Integrate third-party APIs and manage data flow effectively between front-end and back-end components.
- Conduct thorough testing and debugging of applications to ensure smooth performance across various devices and browsers.
- Work with the development team to optimize application performance and improve load times.
- Participate actively in daily stand-ups and sprint planning meetings, providing updates on progress and challenges.
- Document code, workflows, and application architecture for future reference and onboarding purposes.

- Bachelor’s degree in Computer Science, Software Engineering, or a related field, or equivalent practical experience.
- 1-2 years of professional experience in developing web applications using Vue.js or similar front-end frameworks.
- Strong understanding of JavaScript (ES6+), HTML5, CSS3, and pre-processing platforms like SASS or LESS.
- Familiarity with state management tools such as Vuex or similar libraries.
- Experience working with RESTful APIs and asynchronous JavaScript programming.
- Basic knowledge of Git for version control and collaborative software development.
- Strong analytical and problem-solving abilities with attention to detail.
- Good communication skills and an eagerness to work in a team-oriented environment.
