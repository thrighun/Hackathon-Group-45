## Job Title
Frontend Developer specializing in Vue.js and Nuxt.js

## Location
Remote

## Client Industry
Multinational Technology Provider

## Detailed Responsibilities
- Design and implement dynamic web applications using Vue.js and Nuxt.js frameworks.
- Work closely with UX/UI designers to create visually appealing and user-friendly interfaces.
- Participate in code reviews and provide constructive feedback to enhance team performance.
- Implement responsive design to ensure seamless experience across various devices.
- Monitor and improve application performance through profiling and optimization techniques.
- Create comprehensive documentation for developed features and maintain code integrity.

## Skill Requirements
- 3-6 years of hands-on experience in web development using Vue.js and Nuxt.js.
- Strong proficiency in JavaScript, HTML5, and CSS3.
- Solid understanding of modern frontend build tools and package managers like Webpack and npm.
- Experience with state management in Vue applications using Vuex.
- Familiarity with Agile methodologies and collaborative development practices.
- A degree in Computer Science, Software Engineering, or a related discipline.

## Other Requirements
- Experience with Progressive Web Apps (PWAs) is highly desirable.
- Knowledge of testing frameworks such as Jest or Cypress is a plus.
- Excellent analytical skills and problem-solving abilities.
- Strong interpersonal skills and the ability to work well in a team-oriented environment.
