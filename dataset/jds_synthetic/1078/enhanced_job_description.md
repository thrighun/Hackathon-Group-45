- Design and implement user-friendly interfaces using React and Chakra UI to foster seamless user experiences.
- Collaborate with product managers and designers to gather requirements and create prototypes that align with user needs.
- Write efficient, reusable, and testable code while adhering to best practices and coding standards.
- Perform performance tuning and optimization of applications to enhance user satisfaction and engagement.
- Ensure compatibility across various devices and browsers through thorough testing and debugging.
- Actively participate in Agile methodologies, including sprint planning, daily stand-ups, and retrospectives.
- Keep abreast of emerging tools and technologies in the front-end development landscape to propose enhancements.

- Bachelor’s degree in Web Development, Computer Science, or a similar field.
- Proven experience in front-end development, particularly with React for building user interfaces.
- Proficiency in Chakra UI or a similar design system for creating responsive layouts.
- Strong understanding of JavaScript (ES6+), HTML5, and CSS3 principles.
- Experience working with RESTful web services and integrating APIs.
- Familiarity with version control systems, specifically Git.
- Excellent problem-solving skills and a focus on detail.
- Strong communication skills, both verbal and written.

## Other Requirements
