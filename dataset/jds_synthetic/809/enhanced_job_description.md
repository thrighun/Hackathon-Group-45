## Detailed Responsibilities
- Design, develop, and maintain automated test scripts for web and mobile applications.
- Collaborate closely with developers to understand application features and identify areas suitable for automation.
- Analyze test results, report on defects, and work with the team to resolve issues promptly.
- Participate in test planning and strategy meetings to align with project goals.
- Execute regression tests and performance tests to validate software functionality.
- Maintain test documentation, including test plans, cases, and scripts.
- Mentor junior testers in automation testing best practices and tools.
- Stay informed about new testing technologies and methodologies to ensure our processes remain cutting-edge.

## Skill Requirements
- Proficient in scripting languages such as Python or Java.
- Familiarity with automation testing tools such as Selenium, Appium, or similar.
- Strong analytical skills and the ability to troubleshoot defects in applications.

## Other Requirements
- Experience with performance testing tools such as JMeter or LoadRunner.
- Knowledge of CI/CD pipelines and tools like Jenkins, Travis CI, or CircleCI.
- Familiarity with cloud platforms such as AWS or Google Cloud.
