## Detailed Responsibilities
- Design, develop, and maintain full-stack web applications using Node.js for backend and Angular for frontend.
- Collaborate with UI/UX teams to ensure responsive and high-performance web interfaces based on user requirements.
- Implement GraphQL APIs to facilitate efficient data retrieval and manipulation between client and server.
- Ensure high code quality through best practices such as code reviews, automated testing, and deployment strategies.
- Optimize applications for maximum speed, accessibility, and scalability while monitoring performance metrics.
- Maintain comprehensive documentation of application architecture and development processes for future reference.

## Skill Requirements
- Strong expertise in JavaScript, with significant experience in Node.js for backend services.
- Proficiency in Angular framework for building user-facing applications.
- Solid understanding of GraphQL, including query optimization and schema design.
- Familiarity with database technologies, particularly MongoDB or similar NoSQL databases.
- Experience with containerization tools such as Docker and CI/CD pipelines.
- Knowledge of agile methodologies and the ability to adapt to shifting priorities in a fast-paced environment.

## Other Requirements
- Experience with cloud services (AWS, Azure) and their deployment strategies is an advantage.
- Previous experience in security best practices related to web application development is a plus.
- Strong communication skills, with an emphasis on teamwork and collaboration within a diverse group of stakeholders.
