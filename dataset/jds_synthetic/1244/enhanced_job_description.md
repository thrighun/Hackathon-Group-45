## Detailed Responsibilities
- Design and implement a microservices architecture that supports scalability and high availability.
- Develop and maintain RESTful APIs for seamless integration with frontend applications and third-party services.
- Build robust web applications using Java and Spring Boot, ensuring best practices in code quality and performance.
- Utilize frontend technologies, including React, to create user-friendly interfaces and enhance user experience.
- Manage AWS cloud infrastructure, leveraging tools such as Terraform for automation and deployment.
- Collaborate with cross-functional teams in an Agile environment to facilitate rapid application development and delivery.
- Apply Object-Oriented Programming principles and design patterns in all code deliverables.
- Monitor and optimize database performance, including Elasticsearch for effective data retrieval and indexing.
- Troubleshoot and debug complex software issues, providing timely resolutions and support.

## Skill Requirements
- Proficiency in Java, Spring Boot, and Python frameworks.
- Extensive experience in designing and building RESTful APIs and microservices.
- Strong knowledge of frontend frameworks including React, JavaScript, TypeScript, CSS3, and HTML5.
- Expertise in managing AWS cloud environments and utilizing IaC tools like Terraform or CloudFormation.
- Familiarity with Agile methodologies and CI/CD practices.
- Solid understanding of Object-Oriented Programming principles and design patterns.
- Experience with both relational and NoSQL databases, particularly Elasticsearch.
- Proven analytical and problem-solving skills with a thorough approach to debugging.

## Other Requirements

- Exposure to containerization technologies (e.g., Docker, Kubernetes).
- Familiarity with other cloud platforms (e.g., Azure, Google Cloud).
