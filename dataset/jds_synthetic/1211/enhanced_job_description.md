## Job Title
Data Engineer

## Location
N/A

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Design and implement scalable data pipelines to facilitate the efficient movement and transformation of data from diverse sources.
- Develop and maintain robust ETL processes to ensure data integrity and accessibility for business intelligence and analytics applications.
- Collaborate with data analysts, data scientists, and software engineers to create and optimize data models that support analytics initiatives.
- Manage and administer data warehousing solutions to provide a centralized repository for structured and unstructured data.
- Implement real-time data processing solutions to support dynamic analytics and reporting requirements.
- Ensure compliance with data governance policies and maintain documentation related to data architecture and processing workflows.
- Stay current with industry trends and emerging technologies in data engineering and leverage them to enhance existing data solutions.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Information Technology, Data Science, or a related field.
- Extensive experience in designing and building data pipelines with tools such as Apache Kafka, Apache Spark, or similar technologies.
- Proficient in programming languages such as Python, Java, or Scala, with a strong understanding of SQL for database management.
- Hands-on experience with cloud data platforms like AWS Redshift, Google BigQuery, or Azure SQL Data Warehouse.
- Strong knowledge of data modeling techniques and best practices for data warehousing.
- Excellent problem-solving skills and an ability to work under tight deadlines in a fast-paced environment.
- Strong collaboration and communication skills to effectively work within cross-functional teams.

## Other Requirements
- Familiarity with containerization and orchestration tools like Docker and Kubernetes for data processing workflows.
- Experience with version control systems, particularly Git, to manage code and collaboration.
- Understanding of data privacy regulations and the implications for data engineering practices.
