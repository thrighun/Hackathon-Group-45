## Job Title
Machine Learning Engineer

## Location
Chicago, IL or Alameda, CA

## Client Industry
Technology

## Detailed Responsibilities
- Design, build, and deploy machine learning models into production environments to solve complex business challenges.
- Collaborate with data scientists and software engineers to integrate advanced analytics into existing applications and systems.
- Optimize model performance and scalability for handling large volumes of data and real-time processing.
- Conduct rigorous testing and validation of machine learning models to ensure accuracy and reliability.
- Monitor model performance post-deployment and iterate based on new data and feedback.
- Participate in code reviews and contribute to best practices for software development within the team.
- Provide technical guidance and mentorship to junior engineers on machine learning technologies and methodologies.

## Skill Requirements
- Bachelor's or Master's degree in Computer Science, Engineering, Machine Learning, or a related field.
- Minimum of 10 years of experience in machine learning engineering or a closely related field.
- Strong programming skills in languages such as Python, Java, or C++ with an emphasis on machine learning libraries (e.g., PyTorch, Keras).
- Solid understanding of algorithms and data structures, particularly in the context of machine learning applications.
- Experience with cloud-based deployment and orchestration tools (e.g., Docker, Kubernetes).
- Excellent problem-solving capabilities and a proactive approach to challenges.
- Strong collaboration and communication abilities to work effectively with cross-functional teams.

## Other Requirements
- Familiarity with big data processing frameworks like Apache Flink or Apache Beam.
- Knowledge of CI/CD pipelines and version control systems (e.g., Git).
- Prior experience in developing machine learning solutions in a product-driven environment.
