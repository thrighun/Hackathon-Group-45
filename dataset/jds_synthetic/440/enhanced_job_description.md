## Job Title
Senior Software Engineer - Java

## Location
Remote Available

## Client Industry
Software Development Company

## Detailed Responsibilities
- Lead the design and development of scalable Java applications with a focus on microservices architecture.
- Collaborate with product managers and UX designers to translate user needs into technical requirements.
- Implement robust APIs and services to enhance application functionality and user experience.
- Optimize existing applications for maximum speed and scalability while ensuring high availability.
- Mentor junior developers and provide guidance on best coding practices and design patterns.
- Conduct thorough testing and debugging of applications and code to ensure reliability and performance.
- Research and implement new technologies and frameworks that could enhance the company's software solutions.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related discipline.
- Minimum of 7 years of professional experience in Java development with a solid understanding of microservices architecture.
- Proficient in frameworks such as Spring Cloud and Hibernate.
- Extensive experience with RESTful APIs and third-party integrations.
- Strong knowledge of database management systems, particularly NoSQL databases.
- Proficiency in version control systems like Git and CI/CD pipelines.
- Excellent analytical and troubleshooting skills coupled with a detail-oriented mindset.
- Strong verbal and written communication skills, with the ability to work effectively in a team environment.

## Other Requirements
- Experience with containerization technologies such as Docker and Kubernetes.
- Familiarity with cloud solutions, specifically Google Cloud Platform or Azure.
- Understanding of Agile methodologies and experience with tools like Jira or Trello.
