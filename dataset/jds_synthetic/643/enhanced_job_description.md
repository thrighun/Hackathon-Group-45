## Detailed Responsibilities
- Develop and maintain robust full stack applications utilizing Java and microservices architecture.
- Collaborate with UX/UI designers to create seamless user interfaces along with backend services.
- Participate in the architecture design of new system features and enhancements.
- Ensure the application meets performance, quality, and responsiveness requirements through rigorous testing.
- Work closely with DevOps teams to facilitate seamless integration, deployment, and monitoring of applications in cloud environments.
- Create and maintain technical documentation, ensuring all code is well-commented and follows best practices.
- Engage in knowledge sharing within the team by mentoring junior developers and conducting training sessions on new technologies.
- Analyze and improve existing systems and technology stacks, advocating for best practices in software development.

- Strong analytical skills with a proactive approach to problem-solving and debugging.
- Proficiency in SQL and NoSQL databases (e.g., MySQL, MongoDB).
- Excellent communication skills, with the ability to articulate technical concepts to non-technical stakeholders.

## Other Requirements

- Familiarity with Agile/Scrum methodologies and a collaborative development environment.
