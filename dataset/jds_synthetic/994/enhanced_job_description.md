## Job Title
Full Stack Developer (React & Node.js)

## Location
N/A

## Client Industry
Information Technology / Technology Solutions

## Detailed Responsibilities
- Design, develop, and maintain full-stack web applications using React.js and Node.js.
- Collaborate with design and product teams to create intuitive, user-centric interfaces and user experiences.
- Implement server-side logic, database interaction, and RESTful APIs to improve application performance and scalability.
- Ensure high-quality responsive web applications that function seamlessly across various devices and browsers.
- Engage in code reviews and contribute to the team’s coding standards and best practices.
- Troubleshoot and debug complex issues in both client-side and server-side code.
- Participate in Agile/Scrum workflows to plan sprints and deliver features iteratively.
- Document system architecture, processes, and project milestones effectively.
- Stay informed on the latest development trends and technologies to drive innovation within the team.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field (or equivalent experience).
- Proven experience in full-stack development with strong skills in React.js and Node.js.
- Solid understanding of JavaScript, HTML5, CSS3, and backend technologies (such as Express or similar frameworks).
- Experience with databases (SQL or NoSQL), including data modeling and optimization techniques.
- Familiarity with API design and development, especially RESTful services.
- Proficient in using version control systems, particularly Git.
- Excellent analytical and problem-solving skills with a keen eye for detail.
- Strong interpersonal and communication skills to facilitate teamwork.

## Other Requirements
- Experience with TypeScript and server-side rendering techniques.
- Understanding of cloud services (AWS, Azure, GCP) and containerization (Docker, Kubernetes).
- Familiarity with unit testing and integration testing tools (Jest, Mocha).
- Knowledge of security best practices in web application development.
- Proven track record of delivering projects in a fast-paced, collaborative environment.
