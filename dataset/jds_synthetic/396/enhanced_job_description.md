## Detailed Responsibilities
- Build and maintain full-stack web applications using Node.js for the backend and Angular for the frontend.
- Collaborate with product managers and UI/UX designers to gather and refine application requirements, ensuring alignment with business goals.
- Develop RESTful APIs and integrate them with front-end applications to create seamless user experiences.
- Implement caching strategies and performance optimizations to enhance application speed and responsiveness.
- Conduct unit testing and code reviews, ensuring code quality and adherence to best practices.
- Engage in Agile development processes, participating in daily stand-ups, sprint planning, and retrospectives.
- Stay abreast of emerging technologies and trends, proactively sharing knowledge and insights with your team.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- Minimum 3 years of experience in full-stack development, with a strong focus on Node.js and Angular.
- Proficiency in JavaScript (ES6+), TypeScript, HTML5, CSS3, and modern front-end frameworks.
- Experience with relational and non-relational databases (e.g., MongoDB, PostgreSQL).
- Familiarity with version control systems (Git) and CI/CD tools.
- Strong analytical and problem-solving skills, with an emphasis on delivering high-quality applications.
- Excellent collaboration and communication skills, with the ability to work effectively in a team environment.

## Other Requirements
- Experience with cloud services (AWS, Azure, or Google Cloud Platform).
- Familiarity with Docker and containerization technologies.
- Knowledge of automated testing frameworks (Mocha, Jasmine) and code quality tools (ESLint, Prettier).
- Previous experience in a fast-paced startup environment is a plus.
