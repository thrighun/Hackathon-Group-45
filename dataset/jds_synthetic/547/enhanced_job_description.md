## Job Title
Senior Software Engineer - Java Microservices

## Location
N/A

## Client Industry
Information Technology

## Detailed Responsibilities
- Architect and implement scalable microservices-based applications using Java.
- Design and develop RESTful APIs to facilitate seamless integration between different services.
- Collaborate with product owners and DevOps teams to ensure smooth application deployment and continuous integration.
- Conduct performance tuning and optimization of applications to improve efficiency and reduce latency.
- Engage in code reviews and provide mentorship to junior developers to foster a collaborative environment.
- Identify and troubleshoot production issues, providing robust solutions in a timely manner.
- Keep abreast of evolving technologies and best practices in software development to drive innovation.

## Skill Requirements
- 5-7 years of experience in software development with a focus on Java.
- In-depth knowledge of microservices architecture and API design principles.
- Familiarity with cloud platforms (AWS, Azure, GCP) is a plus.
- Strong experience with messaging systems such as Kafka or ActiveMQ.
- Proficient in tools and frameworks like Spring Boot and Docker.
- Bachelor’s degree in Computer Science, Software Engineering, or related field.

## Other Requirements
- Experience in Agile development methodologies.
- Knowledge of testing frameworks and CI/CD tools.
- Understanding of security best practices in application development.
