## Job Title
Cloud Solutions Architect

## Location
Remote/On-site

## Client Industry
Global Cloud Services Provider

## Detailed Responsibilities
- Design and implement scalable cloud solutions tailored to meet client needs using various cloud platforms.
- Collaborate with stakeholders to gather requirements and translate them into technical specifications.
- Lead cloud migration projects, ensuring minimal disruption to existing services and workflows.
- Develop and deploy CI/CD pipelines for application deployment in cloud environments.
- Provide ongoing support and optimization for deployed cloud solutions.
- Conduct security assessments and implement best practices for cloud security management.
- Create detailed documentation of cloud architecture and configurations for operational continuity.
- Mentor junior team members and participate in knowledge-sharing sessions.

## Skill Requirements
- At least 5 years of experience in cloud architecture and design.
- Proficiency in cloud platforms such as AWS, Azure, or Google Cloud Platform.
- Strong knowledge of virtualization technologies and container orchestration (e.g., Docker, Kubernetes).
- Experience with configuration management tools (e.g., Terraform, Ansible).
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- Relevant cloud certifications (e.g., AWS Certified Solutions Architect, Azure Solutions Architect Expert) are preferred.
- Excellent analytical skills and attention to detail.
- Strong verbal and written communication skills to articulate complex concepts.

## Other Requirements
- Familiarity with Agile methodologies and DevOps practices.
- Understanding of networking concepts and security protocols in cloud environments.
- Willingness to stay updated on industry trends and emerging cloud technologies.
