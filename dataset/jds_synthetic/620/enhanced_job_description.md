- Design and implement user interfaces for web applications using Vue.js.
- Work in collaboration with UI/UX designers to create responsive layouts that prioritize user experience.
- Develop and maintain a library of reusable components to streamline future projects.
- Optimize all facets of the application for speed and scalability.
- Engage with back-end developers to integrate RESTful APIs and ensure seamless data flow.
- Conduct thorough testing and debugging of applications to maintain high-quality standards.
- Participate in sprint planning and retrospectives to align project goals with team objectives.

- Experience with responsive design and mobile-first layouts.
- Understanding version control with Git and best practices for collaborative coding.
- Familiar with Agile development methodologies and tools like JIRA.
- Strong analytical skills to understand user needs and translate them into functional requirements.
