## Job Title
Mobile Application Developer (React Native)

## Location
N/A

## Client Industry
Information Technology / Mobile Application Development

## Detailed Responsibilities
- Develop and maintain high-quality mobile applications for iOS and Android platforms using React Native and JavaScript.
- Collaborate with cross-functional teams, including UX/UI designers and backend developers, to gather and define application requirements.
- Implement responsive designs and improve user experience utilizing frameworks like Bootstrap where applicable.
- Integrate RESTful APIs to connect mobile applications with backend services and databases.
- Participate in all stages of the Agile development cycle, including sprint planning, daily stand-ups, and retrospectives.
- Write efficient, reusable, and maintainable code while adhering to industry standards and best practices.
- Conduct thorough testing and debugging of applications, ensuring performance and quality across all devices.
- Stay informed about the latest trends, tools, and technologies in mobile development and React Native.
- Contribute to internal knowledge-sharing initiatives to foster a collaborative and innovative team environment.

## Skill Requirements
- Proven experience in developing mobile applications using React Native and JavaScript.
- Strong understanding of mobile application architecture and best practices for performance optimization.
- Familiarity with integrating third-party libraries and APIs for enhanced functionality.
- Experience with version control systems such as Git and continuous integration/deployment processes.
- Knowledge of Agile methodologies and experience working in an Agile team.
- Bachelor’s degree in Computer Science, Software Engineering, or a related field (or equivalent experience).
- Minimum 3 years of experience in mobile development with a focus on user experience.
- Strong analytical skills and attention to detail, with the ability to solve complex problems.

## Other Requirements
- Experience with state management solutions (Redux, MobX, etc.) in React Native.
- Knowledge of testing frameworks and tools for mobile applications.
- Familiarity with deployment processes on the Apple App Store and Google Play Store.
- Understanding of accessibility standards and best practices in mobile design.
- An active portfolio showcasing previous mobile applications developed is preferred.
