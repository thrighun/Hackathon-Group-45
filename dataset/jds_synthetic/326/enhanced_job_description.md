## Detailed Responsibilities
- Develop and maintain automated test scripts for APIs and security testing to ensure software applications are robust and secure.
- Collaborate with development teams to seamlessly integrate automated testing into CI/CD pipelines, enhancing efficiency.
- Conduct performance and security assessments, identifying vulnerabilities and ensuring adherence to security standards.
- Clearly document test processes, results, and defects while providing insights for ongoing improvement efforts.
- Assist with threat modeling and risk assessment to bolster application security measures.
- Design and execute test scenarios based on user stories and acceptance criteria in coordination with cross-functional teams.
- Mentor and guide junior QA engineers on automation and security testing best practices.
- Engage in sprint planning and retrospectives to provide quality-centric insights throughout the Agile development process.

## Skill Requirements
- Bachelor’s degree in Computer Science, Information Technology, or a related discipline.
- Proven experience (3+ years) in test automation, specifically focused on API and security testing.
- Strong knowledge of testing frameworks and automation tools (e.g., Postman, JMeter, Selenium).
- Familiarity with security testing methodologies and tools (e.g., OWASP, Burp Suite).
- Skilled in documenting test cases and results with attention to detail.
- Excellent problem-solving skills coupled with effective communication abilities.
- Experience working in Agile/Scrum environments is essential.

## Other Requirements
- Knowledge of programming languages such as Python, Java, or JavaScript is preferred.
- Understanding of CI/CD tools (e.g., Jenkins, GitLab CI) is advantageous.
- Relevant certifications in security (e.g., CEH, CISM) or automation best practices are a plus.
