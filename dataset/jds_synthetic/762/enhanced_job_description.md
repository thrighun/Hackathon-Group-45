## Detailed Responsibilities
- Design, construct, and maintain scalable data architectures and pipelines using cloud services (AWS, Azure, or Google Cloud).
- Implement ETL processes to gather, process, and store data from various sources, creating a reliable data ecosystem for AI applications.
- Collaborate closely with AI researchers and software developers to ensure data availability and integrity.
- Monitor and troubleshoot data workflow issues, implementing improvements as necessary.
- Develop data quality metrics and ensure compliance with data governance policies.
- Stay abreast of the latest industry trends in data engineering and AI, and implement innovative solutions to enhance data processing capabilities.
- Participate in technical reviews and contribute to team knowledge sharing sessions, promoting best practices in data management.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Data Science, or a related field.
- Proven experience as a Data Engineer or similar role, with a focus on cloud-based data architectures.
- Expertise in SQL and NoSQL databases, as well as data warehousing solutions.
- Experience with data processing frameworks (e.g., Apache Spark, Hadoop) and data pipeline orchestration tools (e.g., Apache Airflow).
- Proficient in programming languages such as Python or Scala for data manipulation and analysis.
- Understanding of machine learning concepts and the data needs for model training.
- Knowledge of containerization technologies (Docker) and version control systems (e.g., Git).

## Other Requirements
- Familiarity with cloud-native data services (e.g., AWS Glue, Azure Data Factory).
- Experience with data visualization tools (e.g., Tableau, Power BI) to present data insights.
- Prior involvement in large-scale data migration projects is a plus.
- Understanding of data privacy regulations (e.g., GDPR, CCPA).
- Experience working in Agile/Scrum environments.
