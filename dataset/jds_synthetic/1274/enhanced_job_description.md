## Detailed Responsibilities
- Design, develop, and maintain high-performance web applications using Node.js for server-side and Angular for client-side development.
- Collaborate with product managers and designers to translate business needs into technical solutions.
- Implement cloud-native applications, utilizing services such as AWS or Azure for hosting and scaling.
- Employ DevOps practices to streamline the development process through CI/CD pipelines, containerization, and orchestration with Docker and Kubernetes.
- Perform code reviews and contribute to team knowledge sharing through documentation and mentorship.
- Continuously monitor and optimize application performance to ensure reliability and responsiveness.

## Skill Requirements
- Proficient in Node.js for backend development and Angular for frontend development.
- Experience with cloud service providers like AWS or Azure, and familiarity with deployment practices.
- Understanding of containerization and orchestration technologies such as Docker and Kubernetes.
- Knowledge of RESTful services and API integration.
- Familiarity with Agile methodologies and collaborative tools (e.g., Jira, Confluence).
- Excellent troubleshooting skills and an adaptive mindset to work in a fast-paced environment.

## Other Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related discipline, or equivalent experience.
- Relevant certifications in Node.js, cloud technologies, or DevOps practices are a plus.
- Proven track record of delivering high-quality software solutions in a collaborative team environment.
