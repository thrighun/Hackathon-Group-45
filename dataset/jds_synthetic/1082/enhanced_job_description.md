## Detailed Responsibilities
- Design cloud architecture that aligns with business needs and objectives.
- Work closely with development teams to ensure seamless integration of applications in the cloud.
- Evaluate and recommend cloud services and technologies to optimize solution delivery.
- Develop strategies for cloud migration and implementation for existing infrastructure.
- Conduct risk assessments and ensure effective disaster recovery plans are in place.
- Collaborate with security teams to establish and enforce best practices for data protection in the cloud.
- Provide mentorship and training to staff on cloud computing practices and tools.

## Skill Requirements
- Extensive experience with public and private cloud platforms (AWS, Azure, Google Cloud).
- In-depth knowledge of cloud-native application development and deployment.
- Proficiency in automation and Infrastructure as Code (IaC) tools like Terraform and Ansible.
- Solid understanding of networking concepts, virtual systems, and API management.
- Strong troubleshooting and optimization capabilities.

## Other Requirements
- Industry certifications such as AWS Certified Cloud Architect or Azure Solutions Architect Expert.
- Experience in implementing cloud security frameworks.
- Knowledge of cloud-based data analytics and machine learning services.
