## Job Title
Embedded Software Engineer - IoT Devices

## Location
N/A

## Client Industry
Internet of Things (IoT)

## Detailed Responsibilities
- Design and implement embedded software solutions for Internet of Things (IoT) devices using C and C++.
- Collaborate with product managers, hardware engineers, and data scientists to define system specifications and functional requirements.
- Conduct performance analysis and optimization of IoT applications for various devices and networks.
- Develop and maintain firmware for microcontrollers and processors, ensuring robust functionality and reliability.
- Engage in the full software development lifecycle, including requirements gathering, design, testing, and deployment.
- Participate in code reviews and mentor junior engineers to promote best coding practices and standards.
- Create technical documentation and user manuals to assist in software usage and understanding.

## Skill Requirements
- Bachelor’s degree in Computer Engineering, Software Engineering, or a related field.
- 3-6 years of professional experience in C and C++ programming for embedded systems.
- In-depth understanding of IoT protocols such as MQTT, CoAP, and HTTP.
- Hands-on experience with hardware interfaces and protocols (SPI, I2C, UART).
- Familiarity with agile development methodologies and version control systems like Git.
- Strong debugging skills and the ability to troubleshoot complex software and hardware interactions.
- Excellent verbal and written communication skills to effectively collaborate with cross-functional teams.

## Other Requirements
- Knowledge of cloud platforms like AWS IoT or Azure IoT.
- Experience with wireless communication technologies (Wi-Fi, Bluetooth, Zigbee).
- Understanding of security practices related to IoT device development.
- Familiarity with automated testing frameworks and continuous integration tools.
