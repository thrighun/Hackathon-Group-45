## Detailed Responsibilities
- Design and implement full stack web applications leveraging Java and React technologies for enhanced user experiences.
- Create and manage RESTful APIs to ensure efficient data exchange between frontend and backend systems.
- Utilize containerization techniques with Docker and manage application deployments with Kubernetes.
- Write complex queries and optimize performance for PostgreSQL databases to support application needs.
- Engage in automated testing to maintain high code quality and reliability using frameworks such as JUnit and Jest.
- Collaborate with cross-functional teams to troubleshoot application issues and deliver timely solutions.

## Skill Requirements
- Proficient in Java and React with a minimum of 5 years of software development experience.
- Strong experience in developing and integrating RESTful APIs.
- Familiarity with containerization tools like Docker and orchestration with Kubernetes.
- Solid understanding of relational databases, particularly PostgreSQL, including query optimization skills.
- Experience with automated testing frameworks (e.g., JUnit, Jest).
- Ability to work collaboratively in a fast-paced environment.

## Other Requirements
- Knowledge of GraphQL for advanced API development.
- Experience working within Agile/Scrum methodologies and implementing continuous integration practices.
