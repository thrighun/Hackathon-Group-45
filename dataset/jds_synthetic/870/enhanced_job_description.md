## Detailed Responsibilities
- Design and implement user-friendly web applications using React for the front end and Node.js for the server side.
- Participate in all stages of the software development lifecycle, from requirement gathering and design through implementation, testing, and maintenance.
- Collaborate with product managers and designers to define application features and contribute to project planning.
- Develop and maintain scalable RESTful APIs and microservices, focusing on security and performance best practices.
- Manage Docker containers and Kubernetes orchestration for deployment in Azure cloud environments.
- Implement CI/CD pipelines to automate deployment and ensure integration testing.
- Apply Agile methodologies to optimize team collaboration and deliver high-quality software solutions.
- Maintain a solid understanding of software architecture principles, including microservices and event-driven design.
- Work with both SQL Server and MongoDB for data management and processing.
- Troubleshoot and resolve complex technical issues across various systems and platforms.

## Skill Requirements
- Proficient in React and Node.js for full-stack development.
- Strong experience in developing RESTful APIs and microservices architecture.
- Familiarity with Azure cloud services, Docker, and Kubernetes for application deployment.
- Knowledge of SQL Server and MongoDB as database solutions.
- Understanding of CI/CD processes and automation testing frameworks.
- Experience with Agile development practices.
- Excellent problem-solving skills and troubleshooting capabilities.

## Other Requirements
- Relevant certifications in cloud technologies (e.g., Microsoft Certified: Azure Solutions Architect).
- Experience with other programming languages and frameworks (e.g., Python, Ruby on Rails).
- Familiarity with frontend tools such as Redux or Webpack is a plus.
