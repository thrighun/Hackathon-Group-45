## Detailed Responsibilities
- Build and maintain high-performance web applications leveraging Python and FastAPI for backend development.
- Collaborate closely with frontend developers to ensure cohesive integration of AI functionalities and user interfaces.
- Design and implement machine learning models within applications to enhance user experiences and automate processes.
- Optimize performance, scalability, and security of applications, especially focusing on API management and data handling.
- Engage in thorough code reviews and share knowledge to promote best practices across the development team.
- Work alongside cross-functional teams to gather project requirements and align technical solutions to meet business needs.
- Manage NoSQL databases using MongoDB, including designing data models and ensuring efficient data access patterns.
- Contribute to the development of serverless architectures to improve deployment efficiency and reduce operational overhead.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Software Engineering, or a related discipline.
- Strong experience with Python and FastAPI for building web applications, with a clear understanding of asynchronous programming.
- Proficiency in NoSQL databases, particularly MongoDB, and familiarity with data modeling techniques.
- Proven background in deploying machine learning models into production environments.
- Understanding of API design principles, specifically with GraphQL, and experience in managing API lifecycles.
- Excellent problem-solving abilities and a detail-oriented mindset.
- Effective communication skills, capable of conveying complex technical concepts to non-technical stakeholders.

## Other Requirements
- Experience with cloud services (AWS, Azure, GCP) and serverless technologies like AWS Lambda or Google Cloud Functions.
- Familiarity with agile development methodologies and CI/CD processes.
- Contributions to AI/ML communities or involvement in relevant open-source projects.
