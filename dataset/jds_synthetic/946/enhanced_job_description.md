## Job Title
React Developer

## Location
Remote

## Client Industry
Multinational Technology Provider

## Detailed Responsibilities
- Build and maintain high-performance web applications using React 16+ and JavaScript.
- Collaborate with UX/UI designers to create intuitive user interfaces.
- Contribute to all phases of the development lifecycle, from planning to deployment.
- Enhance application performance through optimization techniques and best practices.
- Conduct code reviews and mentor junior developers to foster a collaborative team environment.
- Identify and resolve bugs and performance bottlenecks swiftly.
- Stay informed on emerging trends and technologies in front-end development.

## Skill Requirements
- 3-6 years of experience in front-end development with React.
- Proficiency in JavaScript and React 16+.
- Strong knowledge of web standards and performance optimization techniques.
- Experience with RESTful web services and asynchronous programming.
- Familiarity with Git and Agile development processes.
- Excellent analytical skills and problem-solving abilities.
- Bachelor's degree in Computer Science, Software Engineering, or a related field.

## Other Requirements
- Experience with state management tools (e.g., Redux, Context API).
- Knowledge of testing frameworks (e.g., Jest, Mocha).
- Understanding of Web Accessibility (WCAG) standards and best practices.
