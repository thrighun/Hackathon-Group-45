## Job Title
Senior Embedded Software Engineer Specializing in IoT Devices

## Location
Remote Option Available

## Client Industry
Consumer Electronics

## Detailed Responsibilities
- Develop and implement software for Internet of Things (IoT) devices, with a focus on optimizing performance and connectivity.
- Collaborate with hardware engineers to create integrated solutions that enhance the user experience.
- Design and execute test plans, integrating automated testing frameworks to ensure robust software quality.
- Analyze system performance metrics and refine applications to achieve the highest efficiency and reliability.
- Mentor junior engineers and provide insight into best practices in embedded software development.
- Engage with product management to define software features and prioritize development tasks based on user needs and business goals.
- Document software architectures, algorithms, and development processes for team collaboration and future reference.

## Skill Requirements
- Bachelor's or Master's degree in Computer Science, Software Engineering, or a related field.
- 6-9 years of experience in embedded software development, particularly for IoT applications.
- Proficiency in programming languages such as Python and JavaScript, alongside C/C++.
- Familiarity with communication protocols such as MQTT, HTTP, and Bluetooth.
- Strong background in software testing methodologies, including unit testing and integration testing.
- Excellent analytical and troubleshooting skills.
- Strong verbal and written communication skills for effective collaboration.

## Other Requirements
- Experience with cloud platforms and services for IoT, such as AWS IoT or Azure IoT.
- Knowledge of Agile methodologies and experience with related tools like JIRA or Trello.
- Familiarity with version control systems such as Git and CI/CD pipelines.
- Passion for staying updated with emerging technologies in the IoT space and a willingness to explore innovative solutions.
