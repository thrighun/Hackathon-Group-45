## Job Title
Embedded Systems Software Engineer

## Location
N/A

## Client Industry
Technology

## Detailed Responsibilities
- Design, develop, and optimize firmware for embedded systems and devices.
- Collaborate with hardware engineers to ensure proper integration and functionality of embedded software with devices.
- Participate in full software development lifecycle, including requirement gathering, implementation, testing, and deployment.
- Troubleshoot and debug hardware-software interaction issues to maintain system performance and reliability.
- Create and maintain comprehensive documentation for embedded software solutions as well as participate in design reviews.
- Ensure compliance with industry standards and best practices in embedded software development.
- Mentor junior engineers and provide technical leadership within the team.

## Skill Requirements
- 5-10 years of proven experience in embedded software development using C and C++.
- Strong knowledge of real-time operating systems and low-level hardware programming.
- Experience with debugging tools and methodologies specific to embedded systems.
- Familiarity with hardware interfaces such as I2C, SPI, and UART.
- Ability to work collaboratively in cross-functional teams and communicate effectively.

## Other Requirements
- Experience with additional programming languages like Python or Java is advantageous.
- Knowledge of version control systems, particularly Git.
- Strong analytical and problem-solving skills with a proactive mindset.
