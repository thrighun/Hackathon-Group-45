## Job Title
Software Quality Assurance Analyst – Functional, Mobile & API Testing

## Location
N/A

## Client Industry
Information Technology / Technology Solutions

## Detailed Responsibilities
- Develop and execute comprehensive test plans and test cases for functional, mobile, and API applications to ensure they meet business requirements and technical specifications.
- Conduct thorough mobile application testing across various devices and platforms to ensure optimal performance and user experience.
- Implement API testing strategies using appropriate tools to validate the functionality, performance, and security of server-side applications.
- Document and track defects meticulously using tracking systems, while collaborating with development teams for prompt issue resolution.
- Review software requirements and specifications, participating in design discussions to provide insights on testability and quality standards.
- Analyze testing outcomes and prepare detailed reports, offering constructive feedback and insights to improve product quality.
- Engage actively with Product Managers, Developers, and other QA Analysts in a collaborative Agile environment to ensure comprehensive test coverage.
- Assist in coordinating User Acceptance Testing (UAT) and validate software post-release for functional integrity.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- Minimum of 2 years of experience in quality assurance, with a focus on functional, mobile, and API testing.
- Strong understanding of different testing methodologies and software development life cycle (SDLC).
- Proficiency in designing and executing detailed test cases and documentation.
- Experience using tools like Postman for API testing and familiarity with mobile testing platforms.
- Excellent analytical skills and attention to detail, enabling effective troubleshooting.
- Strong verbal and written communication skills, with the ability to work collaboratively in a team.

## Other Requirements
- Experience in Agile/Scrum development methodologies.
- Knowledge of automation testing tools is a plus, e.g., Appium for mobile testing or REST Assured for API testing.
- ISTQB certification or equivalent QA credentials are preferred.
- Familiarity with cloud services and their testing environments will be advantageous.
