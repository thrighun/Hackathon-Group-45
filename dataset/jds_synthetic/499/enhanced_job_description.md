- Design and develop responsive web applications utilizing Java, React, or Ruby on Rails.
- Implement user-friendly interfaces and optimize applications for maximum speed and scalability.
- Collaborate with product managers and UX/UI designers to gather requirements and ensure a seamless user experience.
- Conduct code reviews and contribute to maintaining coding standards and best practices.
- Analyze application performance metrics and troubleshoot issues to effectively enhance system quality.
- Engage in continuous learning of emerging technologies, particularly in data analysis and machine learning.
- Participate in Agile methodologies, including sprint planning and daily stand-ups.

- Proficiency in Java, React, or Ruby on Rails frameworks.
- Solid understanding of web application architecture and design principles.
- Familiarity with data analysis tools and machine learning concepts is a plus, or a willingness to learn.
- Bachelor’s degree in Computer Science, Software Engineering, or a related discipline.
- Strong problem-solving skills and attention to detail.
- Effective communication skills and ability to work collaboratively in a team environment.
