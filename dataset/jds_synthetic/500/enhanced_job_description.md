## Detailed Responsibilities
- Design and implement scalable data architectures for the ingestion, processing, and storage of data in cloud environments (AWS, Azure, or Google Cloud).
- Collaborate with data scientists and software engineers to ensure data availability and quality for AI model training and evaluation.
- Develop ETL processes and data transformation workflows to support machine learning initiatives.
- Optimize queries and improve the performance of data retrieval processes to facilitate real-time analytics.
- Implement data governance and security measures to protect sensitive information in accordance with industry standards.
- Stay informed about emerging data technologies and best practices related to cloud data management and machine learning.
- Participate in cross-functional teams to drive innovation and enhance the overall data strategy of the organization.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Data Engineering, or related fields.
- Proven experience in building data pipelines using Python or similar programming languages.
- Strong knowledge of cloud services and architectures, specifically in data storage and processing.
- Familiarity with machine learning frameworks and tools (e.g., TensorFlow, PyTorch, Scikit-learn).
- Proficiency in SQL and experience with relational and non-relational databases.
- Understanding of data governance, data quality, and data security best practices.
- Experience with containerization technologies (Docker/Kubernetes) and CI/CD practices.

## Other Requirements
- Familiarity with data visualization tools (e.g., Tableau, Power BI) is a plus.
- Understanding of data science concepts and workflows.
- Experience with infrastructure-as-code tools (e.g., Terraform).
- Cloud certifications (e.g., AWS Certified Data Analytics, Google Cloud Professional Data Engineer) are preferred.
- Strong interpersonal and communication skills, with the ability to articulate technical concepts to non-technical stakeholders.
