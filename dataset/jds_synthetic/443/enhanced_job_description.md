## Job Title
Quality Assurance Automation Specialist

## Location
N/A

## Client Industry
Technology

## Detailed Responsibilities
- Develop and maintain robust automation frameworks for API testing using Python and related technologies.
- Conduct thorough testing of APIs to ensure reliability, performance, and security of web services.
- Collaborate closely with development teams to integrate automated testing within the continuous integration and delivery (CI/CD) pipelines using tools like Git.
- Utilize performance monitoring tools to evaluate application responsiveness and scalability, providing actionable insights for improvements.
- Analyze test results, report defects, and assist in triaging issues to maintain high software quality standards.
- Document testing processes, including test scenarios and results, to support knowledge sharing and compliance requirements.
- Engage actively in Agile team meetings, sprint reviews, and retrospectives to contribute to product quality discussions and planning.
- Identify and recommend enhancements in automation skills and tools aligned with industry best practices.

## Skill Requirements
- Bachelor's degree in Software Engineering, Information Technology, or a related discipline.
- Strong experience in quality assurance and automation, particularly in API testing with Python.
- Familiarity with testing tools and framework experience such as Postman, pytest, or similar.
- Proficient in using version control systems like Git for collaboration on testing efforts.
- Knowledge of software development life cycle (SDLC) and Agile methodologies.
- Excellent analytical skills with a keen eye for detail, capable of managing multiple tasks effectively.
- Ability to work in a collaborative atmosphere, fostering teamwork and communication.

## Other Requirements
- Industry certifications in QA (e.g., Certified Software Tester, Agile Tester) are desirable.
- Understanding of containerization and orchestration technologies (e.g., Docker, Kubernetes) is a plus.
- Experience with load testing tools (e.g., JMeter, LoadRunner).
- Basic knowledge of cloud computing services and deployment processes.
