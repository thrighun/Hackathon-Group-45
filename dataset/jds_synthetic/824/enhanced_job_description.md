## Job Title
Senior Software Engineer - Java

## Location
Bangalore

## Client Industry
Global IT Services Provider

## Detailed Responsibilities
- Develop and maintain cloud-based applications using Java and Spring Framework to enhance business solutions.
- Collaborate closely with cross-functional teams, including business analysts and UX designers, to define and refine application features.
- Create and manage RESTful services for application interactions and third-party integration.
- Implement automated testing frameworks to ensure code quality and reduce deployment times.
- Monitor application performance and troubleshoot issues, ensuring high levels of reliability and uptime.
- Engage in peer code reviews to maintain code quality and share knowledge across the team.
- Stay informed about industry best practices and emerging technologies to improve software development processes.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- 4-6 years of experience in Java development, with strong knowledge of the Spring Framework.
- Experience designing and building RESTful APIs.
- Familiarity with modern cloud environments (AWS, Azure, or similar).
- Proficient in database management with SQL and NoSQL databases.
- Strong analytical thinking and problem-solving capabilities.
- Excellent communication and teamwork skills.

## Other Requirements
- Understanding of CI/CD practices and tools.
- Experience with microservices architecture is a plus.
- Familiarity with containerization technologies like Docker and Kubernetes.
- Knowledge of Agile methodologies.
- Willingness to work flexible hours to accommodate project needs.
