## Job Title
Frontend Engineer

## Location
N/A

## Client Industry
Multinational Technology Provider

## Detailed Responsibilities
- Design and implement user interfaces using Angular for responsive web applications.
- Collaborate with UX/UI designers to create user-centric designs and improve user experience.
- Enhance application performance by implementing best practices in coding and architecture.
- Maintain code quality through unit testing and code reviews.
- Integrate with backend services and APIs to deliver seamless functionality.
- Participate in agile development processes, including sprint planning and retrospectives.
- Monitor and optimize application performance, identifying areas for improvement.

## Skill Requirements
- 2-3 years of hands-on experience with Angular and related technologies.
- Strong understanding of HTML, CSS, and JavaScript fundamentals.
- Experience with state management libraries, such as NgRx.
- Familiarity with RESTful APIs and microservices architecture.
- Proficiency in using version control systems, particularly Git.
- Excellent analytical and troubleshooting skills.
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.

## Other Requirements
- Experience with automated testing frameworks like Jasmine or Protractor.
- Knowledge of responsive design principles and frameworks such as Bootstrap.
- Familiarity with continuous integration and continuous deployment (CI/CD) pipelines.
- Strong communication skills and the ability to work effectively in cross-functional teams.
