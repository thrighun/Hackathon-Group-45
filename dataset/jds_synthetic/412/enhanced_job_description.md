## Job Title
Full Stack JavaScript Developer with Node.js and Angular Skills

## Location
Remote

## Client Industry
Leading Software Development Company

## Detailed Responsibilities
- Design, develop, and maintain scalable web applications using Angular for the front end and Node.js for the back end.
- Collaborate closely with UX/UI designers to transform designs into functional web applications.
- Build reusable code and libraries for future use, ensuring high performance and responsiveness.
- Optimize applications for speed and efficiency while implementing best practices in code quality.
- Participate in code reviews, mentoring junior developers, and contributing to team knowledge sharing.
- Analyze user needs and develop software solutions to improve user experience and functionality.
- Stay informed on emerging technologies and propose innovative solutions to improve application performance.

## Skill Requirements
- 3-6 years of experience in full stack JavaScript development, with strong expertise in Angular and Node.js.
- Proficient in HTML5, CSS3, and JavaScript ES6+.
- Familiarity with RESTful services and API integration.
- Experience with database technologies such as MongoDB or PostgreSQL.
- Understanding of version control systems, particularly Git.
- Bachelor’s degree in Computer Science or related field.
- Strong analytical and troubleshooting abilities.
- Excellent collaboration and communication skills.

## Other Requirements
- Experience with TypeScript and modern front-end build tools (Webpack, Babel).
- Knowledge of microservices architecture and cloud service deployment (AWS/Azure).
- Familiarity with Agile methodologies and experience in fast-paced development environments.
- Understanding of testing frameworks and methodologies (Jest, Mocha).
