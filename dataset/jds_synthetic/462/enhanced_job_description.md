- Develop dynamic and engaging web applications using Angular and Vue.js.
- Collaborate closely with UX/UI Designers and Marketing teams to build interactive and visually appealing online marketing tools.
- Implement responsive designs and ensure seamless user experiences across various devices and browsers.
- Conduct performance analysis and optimizations for high-traffic web applications.
- Participate in Agile development processes, contributing to sprint planning and retrospective meetings.
- Mentor junior developers and facilitate knowledge sharing within the team.
- Participate in user testing and feedback sessions to iterate on the development process.
- Continuously enhance applications by integrating new frameworks and industry best practices.

- Familiarity with API integration, particularly with third-party services.

- Understanding of version control systems, specifically Git.
- Ability to work collaboratively in a fast-paced environment.
- Bachelor's degree in Computer Science, Web Development, or a related field.
