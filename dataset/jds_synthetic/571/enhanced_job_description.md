## Job Title
Full Stack Developer (React.js, Node.js & Machine Learning)

## Location
Remote / Hybrid (flexible)

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Design and implement full-stack web applications using React.js for the frontend and Node.js for backend services.
- Integrate machine learning algorithms and models to enhance application functionality and user interaction.
- Collaborate with cross-functional teams, including data scientists and product managers, to define application requirements and features.
- Develop RESTful APIs and microservices architectures for seamless data exchange between client and server.
- Ensure code quality through rigorous testing, code reviews, and adherence to best practices in software development.
- Optimize application performance, scalability, and security aspects across various platforms and devices.
- Participate in agile development cycles, including sprint planning, stand-ups, and retrospectives, to deliver high-quality software solutions.
- Research and evaluate new technologies and tools that could improve development processes and application performance.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- Minimum of 5 years of experience in full-stack development, particularly with React.js and Node.js.
- Proficiency in integrating and deploying machine learning models, with familiarity in frameworks like TensorFlow or PyTorch.
- Strong understanding of modern JavaScript (ES6+), HTML5, CSS3, and responsive design practices.
- Experience working with databases (SQL and NoSQL) and data storage solutions.
- Knowledge of cloud computing services (AWS, Azure, or GCP) and experience deploying applications in cloud environments.
- Familiar with Continuous Integration/Continuous Deployment (CI/CD) pipelines and automated testing frameworks.

## Other Requirements
- Experience with containerization technologies like Docker and orchestration tools such as Kubernetes.
- Strong communication and collaboration skills, with an aptitude for working in dynamic team environments.
- Familiarity with Agile methodologies and project management tools such as JIRA or Trello.
- A proactive approach to problem-solving and a passion for learning new technologies.
