## Job Title
Node.js Web Application Developer

## Location
N/A

## Client Industry
Information Technology / Data Analytics Solutions Provider

## Detailed Responsibilities
- Develop, enhance, and maintain high-performance web applications utilizing Node.js and the Express.js framework.
- Collaborate with product managers and designers to create seamless user experiences and implement responsive web features.
- Design, optimize, and manage database solutions, primarily using MySQL, ensuring efficient data storage and retrieval.
- Deploy and scale web applications on Amazon Web Services (AWS), employing cloud best practices for high availability and security.
- Integrate machine learning algorithms and data analytics solutions to enhance application capabilities and provide data-driven insights.
- Write robust, reusable, and high-quality code while following industry conventions and software development life cycles.
- Engage in comprehensive code reviews, debugging sessions, and performance tuning to uphold application excellence.
- Stay informed about the latest industry trends and technologies, recommending innovative solutions to enhance product offerings.
- Collaborate closely with DevOps and testing teams to ensure streamlined workflows and high-quality deliverables.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Software Engineering, or a related discipline.
- A minimum of 3 years’ experience in web application development with a strong focus on Node.js and Express.js.
- Proficient in SQL and experience with MySQL databases.
- Familiarity with deploying applications in cloud environments, particularly AWS.
- Understanding of machine learning concepts and experience in implementing data analytics frameworks.
- Solid knowledge of RESTful API design, microservices architecture, and modern web development tools.
- Strong analytical and problem-solving abilities, with a detail-oriented approach to coding and design.

## Other Requirements
- Experience with container orchestration and virtualization tools such as Docker and Kubernetes is a plus.
- Prior experience with continuous integration/continuous deployment (CI/CD) pipelines and automated testing practices.
- Familiarity with additional cloud service providers (e.g., Google Cloud Platform, Microsoft Azure).
- Excellent verbal and written communication skills, with a strong capacity for teamwork and collaboration.
