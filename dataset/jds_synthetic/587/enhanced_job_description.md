## Job Title
Python Software Engineer

## Location
Bangalore

## Client Industry
Global Software Solutions Provider

## Detailed Responsibilities
- Design, develop, and optimize scalable applications using Python and Django framework.
- Collaborate with data engineers and UI/UX designers to ensure cohesive product development.
- Develop and integrate GraphQL APIs for enhanced data fetching and manipulation.
- Implement data pipelines to manage and process large sets of data effectively.
- Perform code reviews, debugging, and maintenance to ensure high-quality software delivery.
- Engage in sprint planning and contribute to Agile ceremonies to improve team efficiency.
- Provide mentorship to junior developers and assist with their coding challenges.
- Remain abreast of industry trends and emerging technologies that can enhance software solutions.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related discipline.
- 4-6 years of solid experience in Python development, with a focus on Django.
- Proficient in building and consuming GraphQL APIs.
- Experience with cloud platforms such as AWS, Azure, or DigitalOcean.
- Strong understanding of data handling and processing frameworks like Apache Airflow or Apache Kafka.
- Excellent analytical and problem-solving abilities.
- Ability to work in a fast-paced, collaborative team environment.
- Effective communication skills, both written and verbal.

## Other Requirements
- Familiarity with front-end technologies such as Vue.js or Bootstrap.
- Knowledge of containerization technologies like Docker or Kubernetes.
- Understanding of CI/CD processes and tools.
- Relevant certifications in Python or cloud technologies.
- Willingness to work during flexible hours as needed.
