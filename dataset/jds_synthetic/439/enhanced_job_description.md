## Job Title
Lead API Architect (Node.js, Express.js, MongoDB)

## Location
Remote Flexibility Available

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Develop and oversee the architecture of RESTful APIs using Node.js and Express.js, ensuring high performance and security.
- Collaborate with cross-functional teams, including frontend developers and product management, to align technical solutions with business needs.
- Design and implement database schemas, data storage solutions, and optimize MongoDB for performance and reliability.
- Establish best practices for API development, including versioning, documentation, and monitoring.
- Mentor and guide junior developers, fostering a culture of knowledge sharing and continuous learning.
- Conduct thorough code reviews and audits, focusing on adherence to coding standards and performance optimization.
- Lead the integration of third-party services and ensure seamless data flow within the architecture.
- Evaluate new technologies and tools to enhance API development and infrastructure.
- Implement CI/CD pipelines to streamline deployments and improve development workflows.
- Stay informed on industry trends and advancements in API architecture and backend development.

## Skill Requirements
- Minimum 7 years of professional experience in API development and architecture.
- Proficiency in Node.js and Express.js frameworks.
- Extensive experience with MongoDB, including data modeling and query optimization.
- Bachelor's degree in Computer Science, Software Engineering, or similar fields. Advanced degrees or certifications are advantageous.
- Strong background in building scalable and resilient API ecosystems.
- In-depth knowledge of version control systems, particularly Git, and familiarity with agile methodologies.
- Excellent analytical skills coupled with meticulous attention to detail.
- Strong communication capabilities to collaborate effectively with diverse teams.

## Other Requirements
- Familiarity with containerization tools like Docker and orchestration platforms such as Kubernetes.
- Experience with serverless architecture and cloud services (AWS, Azure, GCP).
- Understanding of API security standards and practices (e.g., OAuth, JWT).
- Contributions to technology blogs, forums, or open-source projects are a plus.
