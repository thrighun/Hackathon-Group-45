## Job Title
Senior Full Stack Developer

## Location
Bangalore

## Client Industry
Software Development Firm

## Detailed Responsibilities
- Design and develop end-to-end web applications using Vue.js for the front end and Node.js for the back end.
- Collaborate closely with UX/UI designers to create a seamless and engaging user experience.
- Implement GraphQL APIs to facilitate efficient data retrieval and manipulation.
- Optimize applications for maximum speed and scalability while maintaining best practices for code quality and performance.
- Conduct code reviews and provide constructive feedback to improve team coding standards and practices.
- Identify and troubleshoot software defects, ensuring timely resolution and continuous enhancement of the application.
- Work within an Agile environment, actively participating in sprint planning, daily stand-ups, and retrospectives.
- Mentor and guide junior developers in coding and design best practices, fostering a culture of knowledge sharing and collaboration.

## Skill Requirements
- Bachelor's degree in Computer Science or a related field.
- 5-7 years of experience in full-stack development with a focus on Vue.js and Node.js.
- Strong proficiency in building GraphQL APIs and understanding of REST principles.
- Experience with database management systems like MongoDB or PostgreSQL.
- Solid understanding of responsive web design and front-end frameworks.
- Excellent analytical and troubleshooting skills to resolve technical challenges.
- Strong team player with effective communication skills to convey complex technical concepts.

## Other Requirements
- Familiarity with CI/CD tools and practices to streamline the deployment process.
- Knowledge of cloud services such as AWS or Azure for application hosting.
- Experience with containerization using Docker or Kubernetes.
- Exposure to DevOps methodologies and practices.
- Ability to work flexible hours, including occasional night shifts.
