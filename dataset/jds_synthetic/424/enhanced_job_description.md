## Job Title
Frontend Engineer (Angular & Machine Learning)

## Location
Remote

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Design and implement dynamic web applications using Angular framework, ensuring high performance and responsiveness.
- Integrate machine learning models and APIs into the frontend to enhance user experiences with predictive analytics and personalization.
- Collaborate with product managers and designers to create intuitive user interfaces and enhance overall user satisfaction.
- Work with backend developers to ensure seamless integration of APIs and services, focusing on data fetching and state management.
- Conduct performance testing and debugging to optimize application efficiency across multiple platforms and devices.
- Stay updated on the latest developments in frontend technologies and machine learning, applying relevant insights to projects.
- Engage in code review sessions and contribute to best practice discussions to maintain high-quality code standards.
- Participate actively in agile team activities, including sprint planning, stand-ups, and retrospectives.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- At least 4 years of experience with Angular, including component-based architecture and state management tools like NgRx.
- Proficiency in integrating machine learning technologies and APIs (e.g., TensorFlow.js, Azure ML) into web applications.
- Strong knowledge of TypeScript, HTML5, CSS3, and mobile-first design principles.
- Familiarity with RESTful services, asynchronous programming, and reactive programming paradigms.
- Experience with version control systems such as Git and continuous integration/continuous deployment (CI/CD) processes.
- Excellent analytical and problem-solving skills, with attention to detail and the ability to work collaboratively in teams.

## Other Requirements
- Experience in cloud services (AWS, Google Cloud, or Azure) and deploying scalable web applications.
- Understanding of testing frameworks (Karma, Jasmine) and performance optimization tools.
- Knowledge of web accessibility standards and best practices.
- Strong communication and collaboration skills, with experience in interacting with clients or stakeholders.
