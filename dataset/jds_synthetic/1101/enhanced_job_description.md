## Job Title
Frontend Developer specializing in Vue.js and Nuxt.js

## Location
Remote

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Design and implement engaging user interfaces using Vue.js and Nuxt.js frameworks.
- Collaborate effectively with design teams and backend developers to create cohesive and functional web applications.
- Write modular, reusable code that follows best practices for maintainability and scalability.
- Ensure applications are optimized for performance, including minimizing load times and enhancing user experience.
- Conduct regular user testing sessions and iterate features based on feedback and analytics.
- Create comprehensive documentation for code, processes, and best practices to aid team collaboration and onboarding.
- Participate in agile development processes and contribute to sprint planning and retrospectives.
- Troubleshoot and debug issues reported by users, ensuring timely resolution and a smooth experience.
- Stay current with industry trends and emerging technologies to continually refine development practices.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- Proven experience (2+ years) in frontend development with Vue.js and Nuxt.js.
- Strong understanding of JavaScript (ES6+), HTML5, and CSS3.
- Familiarity with state management libraries such as Vuex and middleware integrations.
- Experience working with RESTful APIs and handling asynchronous data fetching.
- Proficiency in version control systems, especially Git.
- Knowledge of responsive web design principles and mobile-first development.
- Excellent problem-solving abilities and attention to detail, alongside a collaborative spirit.
- Strong verbal and written communication skills.

## Other Requirements
- Experience with TypeScript and testing frameworks like Jest or Cypress.
- Familiarity with cloud service platforms (e.g., AWS Lambda, Firebase).
- Understanding of agile methodologies, particularly Scrum and Kanban.
- Experience with CI/CD tools and processes, such as Jenkins or GitLab CI.
- Contributions to open-source projects or demonstrable personal projects showcasing frontend skills.
