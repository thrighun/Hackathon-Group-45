## Job Title
Senior Front-End Developer with Vue.js

## Location
Remote/Hybrid Options Available

## Client Industry
Multinational Technology Provider

## Detailed Responsibilities
- Design and implement web applications using Vue.js, ensuring high performance and responsiveness.
- Collaborate closely with UX/UI designers to create user-friendly interfaces.
- Participate in the entire application lifecycle, focusing on coding and debugging.
- Build reusable code and libraries for future use to enhance development efficiency.
- Optimize applications for speed and scalability while ensuring cross-device compatibility.
- Lead code reviews and mentor junior developers to improve team skill sets.
- Monitor application performance and resolve any issues that arise.

## Skill Requirements
- A minimum of 6 years of experience in front-end development.
- Proficiency in Vue.js and familiarity with its ecosystem (Vuex, Vue Router).
- Strong grasp of modern JavaScript (ES6+), HTML5, and CSS3.
- Experience with component-based architecture and responsive design frameworks (e.g., Bootstrap, Tailwind).
- Knowledge of state management patterns and libraries, preferably Vuex.
- Understanding of RESTful services and APIs as well as GraphQL.
- Bachelor's degree in Computer Science, Software Engineering, or a related discipline.

## Other Requirements
- Experience with TypeScript and SASS/SCSS.
- Familiarity with build tools such as Webpack and npm.
- Excellent analytical and problem-solving skills with a keen eye for detail.
- Strong communication skills and ability to work collaboratively in a team-oriented environment.
