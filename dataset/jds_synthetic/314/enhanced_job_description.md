## Detailed Responsibilities
- Design and implement responsive web applications using Vue.js and Bulma CSS framework.
- Collaborate with UX/UI designers to create visually appealing and user-friendly interfaces.
- Ensure application performance is optimized for speed and efficiency across various devices and browsers.
- Work with back-end developers to integrate APIs and manage data flow between front-end and back-end services.
- Participate in sprint planning, daily stand-ups, and retrospectives to contribute to team goals and project timelines.
- Conduct thorough testing and debugging to ensure applications are free of critical issues prior to deployment.
- Stay up-to-date with the latest trends and best practices in front-end development and e-commerce technologies.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- Minimum of 2 years of professional experience in front-end development using Vue.js.
- Strong knowledge of Bulma CSS for building responsive layouts and components.
- Proficiency in JavaScript (ES6+), HTML5, and CSS3.
- Familiarity with state management patterns in Vue, such as Vuex.
- Experience with RESTful services and version control systems like Git.
- Solid understanding of responsive design and modern web standards.

## Other Requirements
- Knowledge of automated testing frameworks like Mocha or Cypress.
- Experience with build tools such as Webpack or Vite.
- Understanding of SEO principles and practices relevant to e-commerce sites.
- Previous involvement in retail or e-commerce projects is highly desirable.
- Exposure to cloud services and CI/CD workflows would be a plus.
