## Detailed Responsibilities
- Develop and maintain automated test scripts for web applications and APIs, ensuring that all functionalities are well-tested.
- Collaborate with product managers and developers to understand requirements and develop thorough test plans and strategies that cover both functional and non-functional testing.
- Execute automated tests and analyze results to identify any defects, ensuring they are logged and resolved in a timely manner.
- Participate in code reviews and provide input on testability and quality improvements in the codebase.
- Assist in the design and implementation of CI/CD pipelines to facilitate continuous testing and integration.
- Prepare and present test reports to stakeholders, highlighting test coverage, results, and areas for improvement.
- Mentor junior QA team members on automation best practices and techniques, fostering a culture of quality within the team.
- Stay updated with the latest industry trends and technologies in software testing and automation.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- Minimum of 3 years of experience in automated testing for web applications and APIs.
- Proficiency in automation testing tools such as Selenium, TestNG, or similar frameworks.
- Strong programming skills in languages such as Java, Python, or JavaScript to create and maintain test scripts.
- Familiarity with RESTful and SOAP web services, as well as API testing tools like Postman or SoapUI.
- Experience with version control systems such as Git.
- Excellent problem-solving skills and attention to detail.
- Ability to work collaboratively in a fast-paced Agile environment.

## Other Requirements
- Knowledge of performance testing tools (e.g., JMeter) is a plus.
- Experience in cloud computing and testing in cloud environments is advantageous.
- ISTQB or equivalent certification is preferred.
