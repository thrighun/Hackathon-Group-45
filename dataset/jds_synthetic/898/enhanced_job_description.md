## Job Title
Senior Frontend Developer - React and Legacy System Integration

## Location
Remote

## Client Industry
Technology

## Detailed Responsibilities
- Lead the integration of modern React applications with existing legacy systems.
- Design and implement responsive user interfaces to enhance user experience.
- Collaborate with backend developers to define APIs and improve data flow.
- Conduct performance tuning and optimization of both legacy and new codebases.
- Mentor junior developers and foster a culture of knowledge sharing within the team.
- Create clear documentation for code processes and integration procedures.
- Stay abreast of advancements in frontend technologies to drive continuous improvement initiatives.

## Skill Requirements
- Minimum of 7+ years of experience in frontend development.
- Proficiency in React and deep understanding of its ecosystem.
- Strong expertise in JavaScript, HTML5, and CSS3.
- Experience with version control tools like Git and CI/CD processes.
- Excellent analytical and debugging skills.
- Bachelor's degree in Computer Science, Software Engineering, or a related discipline.
- Proven ability to work collaboratively in a fast-paced environment.

## Other Requirements
- Familiarity with TypeScript and modern state management libraries (e.g., Redux).
- Experience with agile development practices and tools such as Jira or Trello.
- Understanding of web accessibility standards and best practices.
