## Job Title
Python Developer

## Location
Remote / Hybrid Available

## Client Industry
Dynamic Technology Provider

## Detailed Responsibilities
- Design, develop, and maintain scalable web applications utilizing Python and related frameworks.
- Collaborate with product managers and UX designers to define functional requirements and enhance user experience.
- Participate in all stages of the software development lifecycle, including planning, development, testing, and deployment.
- Write clean, efficient, and well-documented code in accordance with best practices and coding standards.
- Implement unit tests and participate in code reviews to ensure code quality and performance.
- Monitor application performance and troubleshoot issues to optimize functionality.
- Stay ahead of industry trends and technologies to foster continuous improvement in the development process.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- 3-6 years of experience in Python development and web frameworks such as Django or Flask.
- Solid understanding of RESTful APIs and microservices architecture.
- Familiarity with front-end technologies, including HTML, CSS, and JavaScript frameworks (e.g., React or Angular).
- Experience with relational and non-relational databases such as PostgreSQL or MongoDB.
- Knowledge of version control systems, especially Git.
- Strong analytical skills and problem-solving abilities.
- Effective communication and teamwork skills.

## Other Requirements
- Familiarity with cloud services like AWS, Azure, or Google Cloud.
- Understanding of containerization and orchestration tools such as Docker and Kubernetes.
- Previous experience with Agile methodologies, particularly Scrum.
- Relevant certifications in Python or cloud architecture are a plus.
