## Job Title

## Location

## Detailed Responsibilities
- Develop and maintain scalable web applications using Node.js for backend services and Vue.js for responsive front-end interfaces.
- Collaborate with cross-functional teams, including UX/UI designers and business analysts, to create seamless, user-friendly web experiences tailored to the retail sector.
- Write high-quality, efficient, and reusable code, implementing best practices in both front-end and back-end development.
- Create and manage RESTful APIs, ensuring robust integration with various services and databases to enhance application performance.
- Optimize applications for maximum speed and scalability, providing an outstanding user experience on all devices.
- Conduct rigorous testing and troubleshooting to ensure software reliability and performance under varying conditions.
- Stay informed about the latest technologies and trends in full-stack development, offering innovative solutions to improve application functionality.
- Participate actively in agile sprints, contributing to planning, estimations, and continuous delivery practices.
- Lead knowledge-sharing sessions, mentoring junior developers, and promoting a culture of technical excellence and collaboration.

- Experience with front-end technologies such as HTML5, CSS3, and JavaScript (ES6+).
- Familiarity with version control systems and collaborative workflows (e.g., Git, GitHub).
- Understanding of software development methodologies, particularly agile practices.
- Strong analytical and problem-solving skills, with attention to detail and effective communication.
