## Job Title
Java Software Engineer – AI Model Integration & Intelligent Systems

## Location
Remote

## Client Industry
Technology

## Detailed Responsibilities
- Develop and optimize backend applications using Java, focusing on AI model integration and intelligent systems.
- Architect and implement microservices that facilitate seamless communication between various AI models and client applications.
- Collaborate with machine learning engineers and product managers to specify requirements and design solutions that meet user needs.
- Ensure high availability and performance of applications through rigorous testing and performance tuning.
- Write comprehensive documentation for systems and APIs, maintaining a clear understanding of architecture and components.
- Conduct code reviews and mentor junior developers to foster a culture of knowledge sharing and continuous improvement.
- Stay up-to-date with emerging technologies in AI and software development, recommending new tools and frameworks for integration.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- Strong experience in backend development with proficiency in Java and relevant frameworks (e.g., Spring Boot).
- Familiarity with RESTful APIs and microservices architecture, focusing on efficient data flow and processing.
- Understanding of AI/ML model lifecycle management and deployment practices.
- Knowledge of containerization technologies such as Docker and orchestration tools like Kubernetes.
- Experience with cloud services (e.g., AWS, Azure) and database management systems (SQL and NoSQL).
- Proficiency with version control systems, primarily Git.

## Other Requirements
- Experience with serverless architecture and event-driven programming is a plus.
- Knowledge of front-end technologies (JavaScript, React) to collaborate effectively with frontend teams.
- Familiarity with Agile methodologies and participation in Scrum ceremonies.
- Previous contributions to technology communities or open-source projects are desirable.
- Strong analytical and troubleshooting skills, with the ability to work independently and in a team environment.
