## Job Title
Frontend Engineer (React & Gatsby for eCommerce Optimization)

## Location
Remote

## Client Industry
E-commerce Technology Solutions

## Detailed Responsibilities
- Design, develop, and maintain robust web applications using React and Gatsby frameworks for high-performance eCommerce platforms.
- Enhance user experience through advanced optimizations, creating fast-loading, responsive websites tailored for high traffic.
- Customize and integrate various content management systems (CMS), ensuring seamless content updates and management for dynamic eCommerce needs.
- Collaborate with product managers and designers to implement user-centric features, translating wireframes into elegant interfaces with clean, maintainable code.
- Ensure cross-device compatibility and optimize sites for mobile performance and SEO best practices.
- Participate in team-wide code reviews, endorsing best practices and maintaining a high standard of code quality.
- Work alongside backend developers to create cohesive, end-to-end solutions, including API integration and microservices architecture.
- Monitor application performance and troubleshoot issues to ensure uptime and reliability in production.
- Stay informed on industry trends and emerging technologies, contributing ideas for applying them to improve project outcomes.

## Skill Requirements
- Bachelor’s degree in Software Engineering, Web Development, or related field (or equivalent industry experience).
- Strong experience with React, including hooks and state management libraries (e.g., Redux).
- Proficiency in Gatsby and knowledge of how to leverage its features for optimized site building.
- Solid understanding of CSS, with experience using preprocessors like SASS or LESS for modular styles.
- Experience with integrating eCommerce solutions (e.g., Shopify, WooCommerce) and related payment processing systems.
- Familiarity with RESTful APIs and the ability to work with JSON data.
- Excellent analytical and problem-solving skills.
- Strong communication abilities, with a knack for collaboration in cross-functional teams.

## Other Requirements
- Knowledge of TypeScript for building scalable applications.
- Experience working with cloud services (e.g., AWS services related to hosting).
- Familiarity with Agile/Scrum project management methodologies.
- Proven track record of developing websites for high-traffic eCommerce platforms.
- Understanding of web accessibility standards and practices.
