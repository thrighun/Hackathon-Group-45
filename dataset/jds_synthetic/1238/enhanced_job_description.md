## Detailed Responsibilities
- Design and develop user-friendly web applications using Angular and Bootstrap to enhance front-end experiences.
- Collaborate with cross-functional teams including product managers, designers, and backend developers to translate requirements into technical specifications.
- Implement responsive web design principles to ensure applications function seamlessly across various devices and screen sizes.
- Conduct thorough testing and debugging of applications to ensure robustness and performance.
- Engage actively in collaborative code reviews, fostering a culture of continuous learning and improvement within the team.
- Contribute to the maintenance and ongoing improvement of existing applications as well as help design new features.
- Participate in daily Agile ceremonies, providing insights and feedback during retrospectives and planning sessions.

## Skill Requirements
- Bachelor's degree in Software Engineering, Computer Science, or a similar field.
- Demonstrated experience in front-end development with a strong focus on Angular framework.
- Proficiency in Bootstrap for developing responsive layouts and components.
- Deep understanding of TypeScript, HTML5, and CSS3.
- Familiarity with RESTful APIs for data integration.
- Experience using version control systems such as Git for collaborative development.
- Strong analytical and problem-solving skills with attention to detail.
- Excellent communication skills, both verbal and written, for effective collaboration.

## Other Requirements
- Familiarity with state management solutions (e.g., NgRx).
- Experience with Agile methodologies and practices.
- Exposure to continuous integration and deployment (CI/CD) processes.
- Knowledge of unit testing frameworks such as Jasmine or Karma.
- Previous experience with performance optimization techniques for web applications.
