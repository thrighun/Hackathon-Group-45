## Job Title
Embedded Software Engineer - C++ for IoT Devices

## Location
N/A

## Client Industry
Internet of Things (IoT) Solutions Provider

## Detailed Responsibilities
- Design, develop, and test C++ software for embedded applications in IoT devices.
- Collaborate with hardware engineers to ensure seamless integration of software and hardware components.
- Optimize code for performance, memory usage, and power efficiency in constrained environments.
- Identify and resolve software issues during testing and deployment phases.
- Contribute to the development of IoT protocols and data communication standards.
- Maintain up-to-date documentation of software design, implementation, and testing procedures.

## Skill Requirements
- At least 5 years of experience in C++ programming, particularly for embedded and IoT applications.
- Bachelor's degree in Computer Engineering, Software Engineering, or a related field.
- Strong understanding of embedded systems and real-time constraints specific to IoT devices.
- Proficient in low-level programming and device drivers.
- Excellent analytical skills and attention to detail.
- Strong communication skills for effective collaboration with cross-disciplinary teams.

## Other Requirements
- Experience with cloud-based IoT platforms and APIs.
- Familiarity with wireless communication protocols (e.g., MQTT, CoAP, Zigbee).
- Knowledge of agile development practices and version control tools like Git.
