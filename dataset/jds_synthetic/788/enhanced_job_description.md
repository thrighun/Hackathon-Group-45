## Job Title
Senior Python Engineer – Data Processing

## Location
N/A

## Client Industry
Information Technology and Services

## Detailed Responsibilities
- Lead the design and implementation of data processing pipelines using Python for large-scale datasets.
- Develop and maintain ETL (Extract, Transform, Load) processes to ensure data consistency and integrity.
- Collaborate with data scientists and analysts to understand data requirements and optimize data workflows.
- Utilize advanced libraries and frameworks (e.g., Pandas, NumPy) to perform complex data manipulations and analysis.
- Monitor and improve the performance of data processing systems to handle real-time data ingestion and analytics.
- Implement data validation and quality checks within processing workflows to uphold data standards.
- Conduct code reviews, provide guidance to junior engineers, and champion best practices in software development.
- Stay informed about industry trends and emerging technologies in data engineering, and suggest innovative solutions to enhance processes.
- Participate in cross-functional teams to develop and refine data strategy aligned with business goals.

## Skill Requirements
- Bachelor's degree in Computer Science, Data Science, or a related field.
- At least 3 years of experience in data engineering or data processing using Python.
- Strong expertise in working with data processing frameworks such as Apache Spark or Dask.
- Proficient in SQL and experience with both SQL and NoSQL databases (e.g., PostgreSQL, MongoDB).
- Familiarity with cloud-based data services (AWS Redshift, Google BigQuery) and data warehousing solutions.
- Knowledge of data modeling, data governance, and data privacy principles.
- Experience with version control systems (e.g., Git) and CI/CD practices.
- Excellent problem-solving skills and the ability to communicate complex data concepts clearly.

## Other Requirements
- Experience implementing data lakes and data marts in large organizations.
- Familiarity with containerization technologies (Docker, Kubernetes) for managing data services.
- Understanding of machine learning concepts and their application in data processing.
- Prior experience in agile environments and participation in sprint planning and retrospectives.
- Relevant certifications in data engineering or cloud technologies are a plus.
