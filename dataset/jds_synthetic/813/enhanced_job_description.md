## Detailed Responsibilities
- Lead the development and execution of comprehensive test specifications and strategies for QA projects.
- Create and maintain detailed test plans focusing on functional and regression testing of software applications.
- Manage and execute automation tests in Agile settings, ensuring high-quality software delivery.
- Conduct thorough testing of microservice architectures and investigate performance issues.
- Utilize CI/CD tools like Jenkins or Travis CI to streamline testing processes.
- Write and maintain test scripts using frameworks such as Cypress or Mocha for frontend applications.
- Perform API testing with tools like Swagger and Postman, ensuring robust service interaction.
- Mentor junior QA engineers and promote best practices in testing methodology.
- Analyze and report on test performance metrics to inform development decisions.

- 6 to 8 years of experience in quality assurance and automation testing.
- Strong proficiency in programming languages such as Java or JavaScript.
- Expertise in using automation testing frameworks like Cypress or Mocha.
- Solid background in functional and regression testing.
- Familiarity with CI/CD practices, specifically using Jenkins or Travis CI.
- Understanding of testing microservices and cloud-based solutions.
- Knowledge of database testing and proficiency in SQL.

## Other Requirements
- Experience with API testing tools like Swagger and Postman is highly desirable.
- Ability to mentor and guide junior QA engineers in best practices.
- Understanding of e-commerce systems and their testing challenges.
