## Detailed Responsibilities
- Design and develop cloud-native applications using Python and React, ensuring they are scalable and secure.
- Collaborate with cross-functional teams to define and refine features, functionalities, and user experiences for cloud applications.
- Utilize RESTful APIs for seamless integration between various services and applications.
- Participate in code reviews to uphold coding standards and foster team knowledge sharing.
- Troubleshoot and resolve complex technical issues that arise during development and post-deployment phases.
- Conduct performance tuning and optimization for cloud applications, ensuring efficiency and reliability.
- Mentor junior developers, providing guidance on best practices and new technologies to foster their growth.

- Proficient in Python programming and its frameworks (such as Flask or Django).
- Strong experience in building user interfaces with React and managing complex state.
- Solid understanding of cloud computing concepts and experience with cloud platforms (e.g., AWS, Azure).
- Familiarity with REST API development and integration techniques.
- Knowledge of PostgreSQL or other relational databases.
- Strong analytical and problem-solving skills, with the ability to adapt to new technologies quickly.
- Excellent communication and interpersonal skills, with a proven ability to work collaboratively in a team setting.
