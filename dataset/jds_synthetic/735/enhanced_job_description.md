## Detailed Responsibilities
- Design, develop, and maintain scalable web applications using Java and modern front-end frameworks.
- Collaborate with product managers and UX/UI teams to translate business requirements into technical solutions.
- Integrate and manage RESTful services and APIs to connect front-end components with back-end services.
- Optimize applications for maximum speed and scalability, ensuring high availability and performance.
- Participate in code reviews, contributing to the improvement of overall code quality and sharing knowledge with team members.
- Conduct unit testing and troubleshooting of applications to identify and rectify issues promptly.
- Mentor junior developers, sharing best practices and guiding them in their professional growth.
- Implement CI/CD pipelines and automation tools to enhance deployment processes.

## Skill Requirements
- Bachelor's or Master's degree in Computer Science, Software Engineering, or a related field.
- 6-8 years of experience in full-stack Java development, with a strong emphasis on both front-end and back-end technologies.
- Proficiency in Java, Spring Boot, JavaScript frameworks (such as Angular or React), and HTML/CSS.
- Solid understanding of RESTful web services, microservices architecture, and API design.
- Experience with databases like PostgreSQL, MongoDB, or similar technologies.
- Familiarity with DevOps practices, CI/CD tools, and cloud services (AWS, Azure, etc.).
- Strong analytical and problem-solving skills, combined with excellent communication abilities.

## Other Requirements
- Experience with containerization technologies such as Docker and orchestration tools like Kubernetes.
- Knowledge of software development methodologies, particularly Agile and Scrum.
- Relevant certifications such as AWS Certified Solutions Architect or Java certifications would be beneficial.
