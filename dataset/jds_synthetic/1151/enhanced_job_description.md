## Job Title

## Location
N/A

## Client Industry
Technology

## Detailed Responsibilities
- Develop and enhance dynamic web applications using Vue.js framework.
- Collaborate with UI/UX designers to implement visually appealing interfaces.
- Integrate back-end services and APIs with front-end components.
- Conduct performance optimizations to ensure fast load times and smooth user experiences.
- Write unit and integration tests to maintain code quality and reliability.

- 2-4 years of experience in front-end development, particularly with Vue.js.
- Strong knowledge of JavaScript, HTML5, and CSS3.
- Experience with RESTful APIs and asynchronous programming.
- Familiarity with version control systems, particularly Git and Git workflows.
- Ability to think critically and creatively to solve complex problems.

## Other Requirements
- Understanding of modern front-end build tools and workflows, such as Webpack or Vite.
- Experience with Agile development methodologies, preferably in a Scrum team.
- Knowledge of TypeScript and additional frameworks like Nuxt.js is a plus.
