## Job Title
Full Stack Developer (Vue.js & Bootstrap)

## Location
N/A

## Client Industry
Retail

## Detailed Responsibilities
- Design, develop, and maintain interactive web applications using Vue.js and Bootstrap frameworks.
- Collaborate with UX/UI designers to translate designs into fully functional user interfaces.
- Implement server-side logic and integrate APIs to support dynamic data rendering and interactions.
- Optimize application performance for speed and responsiveness across a range of devices and browsers.
- Conduct unit testing and troubleshooting to ensure robust application functionality and user satisfaction.
- Actively participate in team meetings to discuss project requirements and provide technical guidance.
- Review code contributions from team members, fostering best practices and collective learning.
- Keep abreast of emerging technologies and suggest improvements to enhance development workflows.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related discipline.
- Minimum of 3 years experience developing applications using Vue.js.
- Extensive knowledge of Bootstrap for responsive design and layout structuring.
- Proficiency in JavaScript (Vuex), HTML5, and CSS3.
- Familiarity with RESTful services and microservices architecture.
- Experience with version control tools, particularly Git, and agile project management.
- Strong attention to detail, analytical skills, and the ability to work under tight deadlines.
- Excellent interpersonal skills and a willingness to collaborate effectively with diverse teams.

## Other Requirements
- Experience with state management in Vue.js (Vuex).
- Familiarity with testing tools such as Mocha or Cypress for frontend testing.
- Understanding of Web Accessibility Standards (WCAG) and best practices.
- Exposure to cloud services (Azure, AWS) and familiarity with CI/CD methodologies.
- Previous work experience in the retail sector or on e-commerce platforms is preferred.
