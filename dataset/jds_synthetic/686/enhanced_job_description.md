## Job Title
Frontend Engineer

## Location
Remote

## Client Industry
Ecommerce

## Detailed Responsibilities
- Build and enhance user-facing features for a dynamic online marketplace platform using modern JavaScript frameworks.
- Work closely with UI/UX designers to implement design prototypes and user-centric layouts.
- Develop reusable components and libraries to facilitate consistent user experience across the application.
- Conduct performance testing and optimization to ensure seamless user interaction.
- Collaborate with backend engineers to integrate with RESTful APIs and microservices architecture.
- Participate in sprint planning, code reviews, and continuous integration processes.
- Monitor application performance and resolve front-end issues swiftly.
- Keep abreast of emerging technologies and industry trends to innovate and improve development processes.

## Skill Requirements
- At least 4 years of experience in frontend development, specifically with JavaScript frameworks.
- Proficient in HTML, CSS, and JavaScript; experience with TypeScript is a plus.
- Strong understanding of responsive design principles and adaptable layout strategies.
- Familiar with state management libraries such as Redux or MobX.
- Experience working with GraphQL APIs for data fetching and manipulation.
- Knowledge of testing frameworks (e.g., Jest, Mocha) and methodologies.
- Familiarity with version control systems, particularly Git.
- Excellent analytical skills and attention to detail.

## Other Requirements
- Experience with Progressive Web Apps (PWAs) and service workers.
- Understanding of web accessibility standards and best practices.
- Strong collaboration and communication skills for effective teamwork.
- Ability to thrive in a fast-paced, agile environment.
