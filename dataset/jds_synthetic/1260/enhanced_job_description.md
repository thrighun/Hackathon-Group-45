## Job Title
Frontend Engineer (Vue.js & Bootstrap)

## Location
Remote

## Client Industry
Information Technology / Technology Solutions

## Detailed Responsibilities
- Develop and maintain responsive web applications using Vue.js and Bootstrap, ensuring optimal performance across devices.
- Work closely with product managers and designers to create user-friendly interfaces that enhance user experience.
- Implement responsive design principles to ensure applications function beautifully on any device or screen size.
- Conduct code reviews and assist team members in adhering to best practices in coding and design standards.
- Collaborate with backend developers to integrate APIs and enhance application functionality.
- Monitor and improve application performance through rigorous testing and user feedback.
- Engage in continuous learning to stay ahead of emerging trends in front-end development and share knowledge within the team.
- Document development processes, code structure, and application architecture for knowledge sharing.

## Skill Requirements
- Bachelor’s degree in Software Engineering, Web Development, or a related field, or equivalent practical experience.
- Solid experience with Vue.js and Bootstrap frameworks in building scalable web applications.
- Proficient in JavaScript (ES6+), HTML5, and CSS3, with an understanding of web accessibility standards.
- Familiarity with state management libraries (Vuex) and RESTful API integration.
- Experience using version control systems (Git) and participation in collaborative code development.
- Strong analytical skills, problem-solving ability, and attention to detail.
- Good interpersonal skills for effective teamwork and communication.

## Other Requirements
- Experience with TypeScript and CSS preprocessors (Sass, Less) is a bonus.
- Knowledge of DevOps practices and exposure to CI/CD tools.
- Familiarity with Agile methodologies and effective project management practices.
- A portfolio showcasing live projects or contributions to open-source codebases.
