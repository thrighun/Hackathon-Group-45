## Job Title
React Frontend Developer – Enterprise Solutions

## Location
Remote

## Client Industry
Information Technology / Software Development

## Detailed Responsibilities
- Design, develop, and implement high-quality web applications using React, ensuring adherence to best practices and coding standards.
- Work collaboratively with backend developers, data analysts, and stakeholders to gather and translate business requirements into interactive and user-friendly applications.
- Drive enterprise-level application development and integration, ensuring seamless interactions with external APIs, database systems, and microservices.
- Enhance application performance through code optimization, debugging, and ensuring compliance with web accessibility standards.
- Participate in and contribute to code reviews, providing mentorship and guidance to junior developers in alignment with team goals.
- Document application architectures, integration points, and coding best practices to facilitate knowledge sharing within the team.
- Engage in Agile methodologies, actively participating in sprints, backlog refinement, and team retrospectives for continuous improvement.

## Skill Requirements
- At least 5 years of hands-on experience in front-end development with a deep focus on React (including recent projects utilizing React 17 or higher).
- Proven expertise in enterprise-level application development and integration, with a solid understanding of RESTful services and API integrations.
- Proficient in JavaScript (ES6+), HTML5, CSS3, and experience with state management solutions (e.g., Redux, Context API).
- Familiarity with modern build tools and version control systems (e.g., Webpack, Git).
- Bachelor's degree in Computer Science, Software Engineering, or related field (or equivalent demonstrable experience).
- Excellent problem-solving abilities, strong analytical skills, and effective communication skills.

## Other Requirements
- Experience with cloud services (e.g., AWS, Azure) and container orchestration (e.g., Kubernetes).
- Knowledge of automated testing frameworks (e.g., Jest, Enzyme) and familiarity with test-driven development practices.
- Exposure to Agile project management tools such as JIRA and CI/CD methodologies.
- Previous experience in large-scale projects within multinational organizations is an advantage.
