- Design, build, and implement robust backend solutions and microservices with Java and Spring Boot.
- Collaborate with front-end developers to create user-friendly web applications utilizing React.
- Participate in the complete software development lifecycle, from gathering requirements to deployment and maintenance.
- Develop and integrate RESTful APIs while ensuring adherence to security standards.
- Manage application deployment in AWS, including configuration, performance monitoring, and scaling.
- Employ DataOps practices to improve data flow and delivery processes.
- Utilize strong debugging skills to troubleshoot and resolve issues in cloud-native applications.
