## Job Title
Java Microservices Developer – Machine Learning and Predictive Analytics

## Location
N/A

## Client Industry
Multinational Technology Solutions Provider (Information Technology/IT Services)

## Detailed Responsibilities
- Design, develop, and optimize scalable microservices using Java and the Spring framework.
- Collaborate with data scientists and machine learning engineers to build predictive analytics solutions that enhance business decision-making.
- Implement and manage NoSQL databases, particularly MongoDB, ensuring efficient data storage and retrieval.
- Focus on continuous integration and deployment (CI/CD) practices to streamline application delivery.
- Participate in technical design sessions, code reviews, and maintain high-quality documentation for the development process.
- Collaborate with cross-functional teams to gather requirements and ensure successful integration of machine learning models into production.
- Monitor system performance, troubleshoot issues, and provide support for deployed applications.
- Engage in agile development practices, participating in sprint planning, daily stand-ups, and retrospectives.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Software Engineering, or a related field.
- Proven experience developing microservices architectures using Java and the Spring framework.
- Strong proficiency in NoSQL databases, particularly MongoDB, and data management practices.
- Knowledge of machine learning concepts and experience with predictive analytics tools or libraries.
- Familiarity with RESTful API development and integration.
- Excellent analytical skills and a strong understanding of software development methodologies.
- Effective communication skills, capable of working in diverse team environments.

## Other Requirements
- Experience with cloud platforms (such as AWS, Azure, or Google Cloud) and containerization tools (like Docker or Kubernetes).
- Involvement in open-source projects or contributions to the Java development community.
- Relevant certifications in Java development, cloud technologies, or machine learning.
- Understanding of modern DevOps practices and tools for continuous delivery.
- Experience with front-end technologies for collaborating with UI/UX teams on integrated solutions.
