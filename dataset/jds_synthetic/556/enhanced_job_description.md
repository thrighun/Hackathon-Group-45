## Job Title
Data Engineer – Azure & Big Data

## Location
N/A

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Design, build, and maintain scalable data pipelines for big data ingestion, storage, and processing using Azure cloud technologies.
- Collaborate with data scientists and analysts to understand data requirements and ensure the availability of clean, high-quality datasets for analysis and machine learning initiatives.
- Implement ETL processes to extract, transform, and load data from diverse sources into Azure Data Lakes and other storage solutions.
- Optimize and manage data architecture to support the organization’s data strategy while ensuring compliance with data governance policies.
- Monitor and troubleshoot data workflows, implementing improvements to ensure efficiency and reliability.
- Stay updated with the latest trends in cloud data engineering and big data technologies, proposing enhancements to existing systems.

## Skill Requirements
- Proven experience in data engineering with a solid understanding of big data concepts and frameworks.
- Proficiency in Python for data manipulation and analytics, with experience in relevant libraries (e.g., Pandas, NumPy).
- Strong knowledge of Azure data services (e.g., Azure Data Lake Storage, Azure Databricks, Azure Synapse Analytics).
- Familiar with ETL tools and frameworks (e.g., Apache NiFi, Azure Data Factory) and data warehousing concepts.
- Experience with machine learning concepts and tools, particularly in relation to data preprocessing and feature engineering.
- Bachelor’s degree in Computer Science, Data Science, or a related field.
- Strong analytical and problem-solving skills, with the ability to work collaboratively within teams.

## Other Requirements
- Azure or relevant cloud certifications (e.g., Microsoft Certified: Azure Data Engineer Associate).
- Familiarity with distributed computing frameworks (e.g., Apache Spark, Hadoop).
- Understanding of data modeling, data governance, and compliance standards.
- Experience with version control systems (e.g., Git) for collaboration and code management.
