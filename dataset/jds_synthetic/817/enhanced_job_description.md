- Design and implement dynamic web applications utilizing Angular and TypeScript to enhance user engagement.
- Work closely with UX/UI designers to translate visual designs into responsive user interfaces.
- Optimize application performance by conducting thorough testing and refining existing code.
- Participate in Agile ceremonies, assisting in sprint planning and reviews to promote team collaboration.
- Contribute to the development of reusable components and libraries for future use across projects.
- Monitor and improve application security by following best practices and conducting regular audits.

- Skilled in using version control systems, particularly Git.
- Bachelor’s degree in Software Engineering, Computer Science, or a similar discipline.
- Strong analytical mindset with a keen eye for detail.

## Other Requirements
