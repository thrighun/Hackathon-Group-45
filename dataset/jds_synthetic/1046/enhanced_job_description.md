## Job Title
JavaScript Engineer

## Location
Remote available

## Client Industry
Technology

## Detailed Responsibilities
- Design, build, and maintain high-quality web applications using JavaScript and related frameworks (e.g., React, Vue.js).
- Collaborate with UX/UI designers and backend developers to implement user-friendly features and ensure seamless integration with backend services.
- Participate actively in Agile ceremonies, including sprint planning, daily stand-ups, and sprint retrospectives to achieve project goals.
- Write clean, maintainable code adhering to established coding standards and best practices in web development.
- Implement responsive design principles to optimize applications across various devices and platforms.
- Conduct code reviews and provide constructive feedback to peers to foster a culture of continuous improvement.
- Monitor application performance and troubleshoot issues to enhance user experience and application stability.

## Skill Requirements
- Proficient in JavaScript and experience with modern frontend frameworks (React, Angular, or Vue.js).
- Strong understanding of web development concepts, including HTML, CSS, and RESTful APIs.
- Familiarity with Agile development methodologies and tools (e.g., Jira, Trello).
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- 2+ years of experience in frontend development.
- Knowledge of version control systems (e.g., Git).
- Excellent problem-solving skills and an eye for detail.
- Strong communication skills and ability to work well in a team.

## Other Requirements
- Experience with state management libraries (e.g., Redux, Vuex) is a plus.
- Familiarity with testing frameworks (e.g., Jest, Mocha) for frontend applications.
- Exposure to cloud services and deployment practices for web applications.
- Knowledge of SEO best practices to enhance web visibility.
- Relevant certifications in JavaScript or agile development are advantageous.
