## Job Title
Full Stack Java Developer

## Location
Remote / On-Site Options Available

## Client Industry
Software Development Solutions

## Detailed Responsibilities
- Develop and maintain dynamic web applications using Java, Spring Boot, ReactJS, and Node.js.
- Collaborate with UX/UI designers and product managers to create a seamless and engaging user experience.
- Write clean, maintainable, and efficient code across the full technology stack.
- Conduct system testing and debugging to ensure high-performing and reliable applications.
- Participate in agile development methodologies, including sprint reviews and retrospectives.
- Continuously refactor code and optimize application performance using best practices.
- Research and implement new technologies that could enhance application performance and scalability.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related discipline.
- At least 4 years of experience in full stack development with Java and Spring Boot.
- Proficient in front-end frameworks, particularly ReactJS, with a strong understanding of responsive design principles.
- Experience with RESTful API development and integration.
- Familiar with database management systems such as MySQL or PostgreSQL.
- Knowledge of version control systems, preferably Git, including collaborative development practices.
- Strong analytical skills and the ability to troubleshoot complex issues.

## Other Requirements
- Experience with containerization technologies such as Docker and orchestration tools like Kubernetes.
- Familiarity with CI/CD pipelines and automated testing frameworks.
- Understanding of cloud solutions such as AWS or Google Cloud Platform.
