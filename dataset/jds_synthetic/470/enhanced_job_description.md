## Detailed Responsibilities
- Design and implement engaging user interfaces for web applications that deliver seamless user experiences.
- Collaborate closely with UX/UI designers and backend engineers to integrate user-facing elements with server-side logic.
- Optimize application for maximum speed and scalability while ensuring compliance with accessibility standards.
- Lead initiatives to improve overall product performance and maintainability through code refactoring and modular architecture.
- Support the development team in troubleshooting and resolving issues to enhance application reliability.
- Stay current with emerging technologies and frameworks to drive innovation within the team.
- Assist in mentoring junior engineers and interns, fostering a culture of knowledge sharing and continuous learning.

## Skill Requirements
- 2-6 years of experience in front-end development with a focus on React or similar technologies.
- Proficiency in JavaScript and TypeScript, with a solid understanding of modern development practices.
- Experience with state management libraries (such as Redux or MobX) and comprehensive knowledge of CSS preprocessors (like SASS or LESS).
- Familiarity with API integration and working with GraphQL.
- Strong understanding of testing frameworks (such as Jest or Mocha) and performance optimization techniques.
- Bachelor’s degree in Computer Science, Software Engineering, or a related discipline is preferred.

## Other Requirements
- Experience with responsive and adaptive design methodologies.
- Knowledge of version control using Git and familiarity with CI/CD practices.
- Excellent verbal and written communication skills, with a proactive and collaborative mindset.
- Understanding of Agile and Scrum methodologies to contribute effectively to the project lifecycle.
- Enthusiasm for learning and adapting to new technologies and best practices in web development.
