## Detailed Responsibilities
- Design, develop, and execute automated test scripts for both web and backend applications to improve efficiency and consistency in testing processes.
- Perform performance, load, and stress testing to ensure applications can handle expected user loads and function optimally under pressure.
- Collaborate closely with DevOps teams to integrate automated testing within the CI/CD pipeline, facilitating continuous testing and delivery.
- Analyze performance metrics using monitoring tools and provide actionable insights for application improvement to development teams.
- Participate actively in sprint planning and retrospectives to ensure alignment of quality assurance goals with project objectives.
- Create and maintain comprehensive documentation covering automated testing procedures, results, and refinement opportunities.
- Mentor junior QA staff, fostering skill development and adherence to best practices within the QA process.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- 3+ years of experience in software quality assurance, with a focus on test automation and performance testing.
- Strong knowledge of automation frameworks and tools (e.g., Selenium, JMeter, LoadRunner).
- Familiarity with various testing methodologies and software development lifecycle (SDLC) processes.
- Excellent problem-solving and analytical skills with attention to detail.
- Strong communication skills, both written and verbal, with the ability to work collaboratively in a team environment.
- Knowledge of programming languages relevant to test automation (e.g., Java, Python, JavaScript) is preferred.

## Other Requirements
- Experience with Agile/Scrum methodologies is a must.
- Understanding of cloud computing concepts and deployment models is an advantage.
- ISTQB or equivalent certification in software testing is a plus.
- Previous experience with monitoring and performance tools (e.g., New Relic, Grafana) is desirable.
