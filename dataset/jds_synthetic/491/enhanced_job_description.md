## Detailed Responsibilities
- Develop, maintain, and enhance the frontend and backend components of applications using Java and Spring framework in conjunction with React.js.
- Design and implement RESTful microservices that effectively communicate with various systems and services.
- Create and optimize SQL queries and data models in PostgreSQL for efficient data retrieval and storage.
- Utilize Azure cloud services for application hosting, scalability, and resource management.
- Establish and manage continuous integration and deployment (CI/CD) workflows utilizing Git for version control to promote rapid development cycles.
- Collaborate with UI/UX designers to ensure cohesive and user-friendly interfaces throughout the application.
- Conduct code reviews and provide mentorship to junior developers, fostering a culture of technical excellence.
- Engage in Agile/Scrum ceremonies to align project objectives and deliverables with team goals, adapting to changes as necessary.
- Monitor application performance and troubleshoot issues to ensure optimal uptime and reliability.
- Document technical specifications, user guides, and best practices to facilitate knowledge sharing within the team.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related technical field.
- Strong proficiency in Java development, with significant experience in Spring framework.
- Hands-on knowledge of frontend technologies, particularly React.js.
- Experience with relational databases, specifically PostgreSQL, and proficiency in crafting complex SQL statements.
- Familiarity with Azure cloud services and their deployment mechanisms.
- Understanding of microservices architecture and its best practices.
- Proficient in using Git for version control and collaboration.
- Solid problem-solving skills, with a keen eye for details and a proactive approach to challenges.
- Strong verbal and written communication abilities, facilitating effective teamwork.

## Other Requirements
