## Job Title
Front-End Software Engineer specializing in Vue.js

## Location
N/A

## Client Industry
Multinational Technology Provider

## Detailed Responsibilities
- Design and implement user-friendly web applications using Vue.js and Vuex frameworks.
- Collaborate closely with UX/UI designers to create visually appealing and highly interactive interfaces.
- Write modular, reusable, and high-quality code while following best practices and design patterns.
- Enhance application performance through code optimization and proactive monitoring of web application metrics.
- Participate in Agile ceremonies, including daily stand-ups, sprint planning, and retrospectives, to ensure team alignment and project progression.
- Engage in code reviews to promote knowledge sharing and uphold coding standards across the development team.
- Investigate and resolve performance issues through thorough debugging and comprehensive testing.

## Skill Requirements
- 2-6 years of experience in front-end development, particularly with Vue.js and Vuex frameworks.
- Proficient in JavaScript, HTML5, and CSS3, with a solid understanding of modern web technologies.
- Familiarity with component-based architecture and state management in large applications.
- Experience using Git for version control and collaboration.
- Knowledge of progressive web applications (PWAs) and their implementation.
- Strong analytical skills and attention to detail with a focus on user experience.
- Effective communication and teamwork skills to collaborate with cross-functional teams.

## Other Requirements
- Experience with additional front-end frameworks such as Angular or Svelte.
- Familiarity with TypeScript for type safety in JavaScript applications.
- Understanding of cloud services and deployment strategies, particularly with platforms like AWS or Azure.
- Basic knowledge of web accessibility (a11y) standards and best practices.
