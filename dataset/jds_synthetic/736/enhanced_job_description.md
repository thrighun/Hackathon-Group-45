## Job Title
Full Stack Developer specializing in Java and Node.js with strong DevOps capabilities

## Location
N/A

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Develop robust and scalable web applications using Java and Node.js, ensuring a seamless integration between frontend and backend systems.
- Collaborate with cross-functional teams, including designers and product managers, to create user-friendly interfaces and innovative solutions that meet customer needs.
- Lead the architecture design and implementation of microservices-based applications, enhancing modularity and maintainability.
- Employ DevOps practices to automate deployment processes, streamline CI/CD pipelines, and improve system reliability.
- Write clean, modular, and testable code while actively participating in code reviews to ensure quality and adherence to best practices.
- Monitor application performance and implement optimizations to enhance speed and responsiveness, using tools like New Relic or Grafana.
- Gather and analyze user feedback to continuously iterate on product features and functionality.
- Stay updated with emerging technologies, integrating new tools and best practices that align with the organizational goals.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related discipline.
- Minimum 4 years of experience in full-stack development, with a focus on Java and Node.js frameworks (e.g., Spring Boot for Java and Express for Node.js).
- Proficient in frontend technologies including HTML5, CSS3, and JavaScript frameworks (e.g., Angular, React).
- Strong understanding of database technologies, particularly NoSQL databases (e.g., MongoDB, Cassandra).
- Experience with cloud platforms like AWS or Azure and familiarity with container orchestration tools (e.g., Kubernetes).
- Knowledge of infrastructure as code tools such as Terraform or CloudFormation.
- Excellent analytical and troubleshooting skills, with a proactive approach to problem-solving.
- Strong communication skills, capable of working within an Agile team environment.

## Other Requirements
- Experience implementing CI/CD processes and using tools such as Jenkins or GitLab CI.
- Familiarity with test automation frameworks and practices, particularly for functional and unit testing.
- Previous experience working in startups or dynamic tech environments.
- Advanced certifications in relevant technologies (e.g., AWS Certified Developer or similar) are a plus.
- Exposure to data visualization tools (e.g., Tableau, Power BI) is an advantage.
