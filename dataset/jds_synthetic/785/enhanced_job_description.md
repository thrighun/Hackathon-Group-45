## Job Title
Data Engineer – Cloud Operations & AI Analytics

## Location
Remote/Hybrid Options Available

## Client Industry
Information Technology & Services (Multinational Data Solutions)

## Detailed Responsibilities
- Construct and optimize data pipelines for AI analytics projects utilizing Python and cloud technologies.
- Implement data storage solutions on cloud platforms (AWS, Azure, or Google Cloud) to ensure efficient data retrieval and processing.
- Collaborate with data scientists and ML engineers to facilitate model training and deployment using large datasets.
- Design and manage ETL (Extract, Transform, Load) processes to integrate data from various sources effectively.
- Monitor and troubleshoot data workflows, ensuring data integrity and system performance.
- Develop comprehensive documentation for data workflows, data models, and API integrations.
- Maintain best practices in data governance, ensuring compliance with data privacy standards and regulations.
- Engage in code reviews and knowledge-sharing sessions to enhance team capabilities and project outcomes.
- Actively research and implement emerging technologies and methodologies to improve data engineering processes.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Data Science, or a related field.
- Strong experience with Python for data manipulation and analysis, with a focus on cloud-based solutions.
- Proficiency in SQL and experience with NoSQL databases for diverse data handling.
- Familiarity with cloud services related to data storage and processing (e.g., AWS S3, Azure Blob Storage).
- Understanding of data modeling concepts and frameworks for AI/ML applications.
- Experience with data orchestration tools (e.g., Apache Airflow, Prefect) and data versioning tools.
- Knowledge of containerization and orchestration (e.g., Docker, Kubernetes) for scalable data solutions.
- Excellent problem-solving abilities, attention to detail, and strong communication skills.

## Other Requirements
- Experience with big data technologies (e.g., Hadoop, Spark) is a plus.
- Knowledge of data quality assessment tools and techniques.
- Familiarity with DevOps practices and CI/CD pipelines for data solutions.
- Relevant cloud certifications (e.g., AWS Certified Data Analytics, Google Professional Data Engineer) are advantageous.
- Experience working in Agile development environments.
