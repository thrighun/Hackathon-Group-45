## Job Title
Frontend Developer with Angular and Bootstrap

## Location
Remote

## Client Industry
Technology Services

## Detailed Responsibilities
- Design and implement user-friendly web interfaces using Angular and Bootstrap.
- Collaborate closely with UX/UI designers and backend developers to create seamless web experiences.
- Optimize applications for speed and scalability across various devices and platforms.
- Write robust, maintainable code and utilize version control for tracking improvements.
- Conduct user testing and gather feedback to refine application performance and usability.
- Participate in sprint planning and agile ceremonies to ensure effective project delivery.
- Continuously research and integrate new technologies to enhance the development process.

## Skill Requirements
- Minimum of 4 years of experience in frontend development, specifically with Angular.
- Proficiency in Bootstrap for responsive design implementation.
- Strong knowledge of JavaScript, HTML5, and CSS3.
- Experience working with REST APIs and integrating third-party services.
- Familiarity with build tools and task runners such as Webpack or Gulp.
- Knowledge of Git for version control and collaboration.
- Strong analytical skills and a detail-oriented mindset.
- Excellent communication skills and ability to work in a team environment.

## Other Requirements
- Experience with Progressive Web Applications (PWAs) is a plus.
- Understanding of Agile development methodologies and tools like JIRA.
- Familiarity with testing frameworks such as Jasmine or Protractor.
- Basic knowledge of accessibility standards and practices in web development.
