## Job Title
Software Engineer - Java Backend

## Location
N/A

## Client Industry
Technology

## Detailed Responsibilities
- Design, build, and maintain high-performance backend systems using Java and Spring Boot, focusing on reliability and scalability.
- Collaborate with UI/UX designers and front-end developers to implement seamless user experiences through efficient backend systems.
- Write modular, well-structured, and documented Java code that adheres to the best software development practices.
- Create and manage RESTful APIs for efficient communication between the server and client applications, demonstrating successful project implementations.
- Integrate machine learning models and AI services into backend solutions to enhance functionalities and provide advanced features.
- Conduct comprehensive unit and integration testing to uphold software quality, reliability, and performance benchmarks.
- Identify, debug, and resolve issues in existing applications, ensuring minimal downtime and optimal performance.
- Participate actively in code reviews and share insights to promote knowledge sharing within the engineering team.
- Document back-end services architecture, API specifications, workflows, and system integrations clearly to facilitate future development and maintenance.
- Keep abreast of emerging Java frameworks, tools, and industry developments to drive continuous improvement and innovation in backend systems.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- 3-5 years of experience in backend development with Java, specifically using Spring Boot.
- Strong background in creating and managing RESTful APIs with practical implementation experience.
- Proficient in using version control systems such as Git for collaborative development.
- Solid understanding of relational databases (like MySQL, PostgreSQL) and experience with data modeling and optimization.
- Familiar with agile development methodologies and project management tools.
- Experience with incorporating machine learning or AI capabilities into software applications.
- Excellent analytical and problem-solving skills, especially in troubleshooting complex backend issues.
- Strong communication skills, with an emphasis on teamwork and collaboration.

## Other Requirements
- Knowledge of container orchestration tools like Kubernetes and experience with Docker for application deployment.
- Familiarity with cloud services such as AWS, Google Cloud, or Azure for backend service hosting and management.
- Experience with CI/CD tools to automate testing and deployment processes.
- Involvement in developer communities or contributions to open-source projects to showcase engagement with the tech ecosystem.
