## Job Title
Cloud Software Engineer – Node.js & Angular

## Location
Remote

## Client Industry
Technology

## Detailed Responsibilities
- Develop, deploy, and manage scalable cloud-native applications using Node.js and Angular frameworks.
- Collaborate with cross-functional teams to define, design, and deliver innovative software solutions tailored to client needs.
- Optimize application performance and ensure high availability and responsiveness of cloud platforms.
- Write and maintain clean, efficient, and well-structured code, adhering to software development best practices.
- Participate in code reviews, contributing to continuous improvement of engineering standards and practices.
- Implement automated testing and monitoring strategies to enhance application reliability and performance.
- Engage with clients and stakeholders to gather requirements and provide technical guidance throughout the development lifecycle.
- Stay current with emerging cloud technologies and propose enhancements to improve system performance and user experience.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or related field.
- Minimum of 3 years of experience in cloud-based application development using Node.js.
- Proficiency in Angular for building dynamic front-end applications.
- Strong understanding of cloud services (e.g., AWS, Azure, Google Cloud) and microservices architecture.
- Experience with Docker and Kubernetes for container orchestration and deployment.
- Familiarity with RESTful APIs and integration of third-party services.
- Excellent analytical and problem-solving abilities with attention to detail.
- Strong communication skills, both verbal and written, for effective team collaboration.

## Other Requirements
- Experience with CI/CD tools and methodologies for streamlined software delivery.
- Knowledge of security best practices in cloud application development.
- Familiarity with Agile development methodologies and tools like Jira or Trello.
- Certification in cloud technologies (AWS Certified Developer or similar) is a plus.
- Previous experience in sectors like e-commerce or SaaS applications is preferred.
