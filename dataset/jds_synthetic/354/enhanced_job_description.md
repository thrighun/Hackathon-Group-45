## Job Title
Node.js Backend Engineer

## Location
Remote/Hybrid

## Client Industry
Information Technology Services / Technology Solutions

## Detailed Responsibilities
- Develop and maintain robust backend services and APIs using Node.js and associated frameworks.
- Work in tandem with front-end developers and UX/UI designers to create seamless user experiences.
- Write high-quality, efficient, and maintainable code following industry best practices and design patterns.
- Monitor and optimize server-side application performance, including debugging and resolving production issues.
- Engage in peer code reviews, contribute to system architecture discussions, and guide junior developers.
- Implement third-party services and integrations as required to meet project specifications.
- Enforce security protocols by conducting routine code audits and implementing secure coding methodologies.
- Remain current with emerging technologies in backend development, suggesting improvements and innovations for the tech stack.

## Skill Requirements
- Bachelor’s degree in Software Engineering, Computer Science, or a related discipline.
- A minimum of 3 years of experience in backend development, specifically with Node.js.
- Deep understanding of frameworks such as Express.js or Hapi.js.
- Expertise in designing and developing RESTful APIs and microservices.
- Familiarity with databases such as MySQL, MongoDB, or DynamoDB.
- Proficient in version control systems, particularly Git.
- Knowledge of cloud services and containerization technologies (e.g., AWS, Docker).
- Strong analytical and troubleshooting capabilities.
- Ability to communicate effectively within a diverse team environment.

## Other Requirements
- Experience with CI/CD tools and automated deployment processes.
- Knowledge of serverless architecture and asynchronous programming.
- Familiarity with Agile development processes and tracking tools like Jira.
- Relevant certifications in Node.js or cloud infrastructure are advantageous.
