## Job Title
Embedded Software Engineer - Python & Linux

## Location
Hyderabad or Secunderabad

## Client Industry
Technology

## Detailed Responsibilities
- Design, develop, and optimize embedded software applications using Python programming language and Linux operating systems.
- Collaborate with cross-functional teams, including product managers and quality assurance, to define software requirements and design specifications.
- Develop and implement system architectures for embedded solutions, ensuring scalability and reliability.
- Conduct thorough testing and validation of software applications to ensure functionality and performance compliance.
- Optimize code for performance and resource management, particularly in low-power environments.
- Maintain comprehensive documentation of design processes, code changes, and deployment strategies.
- Actively participate in code reviews, providing constructive feedback to peers and promoting best practices in software development.

## Skill Requirements
- Bachelor's degree in Computer Science, Electronics Engineering, or a related field.
- 4-6 years of experience in embedded software development, particularly with Python and Linux.
- Strong knowledge of embedded system architecture and design principles.
- Familiarity with hardware interfaces, protocols (SPI, I2C, UART), and debugging tools.
- Excellent analytical and troubleshooting skills to diagnose software issues.
- Ability to work effectively within a team setup and engage with stakeholders to achieve project goals.

## Other Requirements
- Experience with version control systems such as Git or SVN.
- Knowledge of continuous integration/continuous deployment (CI/CD) practices.
- Familiarity with Agile or Scrum methodologies.
- Relevant certifications in embedded systems or software development are a plus.
