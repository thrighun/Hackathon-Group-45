## Job Title
Java Frontend Developer

## Location
N/A

## Client Industry
Information Technology / Cloud-Based Application Solutions

## Detailed Responsibilities
- Design and implement user-friendly interfaces for web applications using Java and React frameworks.
- Collaborate with UI/UX designers and backend developers to create seamless, responsive, and high-performance user experiences.
- Develop and maintain microservices architecture to enable scalable and efficient application functionalities.
- Integrate advanced machine learning algorithms and services to enhance user interactions and data processing.
- Deploy and manage application solutions on Amazon Web Services (AWS), adhering to best practices for security and performance.
- Write clean, efficient, and well-documented code, following industry standards and agile development methodologies.
- Participate in regular code reviews, unit testing, and debugging to maintain code quality and application integrity.
- Stay current with emerging trends in frontend technologies and machine learning to drive innovation in development practices.
- Collaborate with DevOps and QA teams to implement continuous integration/continuous deployment (CI/CD) processes for improved software delivery.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Software Engineering, or a related field.
- Proven experience (3+ years) in frontend development using Java and React frameworks.
- Strong understanding of microservices architecture and experience developing in a cloud environment, specifically AWS.
- Familiarity with machine learning concepts and their application in web development.
- Solid experience with RESTful APIs and client-server architecture.
- Strong analytical and problem-solving skills, with an emphasis on attention to detail and quality.

## Other Requirements
- Experience with containerization tools (Docker) and orchestration platforms (Kubernetes) is a plus.
- Prior involvement in CI/CD pipeline implementation and automated testing frameworks.
- Knowledge of additional cloud services (Azure, GCP) or familiarity with hybrid cloud solutions.
- Excellent communication skills with a focus on teamwork and collaboration.
