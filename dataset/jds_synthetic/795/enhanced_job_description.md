- Design and implement advanced machine learning architectures for complex predictive tasks and analytics.
- Oversee the construction and management of datasets for training and testing machine learning models.
- Architect, deploy, and scale machine learning models into production environments.
- Research emerging trends and technologies in machine learning to advance our capabilities.
- Perform model optimization and tuning for improved performance and scalability.
- Collaborate effectively with stakeholders to gather requirements and provide insights on machine learning solutions.

- Bachelor’s or Master’s degree in Computer Science, Data Science, or a related field.
- 5+ years of experience in machine learning, data modeling, or predictive analytics.
- Demonstrated expertise in deploying machine learning models within cloud environments such as AWS or Google Cloud.
- Strong programming skills in Python, R, or Java, and experience with frameworks like TensorFlow or Scikit-learn.
- Knowledge of performance tuning techniques for machine learning models.
- Experience with data preprocessing, feature engineering, and model validation methods.
- Familiarity with containerization tools like Docker and orchestration platforms like Kubernetes.
