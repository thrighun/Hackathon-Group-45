## Job Title
Software Engineer – API Development & Frontend Technologies

## Location
Remote

## Client Industry
Technology

## Detailed Responsibilities
- Design and implement RESTful and GraphQL API services for high-performance applications to support frontend functionality.
- Develop dynamic and interactive web applications using Angular, ensuring responsiveness and a high-quality user interface.
- Collaborate closely with backend developers to integrate APIs seamlessly with database and microservice architectures.
- Write clean and maintainable code in TypeScript and JavaScript, adhering to industry best practices and standards.
- Conduct code reviews and maintain a high standard of software quality through unit testing and integration testing.
- Participate in Agile methodologies, working within cross-functional teams to deliver software products iteratively.
- Monitor and troubleshoot application performance and user feedback to recommend enhancements and optimizations.
- Stay current with industry trends and emerging technologies to continuously improve technical skills and team capabilities.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or related field.
- Minimum of 3 years of professional experience in developing APIs and web applications.
- Strong expertise in Angular for frontend development and proficiency in Node.js for backend services.
- Familiarity with relational databases, particularly PostgreSQL, and experience with microservices architecture.
- Knowledge of containerization tools such as Docker, and experience with version control systems like Git.
- Strong analytical and problem-solving abilities, with a focus on delivering high-quality software solutions.
- Excellent communication skills, capable of working collaboratively with diverse teams.

## Other Requirements
- Experience with cloud services (e.g., AWS, Azure) and CI/CD pipelines is preferred.
- Familiarity with automated testing frameworks and performance tuning is a plus.
- Certification or training in any API development technologies or cloud platforms is advantageous.
- Background in industries such as e-commerce or SaaS is desirable.
