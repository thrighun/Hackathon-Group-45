- Design and implement high-performance, scalable applications using Java and the Spring Boot framework.
- Develop responsive user interfaces using React, ensuring a seamless and intuitive user experience.
- Design, implement, and maintain RESTful APIs and microservices architecture to support application functionality.
- Collaborate closely with product management and UX/UI designers to translate business requirements into technical specifications.
- Manage AWS services, including EC2, S3, Lambda, and RDS, to facilitate application deployment and infrastructure management.
- Ensure the application adheres to security standards and best practices for data protection.
- Participate in code reviews, unit testing, and troubleshooting to maintain high code quality and performance.
- Stay updated with industry trends and emerging technologies to continuously enhance development processes and application robustness.
- Demonstrate strong analytical skills for performance tuning and optimization of applications.
