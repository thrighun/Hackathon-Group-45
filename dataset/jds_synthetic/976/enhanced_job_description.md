## Job Title
Embedded Software Engineer (Python & C++)

## Location
N/A

## Client Industry
Consumer Electronics / Smart Home Technology

## Detailed Responsibilities
- Develop and implement embedded software solutions using Python and C++ for smart home devices and applications.
- Collaborate with UI/UX designers to ensure software is user-friendly and meets design specifications.
- Enhance and optimize existing software code to improve performance and maintainability across different devices.
- Participate actively in the full software development lifecycle, including requirements gathering, design, testing, and deployment.
- Work closely with cross-disciplinary teams, including hardware engineers, to ensure smooth integration of software with various sensor and actuator systems.
- Maintain thorough documentation of software development processes, code, and designs to comply with industry standards.
- Engage in peer code reviews, unit testing, and troubleshooting to uphold high software quality.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or equivalent experience.
- A minimum of 3 years of experience in embedded software development with a strong background in both Python and C++ programming.
- Proficient understanding of the embedded software development lifecycle and familiarity with hardware-software interactions.
- Experience with development tools and version control systems (e.g., Git, JIRA).
- Knowledge of communication protocols (e.g., MQTT, Zigbee, Bluetooth) and microcontroller design.
- Strong analytical and problem-solving abilities with great attention to detail.

## Other Requirements
- Experience with IoT protocols and smart home ecosystems is a plus.
- Familiarity with Agile development methodologies and CI/CD practices.
- Knowledge of security best practices for embedded systems is advantageous.
- Excellent communication skills and ability to work effectively in a collaborative environment.
