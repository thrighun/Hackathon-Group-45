## Detailed Responsibilities
- Design and implement dynamic web applications using Vue.js or Angular.
- Ensure high performance and responsive design across various web-enabled devices and browsers.
- Collaborate with product managers and designers to align technical feasibility with user interface designs.
- Troubleshoot and debug existing web applications, enhancing functionality and user experience.
- Contribute to the development of coding standards and best practices across the engineering team.
- Mentor junior team members and provide constructive feedback during code reviews.

## Skill Requirements
- Strong expertise in JavaScript frameworks such as Vue.js or Angular.
- Extensive knowledge of HTML5, CSS3, and responsive design principles.
- Familiarity with state management libraries (e.g., Vuex for Vue.js or NgRx for Angular).
- Experience with RESTful APIs and integrating front-end components with server-side logic.
- Understanding modern front-end build tools and version control systems such as Git.
- Ability to analyze user requirements and translate them into technical specifications.

## Other Requirements
- Previous experience working in an Agile/Scrum development environment.
- Strong communication skills and ability to work collaboratively in a team.
- A degree in Computer Science, Software Engineering, or a related field is preferred, but relevant professional experience is also valued.
