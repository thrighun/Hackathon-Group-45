## Detailed Responsibilities
- Design, develop, and maintain server-side applications using Node.js and Express.js.
- Collaborate with front-end developers to integrate user-facing elements with server-side logic.
- Create and manage databases using MongoDB or PostgreSQL to support application functionality.
- Ensure the performance, quality, and responsiveness of applications while troubleshooting issues.
- Participate in code reviews and maintain best practices in software development.
- Work closely with product managers and stakeholders to gather requirements and provide feedback on feasibility.

## Skill Requirements
- Minimum of 4 years of professional experience in full stack development using JavaScript.
- Strong proficiency in Node.js and Express.js, along with knowledge of RESTful API design.
- Experience with front-end frameworks such as React or Angular.
- Familiarity with database management systems like MongoDB or SQL databases.
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- Solid understanding of asynchronous programming and its quirks.

## Other Requirements
- Experience in implementing security measures for web applications.
- Knowledge of cloud services (AWS, Azure) and deploying applications in cloud environments.
- Familiarity with version control systems such as Git and CI/CD practices.
- Excellent communication skills and the ability to work within a team-oriented, collaborative environment.
