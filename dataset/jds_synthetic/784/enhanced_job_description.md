## Job Title
Lead Software Engineer - Java Solutions

## Location
Remote/On-Site

## Client Industry
Information Technology / Software Development

## Detailed Responsibilities
- Architect, develop, and implement cloud-native applications utilizing Java and Spring Cloud for optimal performance and scalability.
- Oversee the design and implementation of RESTful APIs, ensuring they are robust and secure.
- Collaborate closely with product owners, UX designers, and DevOps teams to innovate and improve product functionality.
- Mentor and guide a team of developers, fostering an environment of continuous learning and improvement.
- Drive best practices in software development, including code reviews, unit testing, and documentation.
- Analyze system performance and troubleshoot complex issues to enhance application reliability and user experience.
- Stay abreast of industry trends and contribute to strategic planning for future technology implementations.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- 7+ years of experience in software development with a strong focus on Java and cloud technologies.
- In-depth knowledge of Spring Cloud and Java EE frameworks.
- Experience in designing scalable APIs and microservices architectures.
- Proficient with cloud platforms (AWS, Azure) and familiar with serverless architectures.
- Strong understanding of Agile methodologies and experience in Agile team environments.
- Excellent communication skills and the ability to work in a collaborative team atmosphere.

## Other Requirements
- Familiarity with container orchestration tools like Kubernetes and Docker.
- Knowledge of CI/CD tools and DevOps practices.
- Experience with NoSQL databases such as MongoDB or Cassandra is advantageous.
- Previous leadership experience or a track record of coordinating project teams is preferred.
- Relevant certifications in Java or cloud technologies are a plus.
