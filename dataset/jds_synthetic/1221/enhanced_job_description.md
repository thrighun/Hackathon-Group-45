## Job Title
Data Engineer

## Location
N/A

## Client Industry
Multinational Technology Services and Consulting

## Detailed Responsibilities
- Design, build, and maintain scalable data pipelines that support data integration and transformation processes using Python and Apache Spark.
- Develop and optimize ETL processes to ingest and prepare data from various sources into centralized data warehousing solutions.
- Implement complex SQL queries and data models to ensure efficient data retrieval and reporting.
- Leverage AWS services for data processing, storage, and analytics to enhance the availability and reliability of data solutions.
- Utilize Apache Airflow for scheduling and orchestrating data workflows to ensure timely delivery of data to stakeholders.
- Collaborate with data scientists, analysts, and business teams to understand data requirements and provide quality data solutions.
- Create and maintain documentation of data workflows, data lineage, and architecture diagrams to ensure clarity and compliance.
- Perform data quality checks and troubleshoot ETL jobs to maintain high data integrity across the organization.
- Participate in code reviews and collaborate on best practices for data engineering within the team.

## Skill Requirements
- Bachelor’s degree in Computer Science, Data Science, or a related field.
- Proven experience in data engineering roles with strong proficiency in Python and Apache Spark.
- Comprehensive knowledge of SQL and experience with data warehousing concepts.
- Familiarity with AWS data services such as Redshift, S3, and Glue.
- Experience with ETL tools and technologies, particularly Apache Airflow.
- Proficient in version control using GitHub for collaboration and code management.
- Strong analytical skills and attention to detail with a focus on data quality.
- Excellent communication skills to work effectively with cross-functional teams.

## Other Requirements
- Experience with data visualization tools, such as Tableau or Power BI.
- Familiarity with NoSQL databases and big data technologies.
- Understanding of Agile methodologies and experience working in Agile teams.
- Relevant certifications in data engineering, cloud technologies, or data analysis.
