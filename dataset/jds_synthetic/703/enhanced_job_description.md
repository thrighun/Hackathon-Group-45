## Detailed Responsibilities
- Develop and maintain web applications using Java, Spring, and modern JavaScript frameworks such as React or Angular.
- Collaborate with UI/UX designers to create intuitive, user-friendly interfaces that enhance user experience.
- Design and implement RESTful APIs to connect the front-end and back-end systems efficiently.
- Ensure high performance and responsiveness of applications through optimization techniques.
- Troubleshoot, debug, and resolve issues to maintain a high-quality product.
- Engage in daily stand-ups and sprint planning sessions as part of an agile development team.
- Mentor and guide junior developers, fostering a collaborative coding culture through code reviews and best practices.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- Minimum of 3 years of experience in full stack development, with strong proficiency in Java and Spring Framework.
- Experience with front-end technologies, including JavaScript frameworks like React or Angular.
- Understanding of RESTful services and API development practices.
- Familiarity with database management systems (e.g., MySQL, PostgreSQL).
- Excellent analytical and problem-solving skills coupled with attention to detail.
- Strong verbal and written communication skills for effective collaboration.

## Other Requirements
- Familiarity with DevOps practices, including CI/CD pipelines.
- Experience with cloud services such as AWS, Google Cloud, or Azure preferred.
- Knowledge of version control systems, specifically Git.
- Understanding of agile methodologies and tools (e.g., JIRA, Trello).
