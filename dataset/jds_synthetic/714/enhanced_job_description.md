## Job Title
Senior Front-End Developer (Vue.js & Vuetify UI)

## Location
Remote

## Client Industry
Technology

## Detailed Responsibilities
- Lead the development of user-centric web applications using Vue.js and Vuetify UI, ensuring a high level of usability and performance.
- Collaborate with cross-functional teams, including product management and backend development, to define project requirements and deliver solutions.
- Maintain and optimize existing applications for performance improvements and user engagement.
- Implement and enforce coding standards, best practices, and design patterns among the development team.
- Proactively identify and resolve technical issues, providing innovative solutions to enhance application reliability.
- Create and update technical documentation for software features and application architecture.
- Mentor junior developers, fostering a culture of continuous learning and knowledge sharing.
- Participate in Agile/Scrum meetings, engaging in discussions on project updates and timelines.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- 5+ years of professional experience in front-end development, specifically with Vue.js.
- Strong experience with Vuetify UI and the creation of reusable UI components.
- Proficient in JavaScript (ES6+), HTML5, CSS3, and modern front-end build tools (e.g., Webpack).
- Familiarity with API integration and state management techniques (e.g., Vuex).
- Experience using Git and managing version control in a collaborative development environment.
- Solid understanding of responsive design principles and mobile-first development.
- Strong analytical skills and attention to detail.

## Other Requirements
- Familiarity with testing frameworks such as Mocha, Chai, or Jest.
- Experience with server-side rendering and progressive web applications (PWAs).
- Exposure to cloud services (e.g., AWS, Azure) and understanding of serverless architecture.
- Knowledge of Agile methodologies and tools (e.g., Jira, Trello).
- Previous experience working in an international team setting is a plus.
