## Job Title
Embedded Systems Software Engineer for IoT

## Location
Remote/On-site options available

## Client Industry
Internet of Things (IoT) Solutions Provider

## Detailed Responsibilities
- Develop and implement software solutions for embedded systems within IoT devices using C and C++.
- Collaborate with hardware engineers to design and optimize integrated systems for performance and efficiency.
- Conduct system validation and testing to ensure reliability and functionality of IoT applications.
- Participate in design sprints and agile development cycles to deliver innovative IoT features.
- Create comprehensive documentation for software architecture, interfaces, and user guides.
- Provide mentorship to junior engineers and facilitate knowledge-sharing sessions.
- Troubleshoot and resolve technical issues related to embedded software in IoT environments.

## Skill Requirements
- Bachelor’s degree in Computer Engineering, Software Engineering, or a closely related field.
- 3-6 years of experience in embedded programming with C and C++.
- Proficient in developing software for microcontrollers and familiarity with IoT communication protocols (MQTT, CoAP).
- Strong understanding of low-level system programming and hardware interfacing.
- Experience in agile methodologies and version control systems, specifically Git.
- Excellent analytical and debugging skills, with a proven track record of problem-solving in embedded contexts.

## Other Requirements
- Knowledge of cloud platforms and IoT ecosystems, such as AWS IoT or Azure IoT Hub.
- Familiarity with machine learning algorithms as applied to IoT data.
- Understanding of security principles related to embedded systems and IoT devices.
- Experience with continuous integration and deployment (CI/CD) processes.
