## Job Title
Java AI Solutions Architect / Data Integration Specialist

## Location
Remote

## Client Industry
Technology

## Detailed Responsibilities
- Architect and design advanced data integration solutions to support AI and machine learning initiatives using Java and related technologies.
- Collaborate with data engineers and machine learning teams to ensure seamless data flow and accessibility for model training and inference.
- Analyze and refine existing AI systems, making recommendations for enhancement through improved data management and integration processes.
- Implement robust data pipelines for real-time data ingestion and processing, ensuring data quality and integrity for machine learning applications.
- Provide technical guidance and mentorship to team members on Java best practices and AI integration techniques.
- Stay updated with the latest trends in AI and data technologies, incorporating best practices into project work.
- Document architectures, integration points, and workflows for current and future reference.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Software Engineering, or a related field.
- Strong proficiency in Java and experience with frameworks such as Spring and Hibernate.
- Understanding of data integration tools and ETL processes, particularly in the context of AI.
- Familiarity with cloud services like AWS, Azure, or Google Cloud for data storage and processing.
- Excellent analytical and problem-solving skills with a focus on effective collaboration across multi-disciplinary teams.
- In-depth knowledge of database systems (SQL and NoSQL) and their application in AI solutions.

## Other Requirements
- Prior experience with big data technologies such as Hadoop or Spark is preferred.
- Knowledge of data governance and compliance issues related to AI deployments.
- Experience working in Agile development environments will be an advantage.
