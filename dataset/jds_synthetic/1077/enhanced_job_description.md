## Detailed Responsibilities
- Collaborate with cross-functional teams to define project requirements and develop innovative full-stack applications.
- Build and scale web applications with a focus on performance optimization and user experience.
- Develop server-side functionality using Node.js and Express.js, and design rich user interfaces with React.
- Create and manage secure RESTful APIs, implementing best practices for API security.
- Deploy applications on AWS, managing resources and ensuring security protocols are consistently applied.
- Utilize Agile methodologies to drive efficient project development and continuous integration/continuous deployment (CI/CD).
- Ensure mobile-first design principles are incorporated into all applications for enhanced user accessibility.
- Troubleshoot and resolve complex technical issues across various environments and platforms.

## Skill Requirements
- Proficient in Node.js, Express.js, and React for full-stack application development.
- Extensive experience in creating and managing RESTful APIs with a focus on security.
- Strong knowledge of AWS services, particularly Lambda, for serverless architecture.
- Familiarity with MongoDB for data storage solutions.
- Understanding of Agile methodologies and CI/CD practices.
- Solid grasp of responsive design and mobile-first web development principles.
- Proven troubleshooting skills in diverse technology environments.

## Other Requirements

- Experience with Git for version control and collaboration.
- Familiarity with other front-end frameworks or libraries (e.g., Vue.js, Svelte).
