## Detailed Responsibilities
- Design, implement, and optimize ETL processes that load data from various sources into data lakes and warehouses.
- Collaborate with data analysts and scientists to define data requirements and ensure the delivery of accurate and consistent datasets.
- Perform data quality assessments and rectify any discrepancies, ensuring data integrity throughout the processing pipeline.
- Develop and maintain documentation for data models, architectures, and workflows to facilitate knowledge sharing and compliance.
- Monitor and troubleshoot data pipeline performance, implementing improvements for increased efficiency and reduced latency.
- Stay informed about new data technologies and methodologies, recommending best practices for data engineering.

## Skill Requirements
- Proven experience as a Data Engineer or in a related field with a strong understanding of data lifecycle management.
- Proficient in programming languages such as Python or Scala, alongside advanced SQL skills for data manipulation and querying.
- Familiarity with data warehousing concepts and technologies, including experience with ETL tools.
- Strong experience with cloud data solutions, particularly AWS or Google Cloud, for scalable data storage and processing.
- Excellent analytical and quantitative skills, combined with a detail-oriented mindset.

## Other Requirements
- Prior experience with data visualization tools like Tableau or Power BI for communicating insights.
- Knowledge of big data technologies such as Apache Spark or Kafka for real-time data streaming and processing.
- Understanding of data governance, security practices, and compliance requirements relevant to data management.
- Relevant certifications in Data Engineering, Cloud Computing, or related technologies are a plus.
