## Detailed Responsibilities
- Design and develop responsive web applications using React, ensuring a seamless user interface and experience.
- Build and maintain backend services and RESTful APIs using Node.js, with a focus on security and performance optimization.
- Collaborate closely with UX/UI designers to implement visually appealing and user-centric designs.
- Work within an Agile environment, participating in sprint planning, daily stand-ups, and retrospectives to drive team collaboration and project efficiency.
- Conduct thorough code reviews and unit testing to ensure adherence to software quality standards.
- Monitor application performance and troubleshoot issues, providing timely resolutions to enhance user satisfaction.

## Skill Requirements
- Proficient in React and its core principles, with experience in building and deploying single-page applications.
- Strong knowledge of Node.js and Express framework for backend development, including API design and implementation.
- Experience with cloud computing platforms (e.g., AWS, Azure, Google Cloud) for deploying and managing applications.
- Familiarity with relational databases such as PostgreSQL, including schema design and optimization techniques.
- Understanding of RESTful services, with ability to design and develop APIs that support client-server architecture.

## Other Requirements
- Minimum 5 years of software development experience, with at least 2 years in full-stack development roles.
- Bachelor’s degree in Computer Science, Engineering, or a related field is preferred.
- Knowledge of DevOps practices, CI/CD pipelines, and containerization technologies such as Docker is a plus.
- Strong analytical and problem-solving skills, with the ability to work effectively under pressure and meet deadlines.
- Excellent communication skills, with a knack for collaborating and building relationships across teams.
