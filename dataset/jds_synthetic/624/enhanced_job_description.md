## Detailed Responsibilities
- Design and implement Java-based web applications, focusing on user experience and high performance.
- Collaborate with cross-functional teams, including product managers and UX/UI designers, to gather and translate requirements into technical specifications.
- Build and maintain RESTful APIs and microservices, adhering to security best practices.
- Develop backend services and integrate them with React-based frontend components to ensure system reliability.
- Utilize AWS cloud services for application deployment, including configuration and performance monitoring.
- Implement containerization using Docker and orchestrate services with Kubernetes for improved deployment efficiency.
- Establish CI/CD pipelines to automate testing and deployment processes, enhancing overall software delivery.
- Optimize database queries and application performance, working with SQL (PostgreSQL) and NoSQL (MongoDB) databases.

## Skill Requirements
- Proficiency in Java, Spring Boot, and React.
- Extensive experience with RESTful APIs and microservices architecture.
- Strong background in AWS services and cloud-based applications.
- Familiarity with containerization (Docker) and orchestration (Kubernetes).
- Knowledge of CI/CD best practices and automated testing frameworks.
- Solid understanding of SQL databases, particularly PostgreSQL, and experience with NoSQL databases like MongoDB.
- Excellent debugging and performance optimization skills.

## Other Requirements
- Relevant certifications (e.g., Oracle Certified Professional: Java SE Developer).
- Experience with Agile development methodologies.
- Familiarity with additional cloud platforms (e.g., Google Cloud, Azure).
