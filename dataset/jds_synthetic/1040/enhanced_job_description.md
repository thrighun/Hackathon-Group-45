## Job Title
Data Analyst

## Location
Seattle, USA

## Client Industry
Technology Solutions / IT Services

## Detailed Responsibilities
- Analyze large datasets using SQL and Python to extract actionable insights that inform business strategies.
- Create and maintain interactive data visualizations and dashboards using Tableau, ensuring data accessibility for stakeholders.
- Collaborate closely with data engineering teams to validate data sources and ensure the accuracy of data feeds for analysis.
- Design, develop, and deploy machine learning algorithms to improve predictive modeling and data analysis capabilities.
- Streamline data collection methodologies and enhance analytic processes through automation, driving efficiency in reporting practices.
- Present data findings and insights to both technical and non-technical audiences, delivering clear and impactful recommendations.
- Continuously monitor and evaluate the effectiveness of data strategies and make adjustments to optimize outcomes.

## Skill Requirements
- Bachelor’s degree in Data Science, Statistics, Mathematics, or a related field.
- 3–5 years of experience in data analysis or a related analytical role.
- Strong proficiency in SQL for querying and manipulating large datasets.
- Advanced skills in Python for data analysis and machine learning tasks.
- Experience with Tableau or similar data visualization tools for creating compelling dashboards.
- Understanding of statistical methodologies and their application in data analysis.
- Familiarity with machine learning concepts and techniques to support analytical projects.

## Other Requirements
- Experience with data governance principles and data compliance regulations.
- Strong problem-solving abilities and attention to detail.
- Excellent communication skills, with the ability to convey complex data concepts clearly.
- Knowledge of data manipulation frameworks (e.g., Pandas) and libraries.
