## Job Title
Frontend Engineer

## Location
Remote

## Client Industry
Multinational Technology Provider

## Detailed Responsibilities
- Design and implement user interfaces using Vue.js and Bulma CSS frameworks to create dynamic and engaging web applications.
- Collaborate with backend developers to integrate APIs and enhance application functionality.
- Work closely with the design team to ensure the application meets high usability and aesthetics standards.
- Optimize applications for speed and scalability, enhancing the user experience across various devices.
- Conduct regular unit testing and participate in peer code reviews to maintain code quality and adhere to best practices.
- Monitor application performance and troubleshoot issues to ensure a seamless user experience.
- Keep up-to-date with the latest web development trends and technologies to suggest innovative improvements to the team.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- 3-6 years of professional experience in frontend development using Vue.js and Bulma CSS.
- Strong understanding of HTML, CSS, and JavaScript, with a focus on web standards and best practices.
- Experience integrating with RESTful services and working with asynchronous programming techniques.
- Familiarity with state management libraries such as Vuex and testing frameworks like Cypress.
- Strong troubleshooting and analytical skills, with a keen eye for detail.

## Other Requirements
- Experience with version control systems like Git and CI/CD pipelines for deployment.
- Knowledge of Agile methodologies and prior experience working within Agile teams.
- Excellent communication skills and the ability to work collaboratively in a distributed team environment.
