## Detailed Responsibilities
- Develop and implement automated test scripts for both web and backend systems using programming languages and testing frameworks.
- Collaborate with cross-functional teams, including product and development, to gather requirements and define testing strategies.
- Continuously enhance and maintain the automation framework to improve test coverage and execution efficiency.
- Conduct code reviews of test scripts and assist in troubleshooting issues in the automation process.
- Analyze and report on automation testing outcomes, providing key metrics to guide product development.
- Actively participate in Agile ceremonies, contributing to discussions on quality assurance and testing improvements.
- Offer support during user acceptance testing (UAT) and help validate releases with stakeholders to ensure product readiness.

## Skill Requirements
- Bachelor’s degree in Computer Science, Engineering, or a related field.
- A minimum of 2 years of experience in automation testing, specifically with web and backend applications.
- Proficiency in automation tools such as Selenium, JUnit, TestNG, or similar frameworks.
- Ability to write scripts in programming languages such as Java, Python, or JavaScript for test automation.
- Familiarity with CI/CD tools and practices to integrate testing into the development pipeline.
- Strong analytical and problem-solving skills with attention to detail.
- Excellent communication skills and the ability to work collaboratively in a team environment.

## Other Requirements
- Experience in Agile/Scrum development methodologies is preferred.
- ISTQB or equivalent certification in QA/testing is a plus.
- Exposure to performance testing tools (e.g., JMeter) and cloud testing environments would be advantageous.
- Continuous learning mindset with an interest in new testing technologies and frameworks.
