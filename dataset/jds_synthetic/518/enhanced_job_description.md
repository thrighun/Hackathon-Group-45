## Job Title
Java J2EE Software Engineer

## Location
Remote or On-site

## Client Industry
Information Technology Solutions Provider

## Detailed Responsibilities
- Develop and implement microservices-based architectures to create scalable and modular Java J2EE applications.
- Work closely with cross-functional teams, including UX/UI designers and system administrators, to deliver high-quality software solutions.
- Participate in sprint planning and retrospectives to ensure alignment with Agile methodologies.
- Write clean, maintainable, and efficient code while adhering to coding standards.
- Monitor application performance and debug issues in production environments to ensure optimal system functionality.
- Collaborate on the design and implementation of RESTful APIs to enable seamless integration with third-party services.
- Maintain comprehensive documentation of code changes, architecture decisions, and technical specifications.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related discipline.
- 3-6 years of experience in Java J2EE development, with a solid understanding of microservices architecture.
- Proficiency in front-end technologies including Angular, React, or Vue.js, along with HTML, CSS, and JavaScript.
- Strong knowledge of software testing principles and experience with unit testing frameworks such as JUnit or TestNG.
- Familiarity with databases (both SQL and NoSQL) and data modeling practices.
- Ability to work autonomously and as part of a collaborative team in a fast-paced environment.

## Other Requirements
- Experience with cloud-native application development on platforms such as AWS or Azure.
- Understanding of container orchestration tools like Kubernetes is an advantage.
- Knowledge of version control systems, particularly Git, and CI/CD practices is preferred.
