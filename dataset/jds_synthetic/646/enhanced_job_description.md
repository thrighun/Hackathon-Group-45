## Detailed Responsibilities
- Design, implement, and maintain full-stack applications using a variety of programming languages and frameworks to meet user needs.
- Collaborate closely with UX/UI designers to develop user-friendly and visually appealing interfaces.
- Write efficient, maintainable, and scalable code while adhering to best development practices.
- Participate in requirement gathering and analysis, translating user needs into functional software solutions.
- Optimize applications for maximum performance across various devices and browsers.
- Assist with debugging, troubleshooting, and resolving issues to ensure optimal application performance and user satisfaction.
- Conduct code reviews and contribute to team knowledge sharing through documentation and mentorship.
- Continuously research and stay updated on emerging technologies and trends in web development.
- Engage actively with both the front-end and back-end development teams to deliver integrated solutions.
- Ensure quality through test-driven development (TDD) and automated testing practices.

## Skill Requirements
- Proficient in front-end technologies such as HTML, CSS, JavaScript, and frameworks like React or Angular.
- Strong experience with back-end technologies including Node.js, Python, or Ruby on Rails.
- Familiarity with databases, both SQL (PostgreSQL, MySQL) and NoSQL (MongoDB).
- Solid understanding of RESTful API design and development.
- Experienced with DevOps practices, including CI/CD pipelines and containerization using Docker.
- Strong analytical and problem-solving abilities with attention to detail.
- Excellent communication skills and the ability to work effectively in a team environment.
- Bachelor’s degree in Computer Science, Information Technology, or a related discipline.

## Other Requirements
- Experience with cloud computing platforms such as AWS or Azure.
- Knowledge of Agile methodologies and familiarity with version control systems such as Git.
- Experience with automated testing frameworks and continuous delivery concepts.
