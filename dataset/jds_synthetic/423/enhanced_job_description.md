## Job Title
Data Engineer – Cloud Computing & Big Data

## Location
N/A

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Design, develop, and optimize scalable data pipelines to ingest, process, and store large datasets using cloud technologies.
- Collaborate with data scientists and analysts to understand data requirements and ensure data availability and quality for analytics.
- Implement data integration solutions using cloud platforms (AWS, Google Cloud, or Azure) to streamline data flows and enhance reporting capabilities.
- Optimize data storage solutions for performance and cost-effectiveness, ensuring compliance with data governance and security standards.
- Monitor and troubleshoot data processing jobs and workflows, addressing performance bottlenecks and data quality issues.
- Create documentation and user guides for data models, pipelines, and database structures to facilitate understanding and usage across teams.
- Stay informed about emerging technologies in big data, data engineering, and cloud computing, and recommend best practices and tools.

## Skill Requirements
- Proven experience in data engineering, with proficiency in SQL and at least one programming language (Python, Java, or Scala).
- Strong knowledge of cloud platforms and services (e.g., AWS Redshift, Google BigQuery, Azure SQL Database).
- Experience with big data frameworks (e.g., Apache Hadoop, Spark) and data warehousing concepts.
- Familiarity with orchestration tools (e.g., Apache Airflow, AWS Step Functions) for managing and scheduling workflows.
- Understanding of data modeling, ETL processes, and data architecture principles.
- Bachelor’s degree in Computer Science, Data Science, or a related field.
- Excellent analytical skills, attention to detail, and teamwork capabilities.

## Other Requirements
- Relevant cloud certifications (e.g., AWS Certified Data Analytics, Google Professional Data Engineer).
- Experience with NoSQL databases (e.g., MongoDB, Cassandra) and data lake architectures.
- Knowledge of machine learning processes and tools is a plus.
- Strong communication skills to facilitate collaboration with cross-functional teams.
