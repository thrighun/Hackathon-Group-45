## Detailed Responsibilities
- Design, implement, and manage Azure cloud solutions to support business applications and infrastructure.
- Ensure optimal performance, reliability, and security of Azure environments.
- Conduct system monitoring, performance tuning, and troubleshooting across Azure services.
- Develop automation scripts using Azure CLI and PowerShell to streamline processes.
- Work closely with software development teams to facilitate seamless integration and deployment of applications.
- Maintain compliance with relevant industry regulations and security standards.
- Provide support and expertise to teams and clients regarding Azure services and architecture.
- Research and recommend new Azure tools and technologies to enhance operational efficiency.

## Skill Requirements
- 4-6 years of experience as an Azure Cloud Engineer or in a similar role.
- Deep understanding of Azure services such as Azure Functions, Azure SQL Database, and Azure Storage.
- Proficiency in infrastructure-as-code solutions using Azure Resource Manager (ARM) templates or Terraform.
- Solid knowledge of networking concepts including Azure Virtual Networks, ExpressRoute, and Network Security Groups.
- Strong scripting skills in PowerShell or Azure CLI.
- Familiarity with monitoring and management tools like Azure Monitor, Log Analytics, or Application Insights.
- Bachelor's degree in Computer Science, Information Technology, or a related field.
- Azure certification (Solutions Architect, Administrator, or equivalent) is preferred.

## Other Requirements
- Experience with container orchestration platforms like Azure Kubernetes Service (AKS).
- Understanding of DevOps methodologies and CI/CD integration within Azure DevOps.
- Strong analytical thinking and problem-solving capabilities.
- Excellent communication, collaboration, and interpersonal skills.
