## Detailed Responsibilities
- Develop and maintain embedded software applications using C and C++ for various hardware platforms.
- Collaborate with hardware engineers to integrate software and hardware components effectively.
- Write and optimize firmware for microcontrollers and DSPs to ensure high performance and reliability.
- Perform system-level testing and debugging of embedded systems to validate functionality.
- Document software design specifications and maintain updated records of code changes.
- Contribute to the continuous improvement of development processes and methodologies.
- Research and implement innovative solutions to enhance system capabilities and performance.

## Skill Requirements
- Bachelor's degree in Computer Engineering, Software Engineering, or a related discipline.
- 4-6 years of professional experience in embedded software development using C and C++.
- Strong knowledge of microcontroller architectures and embedded development tools.
- Experience with real-time programming and familiarity with operating system concepts.
- Ability to analyze and optimize system performance, memory usage, and power consumption.
- Strong analytical and problem-solving abilities, with meticulous attention to detail.
- Capable of working both independently and collaboratively within a team environment.

## Other Requirements
- Experience with scripting languages like Python or shell scripting.
- Understanding of communication protocols such as CAN, Ethernet, or Bluetooth.
- Proficient with development tools like IDEs, debuggers, and emulators.
- Effective communication skills, with the ability to present technical information clearly to diverse audiences.
