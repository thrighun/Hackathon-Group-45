## Job Title
JavaScript Frontend Developer

## Location
N/A

## Client Industry
Information Technology / Multinational Technology Solutions Provider

## Detailed Responsibilities
- Develop and implement user-friendly web interfaces using React, ensuring responsiveness and performance optimization.
- Collaborate closely with backend developers to integrate RESTful APIs and create a seamless user experience.
- Design and manage database solutions using MongoDB to support dynamic web applications.
- Deploy and maintain front-end applications on Amazon Web Services (AWS), utilizing cloud services to enhance scalability and efficiency.
- Participate in the design and development of AI-powered features and functionalities to enrich user interaction and engagement.
- Write efficient, maintainable JavaScript code and ensure code quality through reviews and testing practices.
- Stay abreast of industry trends and emerging technologies, proposing enhancements and new features based on user feedback and research.
- Work within an Agile environment, actively participating in sprint planning, daily stand-ups, and retrospectives to drive team productivity.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- Minimum of 3 years of experience in frontend development using JavaScript, particularly with React framework.
- Proficiency with NoSQL databases, specifically MongoDB.
- Familiarity with deploying applications on cloud platforms, especially AWS.
- Understanding of AI tools and libraries to integrate intelligent functionalities in applications.
- Strong grasp of UX/UI principles and best practices in web development.
- Excellent analytical skills and the ability to troubleshoot and optimize website performance.

## Other Requirements
- Experience with version control systems (Git) and package management tools (npm, yarn) is a plus.
- Knowledge of containerization (Docker) and CI/CD methodologies.
- Prior experience working in an Agile development environment.
- Strong communication skills and ability to collaborate with remote teams and stakeholders.
