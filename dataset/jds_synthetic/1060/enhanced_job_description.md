## Job Title
Node.js Microservices Developer

## Location
Remote or On-site

## Client Industry
Information Technology / Cloud-Based Solutions Provider

## Detailed Responsibilities
- Develop and maintain microservices-based architectures using Node.js and the Express framework to create scalable applications.
- Collaborate with data scientists and analysts to integrate machine learning models into backend systems, enhancing data processing capabilities.
- Design and implement RESTful APIs that ensure seamless communication between frontend applications and backend services.
- Optimize database management systems, primarily using MongoDB, to handle large-scale data efficiently and securely.
- Deploy and manage applications on Amazon Web Services (AWS), employing best practices for cloud security and scalability.
- Write comprehensive unit and integration tests to ensure robustness and reliability of deployed services.
- Participate actively in code reviews, providing constructive feedback to enhance code quality and team collaboration.
- Stay abreast of industry trends, tools, and technologies, suggesting new approaches that can improve product offerings.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- Minimum of 3 years experience in backend development with Node.js and Express framework.
- Strong proficiency in NoSQL databases like MongoDB with practical experience in database design.
- Familiarity with deploying applications on AWS, including services like Lambda, S3, and EC2.
- Understanding of machine learning concepts and experience integrating models into production systems is a plus.
- Knowledge of building secure and scalable RESTful APIs and microservices architecture.

## Other Requirements
- Experience with containerization tools, such as Docker, and orchestration platforms like Kubernetes.
- Familiarity with CI/CD tools and automated deployment practices.
- Excellent problem-solving abilities and a collaborative mindset to work effectively in team environments.
- Strong written and verbal communication skills, with an emphasis on clear documentation and reporting.
