## Detailed Responsibilities
- Design and implement full-stack applications using Angular for front-end and Node.js for back-end development.
- Collaborate with product owners and designers to create responsive and user-friendly interfaces while ensuring alignment with business goals.
- Develop and maintain RESTful APIs, integrating them seamlessly with front-end applications to create dynamic user experiences.
- Optimize applications for speed, scalability, and performance, focusing on responsive design and cross-browser compatibility.
- Participate in agile development processes, including sprint planning, daily stand-ups, and retrospectives, contributing to team goals and project success.
- Conduct thorough testing and debugging to maintain high standards of quality and performance.
- Stay current with emerging technologies and industry trends, proactively suggesting enhancements to improve application functionality and user satisfaction.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related discipline.
- Strong experience (3+ years) in developing web applications using Angular and Node.js.
- Proficient in HTML5, CSS3, and Bootstrap for building responsive user interfaces.
- Solid understanding of REST APIs and working with databases (e.g., MongoDB, MySQL).
- Familiarity with version control systems (e.g., Git) and CI/CD pipelines.
- Excellent analytical and troubleshooting skills, with the ability to work independently and as part of a team.

## Other Requirements
- Experience with TypeScript and state management libraries (e.g., NgRx) is a plus.
- Knowledge of cloud services (e.g., AWS, Azure) and deployment processes is desirable.
- Previous experience in an Agile/Scrum environment is preferred.
