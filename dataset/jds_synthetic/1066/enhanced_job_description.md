## Job Title
JavaScript Frontend Developer

## Location
N/A

## Client Industry
Information Technology / Multinational Technology Solutions Provider

## Detailed Responsibilities
- Design, develop, and maintain dynamic and responsive frontend applications using JavaScript frameworks, primarily React.
- Collaborate with UX/UI designers and backend developers to create seamless and user-friendly experiences across various platforms.
- Integrate and optimize MongoDB databases, ensuring efficient data retrieval and storage while maintaining data integrity.
- Deploy, manage, and monitor frontend applications on Amazon Web Services (AWS), utilizing cloud services for optimal performance and scalability.
- Work on the integration of AI capabilities to enhance application functionality and user interactions.
- Write clean, modular, and well-documented code while following best practices for frontend development.
- Participate in code reviews, continuous integration, and testing processes to ensure high-quality deliverables.
- Stay abreast of industry trends and emerging technologies, recommending innovative solutions to enhance product offerings.
- Collaborate with agile teams to enhance the development workflow and improve project outcomes.

## Skill Requirements
- Bachelor’s degree in Computer Science, Web Development, or a related field.
- Proven experience (3+ years) in frontend development using JavaScript with React.
- Strong understanding of NoSQL databases, especially MongoDB.
- Hands-on experience deploying applications on AWS.
- Familiarity with AI technologies and their integration into web applications.
- Solid understanding of RESTful services, microservices architecture, and responsive design principles.
- Excellent problem-solving skills, attention to detail, and ability to work both independently and collaboratively within a team.

## Other Requirements
- Experience with version control systems (e.g., Git) and package managers (e.g., npm).
- Knowledge of testing frameworks such as Jest or Mocha is a plus.
- Exposure to containerization technologies (Docker) or serverless architecture.
- Strong communication skills and a proactive, team-oriented approach.
