## Job Title
Front-End Developer (with Vue.js and Bootstrap)

## Location
Remote or Hybrid Options Available

## Client Industry
Information Technology / Web Development Solutions

## Detailed Responsibilities
- Design, develop, and maintain cutting-edge web applications utilizing Vue.js and Bootstrap, focusing on user-centric design principles.
- Collaborate with backend teams to integrate and consume data from GraphQL APIs, ensuring efficient and scalable data management.
- Work closely with UI/UX designers to implement intuitive and engaging user interfaces while adhering to best design practices.
- Perform code reviews, providing insights and suggestions for improvement in both code quality and performance.
- Participate actively in Agile ceremonies, including sprint planning, daily stand-ups, and retrospectives, promoting team cohesion and alignment.
- Optimize web application performance through effective use of lazy loading, asynchronous data fetching, and other performance-enhancing techniques.
- Identify and fix bugs and performance bottlenecks, ensuring cross-browser compatibility and mobile responsiveness.
- Document development processes, architecture decisions, and coding standards for team reference and onboarding.
- Stay current with emerging trends and technologies within the Vue.js ecosystem and overall frontend development.
- Foster a culture of continuous learning and improvement within the development team by sharing knowledge and resources.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field (or equivalent practical experience).
- Proven expertise in building web applications using Vue.js and Bootstrap, with a strong emphasis on component-based architecture.
- Solid understanding of JavaScript (ES6+), HTML5, and CSS3, with experience in responsive web design.
- Familiarity with GraphQL and experience in integrating frontend applications with GraphQL endpoints.
- Proficient in using version control systems like Git, including experience with branching strategies and pull request workflows.
- Strong problem-solving skills and ability to debug complex issues in a fast-paced environment.
- Excellent communication and collaboration skills to effectively work with cross-functional teams and stakeholders.
- Experience in utilizing state management libraries such as Vuex for managing application state efficiently.
- Understanding of automation tools and CI/CD practices to enhance deployment workflows.
- Prior experience in a collaborative software development environment, preferably in multinational or large-scale projects.

## Other Requirements
- Knowledge of TypeScript is a plus.
- Familiarity with testing libraries/frameworks, such as Jest or Cypress, to ensure application reliability and quality.
