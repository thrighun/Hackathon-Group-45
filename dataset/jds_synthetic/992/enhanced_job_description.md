## Job Title
Backend Engineer – Cloud Services

## Location
Remote

## Client Industry
Technology

## Detailed Responsibilities
- Develop and maintain scalable backend services using Node.js, ensuring high performance and responsiveness to requests from the front end.
- Design and implement RESTful and GraphQL APIs to facilitate seamless communication between different service-oriented components.
- Manage data storage and retrieval operations using MongoDB, focusing on data modeling and optimization for performance.
- Collaborate closely with frontend developers and DevOps teams to integrate user-facing elements with server-side logic.
- Implement security protocols and data protection measures to safeguard sensitive information in cloud environments.
- Participate in code reviews, providing constructive feedback to peers and ensuring adherence to coding standards.
- Engage in continuous integration and deployment practices, utilizing Docker for containerization and AWS for cloud services.
- Contribute to Agile ceremonies, including daily stand-ups and sprint planning, fostering a culture of collaboration and innovation.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- Proven experience in building backend applications using Node.js and Express framework.
- Strong understanding of database management with MongoDB and data aggregation techniques.
- Familiarity with cloud services, specifically AWS, including EC2, S3, and Lambda functions.
- Experience with version control systems like Git and agile development methodologies.
- Strong debugging and troubleshooting skills, with a focus on performance optimization.
- Excellent communication skills to effectively collaborate with cross-functional teams.

## Other Requirements
- Experience with container orchestration platforms, particularly Kubernetes.
- Knowledge of testing frameworks and methodologies for backend applications.
- Certification in AWS or related cloud technologies is a plus.
- Previous experience in building applications for e-commerce or SaaS platforms is advantageous.
