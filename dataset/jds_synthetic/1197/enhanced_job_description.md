## Job Title
Java IDE Extension Developer

## Location
Remote

## Client Industry
Software Development Company

## Detailed Responsibilities
- Develop and maintain extensions for integrated development environments (IDEs) using Java and OSGi technologies.
- Collaborate with product managers and UX/UI designers to create user-friendly extensions that enhance developer productivity.
- Ensure high performance, quality, and responsiveness of applications by conducting thorough testing and debugging.
- Implement best practices in software development and collaborate in code reviews to improve team performance and code quality.
- Create and maintain technical documentation for extension features, installation processes, and user guides.
- Keep abreast of emerging technologies and frameworks related to IDE development to continuously improve skills and project outcomes.

## Skill Requirements
- 3-6 years of experience in Java application development, specifically for IDEs.
- Proficient in OSGi (Open Services Gateway Initiative) framework.
- Strong background in Java programming and software architecture.
- Familiarity with popular IDEs such as IntelliJ IDEA, NetBeans, or Eclipse, and their extensibility features.
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- Excellent analytical and troubleshooting skills.
- Strong interpersonal and communication skills for effective collaboration across teams.

## Other Requirements
- Knowledge of web technologies (HTML, CSS, JavaScript) and how they integrate with IDEs.
- Experience with Agile development methodologies and DevOps practices.
- Familiarity with continuous integration/continuous deployment (CI/CD) tools.
