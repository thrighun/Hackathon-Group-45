## Job Title
Senior Software Engineer - Microservices & Cloud

## Location
N/A

## Client Industry
Technology

## Detailed Responsibilities
- Design and implement scalable microservices architectures for cloud-based applications.
- Collaborate with product owners and stakeholders to gather and refine requirements for new features.
- Develop high-quality software using Java and Spring Boot frameworks, ensuring best practices in coding and design.
- Review and enhance existing codebases to improve performance, reliability, and maintainability.
- Identify and resolve performance bottlenecks and troubleshoot cloud infrastructure issues.
- Mentor junior developers, fostering a culture of continuous learning and innovation within the team.
- Stay abreast of emerging trends in cloud technologies and microservices to drive continuous improvement in our development processes.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- 4-7 years of experience in software development, with a focus on microservices and cloud technologies.
- Proficiency in Java, Spring Boot, and related cloud frameworks such as AWS or Azure.
- Strong understanding of containerization technologies (Docker, Kubernetes).
- Experience with RESTful API design and implementation.
- Familiarity with front-end frameworks like React or Angular.
- Knowledge of database technologies, both SQL and NoSQL.
- Excellent analytical and debugging skills.
- Strong collaboration and communication skills tailored for an Agile environment.

## Other Requirements
- Experience working in Agile/Scrum teams.
- Familiarity with CI/CD practices and tools.
- Relevant certifications in cloud technologies or software development.
- Previous experience in DevOps is a plus.
