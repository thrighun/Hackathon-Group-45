## Job Title
Spring Boot Developer

## Location
Remote/On-site

## Client Industry
Technology

## Detailed Responsibilities
- Design and develop scalable applications using Spring Boot and microservices architecture.
- Collaborate with product owners and UX/UI designers to gather and define requirements for application features.
- Write efficient, reusable, and reliable Java code while adhering to best practices.
- Implement automated testing and continuous integration to ensure high code quality.
- Conduct peer code reviews and mentor junior developers to foster a culture of learning and improvement.
- Monitor application performance and troubleshoot any issues that arise in production environments.
- Keep abreast of emerging technologies and contribute to architectural discussions and decisions.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- 3-6 years of experience in backend development using Spring Boot and Java.
- Proficient in RESTful API design and development.
- Experience with containerization technologies such as Docker and orchestration tools like Kubernetes.
- Solid understanding of relational databases and NoSQL data stores.
- Familiarity with front-end frameworks like Angular or React is a plus.
- Strong analytical and problem-solving skills.
- Effective communication and teamwork capabilities.

## Other Requirements
- Experience working in an Agile/Scrum environment.
- Knowledge of cloud computing platforms like AWS, Azure, or GCP.
- Familiarity with CI/CD pipelines and DevOps practices.
- Relevant certifications in Java or Spring technologies are a plus.
