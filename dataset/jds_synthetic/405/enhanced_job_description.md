## Job Title
Data Engineer – Azure & Big Data Solutions

## Location
N/A

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Design, develop, and optimize scalable data pipelines to support real-time analytics and large-scale data processing on Azure cloud.
- Collaborate with data scientists and architects to understand data requirements and translate them into technical solutions.
- Build and maintain data integration workflows using Azure Data Factory, ensuring data quality and accessibility across the organization.
- Implement ETL processes that efficiently manage data from heterogeneous sources and leverage Azure services like Azure Databricks and Azure SQL Database.
- Work with structured and unstructured data, employing best practices for data governance, storage, and retrieval.
- Monitor and troubleshoot data workflows and pipelines to ensure optimal performance and reliability.
- Stay current with advancements in big data technologies and practices, providing insights and recommendations for improvements.

## Skill Requirements
- Proven experience in data engineering, with strong expertise in designing and implementing data pipelines.
- Hands-on experience with Azure cloud services (e.g., Azure Data Lake, Azure Databricks, Azure SQL).
- Proficiency in SQL and programming languages such as Python or Scala for data manipulation and analysis.
- Familiarity with data warehousing concepts and tools (e.g., Snowflake, Azure Synapse).
- Understanding of big data technologies (e.g., Hadoop, Spark) and data modeling techniques.
- Bachelor’s degree in Computer Science, Data Science, or a related field.
- Strong analytical skills and a problem-solving mindset.

## Other Requirements
- Azure or relevant cloud certifications (e.g., Microsoft Certified: Azure Data Engineer Associate).
- Experience with containerization and orchestration tools (Docker, Kubernetes).
- Familiarity with data visualization tools (e.g., Power BI, Tableau) and reporting practices.
- Exposure to machine learning frameworks or projects would be a plus.
