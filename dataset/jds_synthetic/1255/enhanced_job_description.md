## Job Title
Cloud Services Backend Engineer (Python/Django)

## Location
N/A

## Client Industry
Information Technology / Cloud Computing

## Detailed Responsibilities
- Develop and maintain cloud-based backend systems and APIs using Python and Django, prioritizing performance and scalability.
- Design and optimize data models with MongoDB, ensuring efficient data retrieval and storage solutions.
- Work closely with product teams and frontend developers to deliver integrated, user-friendly services.
- Implement automated testing strategies to ensure code quality and stability across the deployment lifecycle.
- Maintain thorough documentation for system architecture, API endpoints, and backend processes to facilitate onboarding and knowledge sharing.
- Conduct regular performance assessments, troubleshoot anomalies, and implement improvements to enhance system efficiency.
- Foster a culture of code quality by participating in code reviews and providing constructive feedback to peers.
- Adhere to industry standards for security and data protection in all backend development practices.

## Skill Requirements
- Bachelor's degree in Computer Science or a related discipline.
- At least 4 years of hands-on experience in backend development using Python.
- Strong expertise in the Django framework and experience with RESTful API development.
- Proficiency in MongoDB and NoSQL database design principles.
- Familiar with software development methodologies such as Agile or Scrum.
- Experience with version control tools (e.g., Git) and collaboration platforms.
- Strong analytical skills and ability to debug and resolve complex issues.
- Excellent communication and teamwork skills.

## Other Requirements
- Experience with cloud service platforms such as AWS, Azure, or Google Cloud is preferred.
- Knowledge of container orchestration technologies like Docker and Kubernetes is a plus.
- Familiarity with CI/CD practices and automated deployment pipelines.
- Involvement in open-source contributions or developer communities is a benefit.
- Prior experience in system monitoring and logging tools (e.g., Prometheus, ELK stack).
