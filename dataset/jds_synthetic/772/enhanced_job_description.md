## Detailed Responsibilities
- Architect and develop cloud-native applications using microservices architecture and Kubernetes for optimal performance and scalability.
- Lead and mentor cross-functional development teams in applying best practices for cloud-based solutions, emphasizing security and maintainability.
- Collaborate with stakeholders to define project objectives and translate business needs into technical solutions.
- Assess and optimize existing applications to improve their efficiency while minimizing costs.
- Innovate by integrating the latest cloud technologies and methodologies into the development process, facilitating a culture of continuous improvement.
- Establish and manage CI/CD pipelines to automate deployment processes and improve development cycles.
- Perform regular code reviews to ensure adherence to quality standards, security protocols, and compliance requirements.

## Skill Requirements
- Extensive experience with cloud architecture, particularly with AWS or Azure.
- Proficiency in microservices design and containerization technologies such as Docker and Kubernetes.
- Strong programming skills in Python or similar languages for developing scalable applications.
- Deep understanding of DevOps principles and practices to enhance development workflows.
- Knowledge of database technologies like PostgreSQL or equivalent systems.

## Other Requirements
- Experience with Agile methodologies and project management tools.
- Relevant certifications in cloud technologies (AWS Certified Solutions Architect, Azure Solutions Architect, etc.) are a plus.
- Knowledge of service mesh technologies (e.g., Istio) and monitoring tools (e.g., Prometheus, Grafana) is advantageous.
