- Collaborate closely with UX/UI designers and backend engineers to ensure cohesive product functionality.
- Enhance application efficiency by implementing best practices for performance optimization.
- Utilize responsive design techniques to deliver a consistent user experience across various devices.
- Maintain comprehensive documentation for code and application features.
- Proactively identify and debug issues in the front-end architecture.
- Keep abreast of evolving web technologies and integrate new tools and practices as necessary.

- Assist in agile sprint planning, feature estimation, and contribute to technical specifications.
