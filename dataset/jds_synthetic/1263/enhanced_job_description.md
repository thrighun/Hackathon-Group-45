## Job Title
Data Engineer

## Location
N/A

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Design, construct, and maintain robust data pipelines to facilitate the seamless transfer and transformation of data across multiple sources.
- Collaborate with data analysts and data scientists to understand data requirements and provide clean, reliable datasets for analysis and reporting.
- Develop and optimize data warehousing solutions to ensure fast and efficient query performance.
- Implement data modeling techniques to structure data for optimal usage in analytics and reporting tasks.
- Utilize big data technologies (such as Hadoop, Spark, or Kafka) to manage and process large datasets effectively.
- Monitor data pipeline performance, troubleshoot issues, and implement strategies for performance enhancement.
- Ensure data security and compliance with relevant regulations while promoting best practices in data management.
- Prepare technical documentation for data processes, pipeline architecture, and data flow diagrams to facilitate knowledge sharing.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Information Technology, or a related field.
- Proven experience in building and managing data pipelines and data warehousing solutions.
- Strong programming skills in Python, SQL, or Scala, with experience in data processing frameworks like Apache Spark.
- Familiarity with ETL tools and data integration techniques.
- Experience with cloud-based data platforms (AWS Redshift, Google BigQuery, or Azure Synapse) for data storage and processing.
- Solid understanding of database management systems and data modeling concepts.
- Excellent analytical skills and attention to detail in data handling.
- Strong communication and collaboration skills to work within cross-functional teams.

## Other Requirements
- Knowledge of data governance and best practices for maintaining data quality.
- Experience with real-time data processing and streaming technologies.
- Familiarity with machine learning concepts to enhance data products and support analytics initiatives.
- Contributions to open-source data engineering projects or relevant research publications.
