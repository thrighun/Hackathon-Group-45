## Job Title
Senior Java Software Engineer

## Location
Remote

## Client Industry
Software Development

## Detailed Responsibilities
- Design and implement robust, scalable microservices using Java and frameworks such as Spring Cloud.
- Lead architectural discussions to define service-oriented architectures and improve existing systems.
- Collaborate with product management and other stakeholders to gather requirements and translate them into technical specifications.
- Develop automated tests to ensure code reliability and maintainability.
- Optimize application performance through profiling and tuning.
- Mentor junior developers, providing guidance on best practices and development techniques.
- Contribute to the continuous integration/continuous deployment (CI/CD) processes to enhance development workflows.

## Skill Requirements
- Bachelor's degree in Computer Science or a related field.
- A minimum of 7 years of experience in Java development with a focus on microservices architecture.
- Strong proficiency in Spring Cloud and RESTful API development.
- Experience with containerization technologies, such as Docker and Kubernetes.
- Thorough understanding of database systems, including NoSQL databases.
- Proficient in using Git and CI/CD tools like Jenkins or GitLab CI.
- Excellent analytical and troubleshooting skills.
- Ability to communicate complex concepts clearly to technical and non-technical team members.

## Other Requirements
- Familiarity with cloud-native development on platforms like Google Cloud or Azure.
- Understanding of front-end technologies like Vue.js or Svelte.
- Knowledge of security best practices in software development.
