## Detailed Responsibilities
- Design, develop, and maintain automated test scripts for both web and mobile applications.
- Collaborate with software developers and product owners to understand application requirements and create appropriate test strategies.
- Execute automated test cases and analyze results to detect bugs and performance issues.
- Continuously improve the efficiency of the testing process by integrating automated testing into the CI/CD pipeline.
- Document and report on test results, providing clear feedback to the development team.
- Participate in peer reviews of test cases and automated scripts to elevate team standards.
- Stay abreast of industry best practices for test automation tools and methodologies.

## Skill Requirements
- Strong coding skills in languages such as Python, Java, or JavaScript for scripting automated tests.
- Experience with automation testing frameworks such as Selenium, TestNG, or JUnit.
- Proficiency in version control systems like Git and CI/CD tools such as Jenkins or CircleCI.
- Strong analytical skills with the ability to troubleshoot and resolve issues efficiently.

## Other Requirements
- Bachelor’s degree in Computer Science, Information Technology, or a related field.
- At least 3 years of experience in software testing with a focus on automation.
- Familiarity with Agile methodologies and experience working in Agile teams.
- Excellent communication skills and the ability to collaborate effectively with cross-functional teams.
