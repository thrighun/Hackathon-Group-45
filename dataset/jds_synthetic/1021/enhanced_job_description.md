## Job Title
Data Engineer – Cloud Architecture & Big Data Solutions

## Location
N/A

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Design, construct, and maintain scalable data pipelines that support big data processing and analytics across various cloud platforms.
- Collaborate with data scientists and analytics teams to understand data requirements and ensure the availability of clean, reliable data for analysis.
- Build and optimize ETL processes to efficiently extract, transform, and load data from diverse sources into cloud-based data warehouses and lakes.
- Implement best practices for data governance, quality, and security to ensure compliance and data integrity.
- Utilize cloud services to deploy and manage data solutions, ensuring optimal performance and cost-effectiveness.
- Monitor data flow and troubleshoot bottlenecks to improve pipeline efficiency and reliability.
- Stay informed about industry trends and emerging technologies in data engineering, big data, and cloud computing, offering innovative solutions for continuous improvement.

## Skill Requirements
- Proficient in data engineering concepts and practices, with a strong emphasis on big data technologies (e.g., Hadoop, Spark).
- Extensive experience with cloud platforms (e.g., AWS, Azure, Google Cloud) and their data offerings (e.g., Redshift, Azure Synapse).
- Proven ability to develop complex ETL workflows using tools like Apache NiFi, Talend, or AWS Glue.
- Strong SQL skills, with experience in database design, optimization, and management.
- Understanding of data modeling, data warehousing concepts, and data architecture principles.
- Bachelor’s degree in Data Science, Computer Science, or a related field.
- Excellent problem-solving, analytical, and communication skills.

## Other Requirements
- Relevant cloud certifications (e.g., AWS Certified Data Analytics, Microsoft Certified: Azure Data Engineer Associate).
- Familiarity with containerization tools (Docker, Kubernetes) for deploying data applications.
- Experience with infrastructure-as-code tools (Terraform, CloudFormation) for automating data environment setups.
- Knowledge of advanced analytics, machine learning integration, or artificial intelligence techniques in data projects.
