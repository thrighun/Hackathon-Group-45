- Design and implement robust data architectures and engineering solutions for pharmaceutical data analytics.
- Build scalable ETL processes using tools such as Apache Airflow, Talend, or Informatica to transform raw data into actionable insights.
- Develop and maintain data models, schemas, and data dictionaries for various data sources including clinical trials, patient records, and research databases.
- Ensure data quality and consistency through automated testing and validation processes.
- Collaborate with cross-functional teams to gather requirements and provide technical expertise on data-related projects.
- Optimize SQL queries and data retrieval processes for efficiency and performance.
- Implement data governance practices to ensure compliance with industry regulations (e.g., HIPAA, GxP).
- Use cloud platforms like AWS or Azure to manage data storage and processing capabilities effectively.

- Hands-on experience with data processing tools like Apache Spark or Hadoop.
- Understanding of data governance and compliance standards relevant to the pharmaceutical industry.
