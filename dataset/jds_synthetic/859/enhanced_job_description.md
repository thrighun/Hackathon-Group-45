- Develop, test, and maintain full-stack applications using JavaScript frameworks, primarily React.js for the front-end and Node.js for the back-end.
- Collaborate with product managers, designers, and other stakeholders to define application features and functionalities.
- Write clean, modular, and efficient code while adhering to industry best practices.
- Manage database integrations, ensuring the security and integrity of data.
- Conduct unit and integration testing to verify application stability and performance.
- Monitor application performance and troubleshoot issues in production environments.
- Participate in daily stand-up meetings and contribute to the Agile development process.
- Foster a culture of continuous improvement by sharing ideas and collaborating on coding best practices.
