## Detailed Responsibilities
- Design, implement, and manage scalable cloud solutions on Google Cloud Platform for various applications.
- Ensure optimal performance, security, and reliability of cloud resources.
- Collaborate with software development teams to facilitate implementation of cloud-native applications.
- Automate deployment and maintenance tasks using GCP tools and CI/CD pipelines.
- Monitor system health and performance metrics, implementing solutions for identified issues.
- Conduct cost analysis and optimization for cloud resource allocation.
- Keep abreast of the latest GCP services and best practices to leverage for infrastructure improvement.
- Provide technical documentation and training for internal teams on cloud technologies.

## Skill Requirements
- 4-6 years of experience in a cloud engineering role, particularly with Google Cloud Platform.
- Strong understanding of GCP services such as Compute Engine, Kubernetes Engine, BigQuery, and Cloud Storage.
- Experience with configuration management tools like Ansible or Chef.
- Knowledge of networking concepts, including subnets, firewalls, and load balancing within GCP.
- Proficiency in programming languages such as Go, Ruby, or Node.js.
- Familiarity with monitoring and logging services such as Stackdriver or Grafana.
- Bachelor’s degree in Information Systems, Software Engineering, or a related discipline.
- Google Cloud certification (Professional Cloud Architect or equivalent) is advantageous.

## Other Requirements
- Experience with serverless architectures and microservices design principles.
- Familiarity with Agile methodologies and collaboration tools like Jira or Trello.
- Strong troubleshooting and analytical skills to resolve cloud issues efficiently.
- Excellent interpersonal skills to effectively communicate with both technical and non-technical stakeholders.
