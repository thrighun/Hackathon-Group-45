## Job Title
Data Engineer

## Location
N/A

## Client Industry
Information Technology / Global Data Solutions Provider

## Detailed Responsibilities
- Design, implement, and maintain scalable data pipelines using Python and Apache Spark for efficient data processing and transformation.
- Collaborate with data scientists and analysts to understand data requirements and deliver high-quality datasets for analytics and machine learning applications.
- Develop and optimize ETL (Extract, Transform, Load) processes to ensure seamless data integration from multiple sources into a centralized data warehouse.
- Utilize Google BigQuery and other cloud computing solutions to store, query, and analyze large datasets efficiently.
- Work on the integration and deployment of machine learning models to production environments, ensuring model reliability and performance.
- Monitor and troubleshoot data workflows, ensuring data accuracy, consistency, and availability across platforms.
- Write comprehensive documentation for data workflows and pipelines, promoting transparency and knowledge sharing among teams.
- Stay abreast of industry trends and technologies in data engineering and machine learning, proactively suggesting enhancements to existing processes.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Data Science, or a related field.
- At least 3 years of experience in data engineering or a related role, with strong proficiency in Python and Apache Spark.
- Experience working with cloud platforms, specifically Google Cloud Platform (GCP) and BigQuery.
- Knowledge of ETL tools and best practices, with experience in data warehousing solutions.
- Familiarity with machine learning frameworks and deploying models in production environments.
- Strong analytical skills and an ability to troubleshoot data-related issues effectively.

## Other Requirements
- Experience with containerization technologies such as Docker is a plus.
- Understanding of CI/CD processes and tools for automating data pipeline deployments.
- Familiarity with additional programming languages (e.g., Java, Scala) or data processing frameworks is advantageous.
- Excellent communication skills and a collaborative approach to problem-solving.
