## Detailed Responsibilities
- Lead the design and implementation of scalable microservices using Java Spring Boot, ensuring integration with cloud platforms.
- Collaborate with product management and design teams to define user stories, and transform them into technical specifications and solutions.
- Develop responsive web applications using modern frontend technologies such as React or Angular, ensuring optimal user experience across devices.
- Conduct performance analysis and optimization for both backend services and frontend applications, addressing issues proactively.
- Guide and mentor junior developers on best practices in coding, debugging, and version control.
- Participate actively in Agile development processes, contributing to sprint planning, retrospectives, and daily stand-ups.
- Ensure thorough documentation of software designs, processes, and code for future reference and knowledge transfer.
- Evaluate and recommend new tools and frameworks that improve development effectiveness and productivity.

## Skill Requirements
- Bachelor's degree in Software Engineering, Computer Science, or a related field.
- A minimum of 5 years of experience in Java development with a strong focus on Spring Boot and microservices architecture.
- Proficiency in frontend frameworks such as React, Angular or Vue.js, along with core web technologies (HTML, CSS, JavaScript).
- Experience with cloud services like AWS, Azure, or Google Cloud, specifically in deploying and managing microservices.
- Solid knowledge of RESTful API design and implementation, along with security best practices for web applications.
- Familiarity with DevOps practices and CI/CD tools (e.g., Jenkins, GitLab CI).
- Strong analytical skills with an aptitude for solving complex problems efficiently.
