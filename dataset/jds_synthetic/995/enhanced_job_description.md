## Detailed Responsibilities
- Develop and maintain responsive mobile applications using React Native for iOS and Android platforms, prioritizing performance and user engagement.
- Collaborate with UX/UI designers to create visually appealing and user-friendly application interfaces.
- Integrate various RESTful APIs to enhance application functionality and improve user experience.
- Conduct peer code reviews and contribute to the establishment of coding standards and best practices within the team.
- Continuously monitor application performance, diagnose issues, and implement solutions to enhance usability and reliability.
- Keep abreast of the latest industry developments and technologies to propose improvements and innovations in mobile application development.
- Work within an Agile development framework to ensure timely delivery of features and adapt to evolving project needs.

- Proficient in React Native for developing cross-platform mobile applications.
- Strong understanding of UX principles and best practices for mobile design.
- Experience with API integration and backend communication methods.
- Familiarity with version control systems, particularly Git.
- Knowledge of mobile development testing frameworks and methodologies.
- Excellent problem-solving skills with a keen eye for detail and user experience.
- Strong communication skills to collaborate effectively within cross-functional teams.
- Bachelor’s degree in Computer Science, Mobile Development, or a related field (or equivalent work experience).

## Other Requirements
