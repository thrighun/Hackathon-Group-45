## Job Title
Cloud Data Engineer – AI-Driven Analytics

## Location
N/A

## Client Industry
Information Technology & Services (Data Analytics Solutions)

## Detailed Responsibilities
- Design, build, and maintain scalable data pipelines that integrate AI analytics and cloud services, ensuring high availability and performance.
- Collaborate with data scientists and business analysts to translate requirements into data architecture and optimize performance for AI initiatives.
- Implement and manage ETL processes that facilitate seamless data flow between on-premises systems and cloud platforms (AWS, Azure, or Google Cloud).
- Develop and optimize SQL and NoSQL databases to support large-scale data analytics and storage for AI-powered applications.
- Ensure data quality and integrity through monitoring, testing, and auditing data flows and processes.
- Create documentation outlining data architecture, data dictionaries, and ETL processes for team reference and knowledge sharing.
- Stay current with best practices in data engineering, cloud technologies, and AI integration, recommending innovative solutions to enhance data analytics capabilities.
- Participate in code reviews, project planning, and agile ceremonies to foster a collaborative team environment.
- Maintain compliance with data security and privacy regulations, implementing necessary safeguards for sensitive data.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Data Science, or a related field.
- Demonstrated experience in data engineering with expertise in ETL processes and data warehousing.
- Strong proficiency in Python or Java, along with experience in cloud services (AWS, Azure, or Google Cloud).
- Familiarity with AI/ML libraries and tools for data analysis (e.g., Pandas, NumPy, TensorFlow).
- Experience with both SQL and NoSQL databases (e.g., MySQL, PostgreSQL, MongoDB).
- Knowledge of data modeling techniques and best practices in data architecture.
- Proficient in version control systems (e.g., Git) and agile software development methodologies.

## Other Requirements
- Understanding of data governance and compliance standards (e.g., GDPR, HIPAA).
- Experience with data visualization tools (e.g., Tableau, Power BI) is a plus.
- Familiarity with container technologies (e.g., Docker) and orchestration (e.g., Kubernetes) for scalable deployments.
- Cloud certifications (e.g., AWS Certified Data Analytics, Google Cloud Professional Data Engineer) are a bonus.
- Strong analytical, problem-solving, and communication skills to collaborate effectively with cross-functional teams.
