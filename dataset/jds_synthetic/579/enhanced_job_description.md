- Collaborate with backend engineers to develop RESTful APIs for seamless data integration.
- Optimize applications for speed and performance on various devices and browsers.
- Conduct usability testing and gather feedback to refine and improve application features.
- Work alongside UX/UI designers to translate visual concepts into functional web applications.
- Keep abreast of the latest trends in frontend development and incorporate relevant techniques into projects.

- Bachelor’s degree in Computer Science, Software Engineering, or a related field.

- Proficiency in modern JavaScript frameworks (e.g., React, Vue.js) as well as HTML and CSS.
- Familiarity with version control systems such as Git and agile development practices.
- Understanding of web performance optimization techniques and tools.
- Strong attention to detail and ability to produce high-quality user interfaces.
- Excellent communication skills and a collaborative mindset.
