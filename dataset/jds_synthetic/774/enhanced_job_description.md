## Job Title
UI/UX Front End Engineer

## Location
Remote

## Client Industry
Technology

## Detailed Responsibilities
- Design and implement user interfaces that provide a seamless experience across devices.
- Work closely with product managers and stakeholders to gather requirements and define the user journey.
- Create interactive prototypes and conduct user testing to validate design concepts.
- Utilize modern JavaScript frameworks, such as Vue.js or Svelte, to build dynamic web applications.
- Collaborate with graphic designers to create visually appealing and functional website layouts.
- Analyze user feedback and behavior to refine and enhance front-end features.
- Ensure accessibility standards are adhered to, providing an inclusive experience for all users.

## Skill Requirements
- Strong proficiency in HTML, CSS, and JavaScript, with a solid grasp of web design principles.
- Experience with UI frameworks like Tailwind CSS or Material-UI.
- Familiarity with user testing methodologies and data analysis tools.
- Knowledge of version control systems such as Git.
- Excellent creativity combined with strong analytical skills.
- Bachelor’s degree in Design, Computer Science, or a related discipline.
- Minimum of 4 years of experience in UI/UX front-end development.

## Other Requirements
- Experience with animation libraries like GSAP or Framer Motion.
- Understanding of performance optimization techniques for web applications.
- Familiarity with Agile methodologies and project management tools like JIRA.
- Strong collaboration and communication skills to work effectively in cross-functional teams.
