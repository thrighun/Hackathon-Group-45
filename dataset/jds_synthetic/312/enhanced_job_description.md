## Detailed Responsibilities
- Design and implement embedded software solutions for various hardware platforms using C and C++.
- Collaborate with hardware teams to ensure seamless integration of software and hardware components.
- Optimize application performance with a focus on resource efficiency and low power consumption.
- Conduct system-level testing, validation, and debugging to ensure reliability and performance of embedded applications.
- Engage in the software development lifecycle, providing input during requirements analysis and design phases.
- Create and maintain comprehensive documentation for software systems, including design specifications and user manuals.
- Mentor and support junior engineers in best practices for embedded software development.

## Skill Requirements
- 5-10 years of experience in embedded software development using C and C++.
- Strong knowledge of embedded systems architecture and design principles.
- Proficiency in debugging and performance optimization for embedded applications.
- Familiarity with real-time operating systems (RTOS) and low-level hardware interfaces.
- Ability to work both independently and collaboratively in a fast-paced environment.
- Bachelor's degree in Computer Engineering, Electrical Engineering, or a related field.

## Other Requirements
- Experience with scripting languages such as Python for automation tasks is preferred.
- Understanding of communication protocols (e.g., I2C, SPI, UART) and hardware interfaces.
- Excellent communication skills and ability to convey complex technical concepts to diverse audiences.
