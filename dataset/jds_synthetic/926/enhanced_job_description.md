## Job Title
Full Stack .NET Developer – API and Frontend Specialist

## Location
N/A

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Develop and maintain scalable web applications using .NET Core for the backend and Angular for the frontend, providing a seamless user experience.
- Collaborate closely with UX/UI designers and backend developers to execute software features and enhancements.
- Design and implement RESTful APIs to support frontend functionality and ensure optimal integration with various services.
- Utilize CI/CD tools to automate builds, testing, and deployment processes to improve development efficiency.
- Conduct thorough code reviews and debugging to maintain high-quality standards and reduce technical debt.
- Stay updated on industry trends and emerging technologies, applying them to enhance application performance and user satisfaction.
- Participate in Agile ceremonies such as daily stand-ups, sprint planning, and retrospectives to foster team collaboration and communication.
- Provide guidance and mentorship to junior developers, fostering an environment of learning and professional growth.

## Skill Requirements
- Minimum 6 years of professional experience in full stack web development with a strong focus on .NET Core and Angular.
- Proven experience in designing and implementing RESTful APIs.
- Proficiency in front-end technologies including HTML, CSS, and JavaScript frameworks.
- Familiarity with CI/CD practices and tools (e.g., Azure DevOps, Jenkins).
- Strong background in working with cloud services, particularly Azure.
- Bachelor’s degree in Computer Science, Information Technology, or related field.
- Excellent analytical and problem-solving skills.
- Strong interpersonal and communication skills to facilitate team collaboration.

## Other Requirements
- Experience with microservices architecture is a plus.
- Knowledge of containerization tools such as Docker is advantageous.
- Familiarity with Agile and Scrum methodologies.
- Relevant certifications in .NET, cloud services, or full stack development are preferred.
