## Detailed Responsibilities
- Design and implement scalable web applications using React for front-end and Node.js for back-end development.
- Collaborate with designers and stakeholders to gather requirements and translate them into functional specifications.
- Ensure responsive design and seamless user experience across various devices and platforms.
- Write clean, maintainable, and efficient code while adhering to industry best practices.
- Conduct performance tuning and optimization of applications to improve usability and efficiency.
- Participate in code reviews and provide constructive feedback to peers to enhance team output.
- Stay informed about emerging technologies and frameworks, and suggest improvements to existing applications.
- Create and maintain documentation for software features and architectural decisions.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- 4+ years of experience in full stack development, with strong proficiency in React and Node.js.
- Solid understanding of JavaScript (ES6+), HTML5, CSS3, and related frameworks.
- Experience with database management systems such as MongoDB or PostgreSQL.
- Familiarity with RESTful services and API integration.
- Knowledge of version control systems, particularly Git.
- Understanding of unit testing and debugging methodologies.
- Strong analytical skills and a proactive approach to problem-solving.
- Excellent teamwork and communication skills, with the ability to work in an Agile environment.

## Other Requirements
