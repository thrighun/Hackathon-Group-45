## Job Title
Data Engineer – Azure & Machine Learning

## Location
Remote

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Design, build, and optimize scalable data pipelines and ETL processes on Microsoft Azure to support data warehousing and analytics.
- Collaborate with data scientists and analysts to understand data requirements and deliver high-quality data solutions that empower machine learning projects.
- Develop and maintain data integration solutions using Azure Data Factory, Azure Databricks, and other Azure data services to streamline data workflows.
- Ensure data quality and integrity through rigorous testing and monitoring processes, and implement best practices in data governance.
- Tune and optimize SQL and NoSQL databases for performance and scalability in support of analytics and business intelligence initiatives.
- Create documentation and visualizations to communicate data workflows, architecture, and outputs to stakeholders.
- Stay current with industry trends in data engineering, big data technologies, and AI to enhance existing data infrastructures and propose innovative solutions.

## Skill Requirements
- Proven experience in data engineering or related roles, with a strong portfolio of data-related projects.
- Hands-on experience with Microsoft Azure data services (e.g., Azure Data Lake, Azure SQL Database, Azure Synapse Analytics).
- Proficiency in programming languages such as Python or Scala for data manipulation and transformation.
- Strong understanding of data modeling concepts, ETL processes, and data warehousing principles.
- Familiarity with machine learning frameworks and algorithms is a plus.
- Bachelor’s degree in Computer Science, Data Science, or a related field.
- Excellent problem-solving, analytical, and communication skills.

## Other Requirements
- Azure or relevant cloud certifications (e.g., Microsoft Certified: Azure Data Engineer Associate).
- Experience with containerization and orchestration (e.g., Docker, Kubernetes).
- Knowledge of version control systems (e.g., Git) and CI/CD practices for data projects.
- Experience with data visualization tools (e.g., Power BI, Tableau) and reporting frameworks.
