## Job Title
JavaScript Frontend Developer

## Location
N/A

## Client Industry
Information Technology / Innovative Software Solutions Provider

## Detailed Responsibilities
- Develop and maintain dynamic and responsive web applications using JavaScript, primarily with React and Node.js frameworks.
- Collaborate with UI/UX designers to create intuitive interfaces and enhance user experience across web platforms.
- Integrate and manage data through MongoDB, ensuring high availability and performance for user-driven applications.
- Deploy and maintain frontend solutions on Amazon Web Services (AWS), utilizing serverless architecture and cloud services for scalability.
- Contribute to the implementation of AI features and automation tools to optimize workflows and enhance user engagement.
- Write efficient, reusable, and testable code while adhering to best practices and coding standards.
- Engage in code reviews, debugging, and performance enhancement practices to deliver high-quality software.
- Keep abreast of the latest trends and technologies in frontend development and recommend innovative solutions.
- Work closely with backend teams to ensure seamless integration of APIs and databases.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Software Engineering, or a related field.
- Demonstrated 3+ years of experience in frontend development using JavaScript with React and Node.js.
- Strong expertise with NoSQL databases, particularly MongoDB.
- Familiarity with deploying and managing applications on AWS, including services like Lambda and DynamoDB.
- Experience with integrating AI functions and automation tools into web applications.
- Solid understanding of web performance optimization, responsive design, and cross-browser compatibility.
- Excellent problem-solving capabilities, detail orientation, and the ability to thrive in a collaborative team setting.

## Other Requirements
- Experience with version control systems, particularly Git.
- Knowledge of testing frameworks (Jest, Mocha) and CI/CD practices.
- Familiarity with additional cloud services or related technologies (Azure, GCP) is a plus.
- Strong communication skills and a proactive attitude toward continuous improvement and learning.
