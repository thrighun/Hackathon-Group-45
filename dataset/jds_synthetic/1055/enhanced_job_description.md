## Detailed Responsibilities
- Design and implement scalable data pipelines that enable efficient access to clean, actionable data for machine learning applications.
- Collaborate with cross-functional teams, including data scientists, business analysts, and IT, to integrate machine learning models into production systems.
- Optimize model performance and scalability through continuous monitoring and fine-tuning of machine learning algorithms in a cloud setting.
- Implement MLOps best practices, including version control, continuous integration, and deployment strategies for ML models.
- Document processes and workflows, producing comprehensive technical documentation for internal and external stakeholders.
- Participate in client workshops and technical discussions to understand their needs and tailor solutions accordingly.
- Research and evaluate new machine learning frameworks and tools, providing recommendations for their adoption based on business impact.

## Skill Requirements
- Bachelor’s or Master’s degree in Data Science, Computer Science, Engineering, or a related field.
- 5+ years of experience in developing and deploying machine learning solutions, particularly in cloud environments.
- Proficiency in data processing frameworks (e.g., Apache Spark, Pandas) and machine learning libraries (e.g., TensorFlow, PyTorch, scikit-learn).
- Strong experience with cloud platforms (AWS, Azure, or GCP) and their machine learning services (e.g., SageMaker, Azure ML, AI Platform).
- Familiarity with programming languages such as Python, R, or Scala for data manipulation and model development.
- Understanding of data architecture, databases (SQL and NoSQL), and data warehousing concepts.

## Other Requirements
- Relevant certifications in cloud technologies (e.g., AWS Certified Machine Learning Specialty, Azure Data Scientist Associate).
- Experience in deploying applications with containerization technologies like Docker and orchestration with Kubernetes.
- Demonstrated knowledge of data governance practices and ethical AI principles.
- Previous experience in a client-facing role with strong communication and presentation skills.
- Portfolio of projects or contributions to open-source machine learning initiatives.
