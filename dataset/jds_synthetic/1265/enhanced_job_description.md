- Develop and maintain robust web applications using Java on the server side and Angular on the client side.
- Collaborate with product managers and design teams to create intuitive and visually appealing user interfaces.
- Optimize application performance through thorough testing, debugging, and code optimization practices.
- Contribute to architecture discussions and implement best practices for scalable and maintainable application design.
- Provide technical support and troubleshooting for deployed applications, responding to user-reported issues.
- Engage in continuous learning and share knowledge with team members to foster a culture of growth.

- Proficient in RESTful web services and API integration.
- Familiarity with front-end build tools and version control systems (e.g., Git).
- Experience with database technologies such as MongoDB, PostgreSQL, or MySQL.
- Strong problem-solving skills with a focus on user experience.
- Excellent team collaboration and communication skills.
