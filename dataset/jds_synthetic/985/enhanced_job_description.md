## Job Title
Senior Software Engineer - Python Django Developer

## Location
Remote

## Client Industry
Multinational Technology Provider

## Detailed Responsibilities
- Develop and maintain robust web applications using Python and Django framework.
- Collaborate with product managers and UI/UX designers to deliver seamless user experiences.
- Design and implement RESTful APIs to support various client applications.
- Optimize application performance and conduct system testing for quality assurance.
- Mentor junior developers and foster a collaborative team environment.
- Participate in architectural discussions to contribute to system design and best practices.
- Troubleshoot application issues and lead the resolution efforts efficiently.
- Stay abreast of emerging technologies and industry trends to drive continuous improvement.

## Skill Requirements
- Minimum of 6 years of experience in software development with proficiency in Python and Django.
- Strong experience in API development and microservices-based architecture.
- Familiarity with agile development methodologies and project management tools.
- Experience with cloud service providers (AWS, Azure, or Google Cloud) for application deployment.
- Knowledge of database systems like PostgreSQL or MySQL and ORM frameworks.
- Excellent analytical and problem-solving abilities.
- Bachelor’s degree in Computer Science, Software Engineering, or a related domain.
- Relevant certifications in Python or cloud services are advantageous.

## Other Requirements
- Experience with container orchestration tools like Docker and Kubernetes.
- Understanding of DevOps and CI/CD practices to enhance deployment processes.
- Strong communication skills and the ability to work effectively within a team.
