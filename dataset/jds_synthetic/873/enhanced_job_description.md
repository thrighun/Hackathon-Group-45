## Job Title
Frontend Engineer (with Vue.js and Bootstrap)

## Location
N/A

## Client Industry
Information Technology / Web Development Solutions

## Detailed Responsibilities
- Design, implement, and optimize user interfaces for web applications using Vue.js and Bootstrap, ensuring an intuitive and visually appealing experience.
- Participate in migration efforts, especially transitioning legacy frontend frameworks to Vue.js, addressing potential challenges during the process.
- Collaborate with product managers, backend developers, and designers to create cohesive and user-centric products.
- Write efficient, maintainable code following industry best practices and architectural guidelines.
- Enhance application performance through effective techniques like lazy loading, dynamic imports, and real-time data handling.
- Engage in code reviews to ensure quality and facilitate knowledge sharing among team members.
- Debug and resolve issues that arise across various platforms and devices, ensuring cross-browser compatibility.
- Maintain comprehensive documentation for development processes, including architectural decisions and design patterns.
- Keep abreast of the latest trends in frontend development and integrate new technologies and methodologies to improve productivity.
- Utilize Git for version control, maintaining organized and manageable code repositories.
- Integrate frontend components with backend APIs, ensuring seamless communication and data integrity.
- Contribute to the Agile development process by participating in daily stand-ups, sprint planning, and retrospectives.
- Apply critical thinking and problem-solving skills to deliver innovative solutions to frontend challenges.
- Communicate technical information effectively to both technical and non-technical stakeholders, fostering collaboration across teams.
- Stay updated on evolving frontend tools and frameworks to continuously enhance the development lifecycle.

## Skill Requirements
- Bachelor’s degree in Software Engineering, Computer Science, or a related field (or equivalent experience).
- Proven experience developing applications using Vue.js and Bootstrap, with a strong emphasis on responsive design and user experience.
- Solid understanding of JavaScript (ES6+), HTML5, and CSS3, particularly with a focus on modern frameworks.
- Familiarity with RESTful API development and experience integrating third-party services into frontend applications.
- Demonstrated capability to adapt to Agile methodologies, participating in iterative development processes.
- Strong analytical and debugging skills to effectively troubleshoot and resolve technical issues.
- Excellent interpersonal and communication skills, with the ability to articulate technical concepts to a diverse audience.
- Experience with component migration strategies, particularly in transitioning from older frameworks to Vue.js.
- Knowledge of TypeScript and its application in enhancing JavaScript-based projects.
- Experience in using state management solutions such as Vuex for efficient data handling in large-scale applications.
- Familiarity with testing frameworks and CI/CD pipelines to support continuous integration and deployment practices.
- Previous experience in a multinational or large-scale project environment, with an understanding of enterprise-level application development.
