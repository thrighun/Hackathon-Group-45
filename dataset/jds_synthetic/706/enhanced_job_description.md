## Detailed Responsibilities
- Develop and maintain full-stack web applications utilizing Java and modern JavaScript frameworks.
- Collaborate with product teams to define features and functionality, translating requirements into technical specifications.
- Create responsive UI components and ensure optimal application performance and scalability.
- Implement and optimize MongoDB data models and queries to support application needs.
- Conduct unit testing and troubleshooting to ensure high-quality software delivery.
- Participate in architecture discussions and contribute to best practices and coding standards across the team.
- Document application designs, APIs, and deployment processes effectively for team knowledge sharing.
- Mentor junior developers and share knowledge on emerging technologies and development practices.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related discipline.
- Proficiency in Java and familiarity with Java frameworks such as Spring or Hibernate.
- Strong experience with front-end technologies including HTML5, CSS3, and JavaScript frameworks (e.g., React, Angular, or Vue.js).
- Solid understanding of NoSQL databases, particularly MongoDB, and ability to write efficient queries.
- Familiarity with RESTful APIs and microservices architecture.
- Strong debugging, analytical, and problem-solving skills.
- Excellent teamwork and communication skills to collaborate effectively with cross-functional teams.

## Other Requirements

- Knowledge of CI/CD processes and tools (e.g., Jenkins, Docker) is advantageous.
- Relevant certifications in Java, MongoDB, or full-stack development are preferred.
