## Job Title

## Location
N/A

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Design and implement interactive web applications using Vue.js, prioritizing user experience and performance.
- Collaborate with data scientists to integrate machine learning models and features that enhance application functionality and user engagement.
- Work closely with backend developers to ensure seamless integration between frontend components and backend services.
- Optimize applications for speed and efficiency, ensuring they perform well on various devices and browsers.
- Conduct code reviews and provide mentorship to junior team members to foster a high-quality development environment.
- Stay updated on the latest frontend technologies and machine learning trends, advocating for improvements and best practices within the team.
- Participate in agile project management practices, contributing to sprint planning and retrospectives for continual process improvement.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related field.
- Minimum 5 years of experience developing applications with Vue.js, with a strong focus on component design and state management.
- Experience in integrating machine learning frameworks and APIs into web applications.
- Proficient in modern JavaScript (ES6+), HTML5, CSS3, and responsive design techniques.
- Familiarity with RESTful APIs and real-time data handling.
- Experience with version control tools, especially Git.
- Strong analytical skills and attention to detail, with the ability to solve complex problems efficiently.

## Other Requirements
- Experience with cloud services (AWS, GCP, or Azure) and deploying scalable web applications.
- Knowledge of testing methodologies and frameworks, including Mocha or Jasmine.
- Understanding of web accessibility standards and best practices for internationalization.
- Excellent communication and collaborative skills, with experience in client-facing situations.
