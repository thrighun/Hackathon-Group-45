## Job Title
Full Stack .NET Engineer – Web Applications Specialist

## Location
N/A

## Client Industry
Information Technology & Services

## Detailed Responsibilities
- Collaborate with software architects and designers to create intuitive and efficient web applications using .NET Core and modern front-end frameworks (e.g., Angular, React).
- Develop RESTful APIs to facilitate communication between front-end and back-end systems.
- Implement responsive design principles to ensure optimal user experience across devices.
- Conduct regular code reviews and unit testing to maintain high code quality and performance.
- Participate actively in Agile ceremonies and contribute to sprint planning and retrospectives.
- Optimize application functionality for scalability and performance.
- Manage database configurations and data access using ORM tools.
- Document application architecture, user stories, and technical workflows.
- Provide mentorship and support to junior developers within the team, fostering a collaborative environment.
- Stay updated on industry trends and emerging technologies to continually enhance application performance and user satisfaction.

## Skill Requirements
- A minimum of 6 years of experience in software development as a .NET Engineer.
- Proficient in .NET Core and experience with front-end frameworks such as Angular or React.
- Strong understanding of RESTful API development and integration.
- Familiarity with ORM frameworks (e.g., Entity Framework, Dapper) for database management.
- Experience with version control systems, preferably Git.
- Knowledge of containerization and orchestration tools like Docker and Kubernetes.
- Bachelor's degree in Computer Science, Engineering, or a related discipline.
- Excellent analytical and problem-solving abilities.
- Strong team player with effective communication skills.

## Other Requirements
- Familiarity with cloud services (e.g., Azure or AWS) is a plus.
- Previous experience working within Agile/Scrum environments.
- Understanding of CI/CD pipelines and DevOps methodologies.
- Relevant certifications in .NET development or web technologies are advantageous.
