## Job Title
Junior Frontend Developer with React and Bootstrap

## Location
Remote / Hybrid

## Client Industry
Information Technology Services

## Detailed Responsibilities
- Collaborate with UX/UI designers and backend developers to create and maintain responsive web applications using React and Bootstrap.
- Implement interactive features and optimize the performance of web applications.
- Contribute to the development and maintenance of application documentation and technical specifications.
- Participate in code reviews and contribute to team knowledge sharing.
- Troubleshoot and debug web applications to ensure a seamless user experience.
- Stay current with emerging web technologies and industry trends.

## Skill Requirements
- 1-2 years of experience in frontend development using React.
- Proficiency in Bootstrap for responsive design.
- Solid understanding of HTML5, CSS3, and JavaScript.
- Familiarity with RESTful APIs and JSON data formats.
- Experience with version control systems, preferably Git.
- Strong analytical skills and attention to detail.
- Bachelor’s degree in Computer Science, Web Development, or a related field.

## Other Requirements
- Understanding of Agile/Scrum methodologies.
- Basic knowledge of TypeScript is a plus.
- Excellent communication skills and the ability to work collaboratively in a team environment.
