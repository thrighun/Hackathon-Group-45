## Job Title
Vue.js Developer with Nuxt.js

## Location
Remote

## Client Industry
Multinational Technology Provider

## Detailed Responsibilities
- Design and implement user-friendly web applications using Vue.js and Nuxt.js.
- Work closely with UI/UX designers to transform designs into high-quality code.
- Collaborate with backend developers to integrate APIs and other services.
- Ensure application responsiveness and efficiency across different devices and browsers.
- Participate in code quality reviews and maintain coding standards across the team.
- Identify and address performance bottlenecks in the application.
- Research and apply the latest web technologies and best practices to improve development processes.

## Skill Requirements
- 3-6 years of experience with Vue.js and Nuxt.js.
- Solid proficiency in JavaScript (ES6+), HTML5, CSS3, and responsive web design principles.
- Experience with state management libraries such as Vuex.
- Familiar with build tools and package managers like Webpack and npm.
- Strong knowledge of RESTful services and API integration.
- Experience working in Agile/Scrum environments.
- Excellent analytical skills and a detail-oriented mindset.

## Other Requirements
- Exposure to TypeScript and the benefits of type safety in JavaScript applications.
- Understanding of server-side rendering (SSR) principles and performance optimization strategies.
- Familiarity with testing frameworks like Jest or Cypress for unit and integration testing.
- Knowledge of cloud-based deployment solutions such as AWS or Azure.
