## Detailed Responsibilities
- Design and implement web applications using Node.js for back-end functionality and Angular for front-end interfaces.
- Collaborate closely with product teams to gather requirements and ensure alignment with business goals.
- Utilize GraphQL to enhance data-fetching capabilities and streamline interactions between client and server.
- Conduct code reviews and enforce coding standards to maintain software quality.
- Troubleshoot and enhance existing applications to boost performance, scalability, and user satisfaction.
- Document application architectures, workflows, and processes to facilitate onboarding and knowledge sharing.
- Actively participate in Agile practices, including user story grooming, sprint reviews, and retrospectives.

## Skill Requirements
- Proficient in Node.js for backend development and server management.
- Strong understanding of Angular for creating rich client-side applications.
- Experience with GraphQL for efficient querying and data manipulation.
- Familiarity with MongoDB or other NoSQL databases.
- Knowledge of CI/CD practices for automating deployment and integration processes.
- Excellent analytical skills and the ability to thrive in a collaborative environment.

## Other Requirements
- Familiarity with containerization technologies such as Docker.
- Exposure to cloud services like AWS or Azure is a plus.
- Previous experience in an Agile software development environment is desirable.
