## Job Title
Senior Java Developer

## Location
Bangalore or Hyderabad

## Client Industry
Information Technology Services

## Detailed Responsibilities
- Develop and maintain robust backend services using Java and Spring Cloud for high-traffic applications.
- Collaborate with front-end developers and UX/UI designers to create seamless integrations and enhance user experience.
- Participate in architectural discussions and contribute to the design of scalable and maintainable system architectures.
- Write clear, maintainable code and conduct peer reviews to ensure adherence to best practices and standards.
- Optimize application performance by identifying and resolving bottlenecks and system inefficiencies.
- Engage in regular sprint activities, including planning, reviewing, and retrospectives, in a fast-paced Agile environment.
- Demonstrate a commitment to continuous learning by exploring new technologies and suggesting improvements.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or an equivalent field.
- 4-6 years of experience in Java development with a solid understanding of RESTful APIs and Spring Cloud.
- Experience working in Agile teams and a willingness to adopt new methodologies.
- Strong analytical skills with the capability to troubleshoot and resolve performance issues.
- Effective communication skills to liaise with team members and stakeholders.

## Other Requirements
- Familiarity with CI/CD pipelines and tools such as Jenkins or GitLab CI.
- Experience with relational databases such as MySQL or PostgreSQL, and NoSQL databases like MongoDB.
- Understanding of security best practices in software development.
- Knowledge of front-end technologies like Angular or React is a plus.
