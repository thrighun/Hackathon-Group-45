## Job Title
Java AI Solutions Engineer – Machine Learning Integration & Cloud Automation

## Location
N/A

## Client Industry
Technology

## Detailed Responsibilities
- Develop and maintain scalable and efficient machine learning applications using Java, focusing on integration with AI frameworks and cloud platforms.
- Design and implement microservices that facilitate real-time data processing and automate workflows within AI-driven solutions.
- Collaborate closely with data scientists and machine learning engineers to refine model deployment processes and improve operational efficiency.
- Ensure high availability and performance of applications through effective system architecture and cloud resource management.
- Write high-quality, maintainable code while following industry standards and best practices in software development and DevOps principles.
- Participate in debugging and optimizing machine learning models and algorithms, addressing performance bottlenecks and operational issues.
- Engage in regular code reviews and team knowledge sharing to promote continuous improvement and innovation.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Software Engineering, or a related field.
- Proven experience in Java development with a strong background in machine learning or AI technologies.
- Proficiency in developing and implementing RESTful APIs, Microservices, and Cloud-based architectures.
- Familiarity with machine learning frameworks (like TensorFlow, PyTorch) and deployment options.
- Knowledge of database technologies (SQL and NoSQL) and data pipeline tools.
- Experience with cloud services (AWS, Azure, Google Cloud) and container orchestration (Kubernetes).
- Strong proficiency in version control systems, particularly Git.
- Excellent communication, analytical, and problem-solving abilities.

## Other Requirements
- Experience with CI/CD processes and DevOps methodologies.
- Knowledge of additional programming languages (e.g., Python, Scala) is an advantage.
- Familiarity with agile development frameworks and practices.
- Prior contributions to open-source machine learning or Java projects.
- Understanding of data security and compliance issues in working with cloud-based applications.
