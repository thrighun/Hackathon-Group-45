## Detailed Responsibilities
- Design and implement scalable web applications using Java and Spring Boot, including the development lifecycle from requirement gathering to deployment.
- Collaborate closely with product owners and other stakeholders to synthesize requirements into actionable technical specifications.
- Build and maintain microservices architecture along with RESTful APIs, emphasizing security best practices and performance tuning.
- Develop dynamic user interfaces using front-end technologies including ReactJS, HTML5, CSS3, and JavaScript.
- Manage application deployment and orchestration using containerization technologies like Docker and Kubernetes.
- Implement CI/CD pipelines and utilize automated testing frameworks to streamline development processes and enhance software reliability.
- Perform troubleshooting and issue resolution across diverse technologies and environments, fostering a culture of continuous improvement.

## Skill Requirements
- Proficient in Java, Spring Boot, and microservices architecture.
- Strong experience with front-end development using ReactJS, JavaScript, HTML5, and CSS3.
- Familiarity with containerization and orchestration tools, particularly Docker and Kubernetes.
- Understanding of AWS cloud services and experience in managing cloud-based applications.
- Knowledge of CI/CD practices and experience with automated testing tools.
- Proficient in relational databases such as MySQL and experience with NoSQL databases.
- Strong problem-solving skills with a proactive approach to troubleshooting issues.

## Other Requirements
- Relevant certifications (e.g., Oracle Certified Professional: Java SE).
- Experience with other cloud platforms (e.g., Azure, Google Cloud).
- Familiarity with additional technology stacks and frameworks.
