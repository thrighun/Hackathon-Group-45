## Job Title
Software Engineer – Mobile Applications & AI Integration

## Location
N/A

## Client Industry
Technology

## Detailed Responsibilities
- Develop and maintain innovative mobile applications for both iOS and Android platforms with a focus on user experience and performance.
- Collaborate with backend teams to ensure seamless integration of APIs and AI services within mobile applications.
- Implement machine learning functionalities to enhance user interactions and app intelligence.
- Participate in the design and architecture of scalable mobile applications while adhering to best practices in software development.
- Conduct user testing and gather feedback to improve application features and overall performance.
- Work closely with product managers, UI/UX designers, and data engineers to deliver cohesive and functional mobile solutions.
- Write unit and integration tests to ensure software reliability and maintainability.
- Keep abreast of the latest trends in mobile technology, AI integration, and user experience design.

## Skill Requirements
- Bachelor's or Master's degree in Computer Science, Software Engineering, or a related field.
- Proficient in mobile application development for iOS and Android using frameworks such as Flutter, React Native, or native languages.
- Experience with backend integration and RESTful APIs to support mobile functionalities.
- Familiarity with AI technologies and their application in enhancing mobile user experiences.
- Strong understanding of mobile application testing methodologies and tools to ensure high-quality outputs.
- Excellent analytical and problem-solving skills, as well as effective communication abilities.

## Other Requirements
- Experience with cloud services like AWS, Azure, or Google Cloud for deploying mobile solutions.
- Familiarity with version control systems, particularly Git, and agile development methodologies.
- Background in working with cross-functional teams in a fast-paced environment.
- Contributions to mobile app development projects or open-source initiatives.
- Knowledge of additional programming languages like Java, Swift, or Kotlin is a plus.
