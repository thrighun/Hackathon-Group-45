## Job Title
Spring Framework Developer

## Location
N/A

## Client Industry
Technology

## Detailed Responsibilities
- Build, maintain, and scale enterprise-level applications using the Spring Framework.
- Collaborate with stakeholders to gather requirements and ensure software solutions align with business goals.
- Write clean, efficient, and maintainable code while implementing coding standards.
- Perform rigorous testing and debugging to ensure application reliability and performance.
- Participate in architectural reviews and contribute to design discussions for scalable solutions.
- Stay informed about emerging technologies and integrate them into existing applications where applicable.
- Engage in Agile practices, participating in sprint planning, reviews, and daily stand-ups to ensure project deliverables are met.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related discipline.
- 3-6 years of experience in developing applications using the Spring Framework.
- Strong proficiency in Java and familiarity with other programming languages.
- Solid understanding of microservices architecture and REST API development.
- Experience with modern front-end frameworks such as Angular or React is a plus.
- Knowledge of unit testing frameworks such as JUnit and Mockito.
- Familiarity with SQL and database design, as well as experience with NoSQL databases.
- Excellent analytical and problem-solving skills, with a detail-oriented mindset.
- Strong communication skills and the ability to work collaboratively in a team environment.

## Other Requirements
- Familiarity with CI/CD processes and tools, such as Jenkins or GitLab CI.
- Experience with cloud-based services (AWS, Azure, or Google Cloud).
- Knowledge of containerization technologies like Docker and orchestration tools like Kubernetes.
- Relevant certifications in Spring or cloud technologies are advantageous.
