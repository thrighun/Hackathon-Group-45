## Job Title
Senior Front-End Engineer

## Location
Remote

## Client Industry
Multinational Technology Provider

## Detailed Responsibilities
- Develop and enhance user interfaces for scalable web applications leveraging the Angular framework.
- Collaborate with backend developers to integrate RESTful services, ensuring seamless data flow.
- Conduct code reviews and mentor junior developers, instilling best practices and coding standards.
- Architect components for reusability and optimize performance for both mobile and desktop browsers.
- Participate actively in sprint planning and agile ceremonies to drive project scope and output.
- Remain informed about industry trends and evolving best practices to continuously improve code quality and application performance.

## Skill Requirements
- Minimum of 6 years of experience in front-end development with a focus on Angular.
- Strong proficiency in TypeScript, HTML5, and CSS3.
- Familiarity with state management libraries such as NgRx or Redux.
- Experience with front-end build tools and version control systems like Git.
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- Exceptional problem-solving capability and a keen eye for detail.

## Other Requirements
- Understanding of accessibility standards and mobile-first design principles.
- Experience with responsive and adaptive design techniques.
- Knowledge of continuous integration and deployment (CI/CD) practices.
- Familiarity with cloud services such as AWS or Azure for front-end deployment.
