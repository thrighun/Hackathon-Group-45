## Detailed Responsibilities
- Design, implement, and execute automated test scripts for both web and mobile applications to verify functionality and performance.
- Collaborate with software developers and product managers to understand application features and ensure comprehensive testing coverage.
- Analyze test results, report defects using tools such as JIRA, and track progress in resolving issues.
- Maintain and improve existing automated testing frameworks and build new testing capabilities as needed.
- Conduct continuous integration and deployment testing to ensure software quality throughout the development lifecycle.
- Mentor junior QA team members in test automation best practices and methodologies.
- Stay current with industry trends and advancements in automation tools and practices.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- Proven experience (3+ years) in test automation with frameworks such as Selenium, Appium, or similar tools.
- Strong programming skills in languages such as Java, Python, or C# for test script development.
- Familiarity with version control systems like Git and CI/CD tools like Jenkins.
- Excellent analytical and problem-solving skills, with a detail-oriented mindset.

## Other Requirements
- Relevant certifications in software testing or automation (e.g., ISTQB, Agile Testing).
- Experience working in an Agile development environment.
- Knowledge of performance testing tools such as JMeter or LoadRunner is a plus.
