## Detailed Responsibilities
- Perform comprehensive manual testing for mobile applications targeting both iOS and Android platforms, ensuring seamless functionality and user experience.
- Execute API testing to validate endpoints and ensure data integrity and performance across different services.
- Collaborate with cross-functional teams, including developers and product managers, to refine feature specifications and enhance overall product quality.
- Ensure thorough documentation of test plans and test cases while maintaining a clear defect tracking system.
- Analyze application performance and security through stress testing and evaluate user interface designs against usability standards.
- Drive quality assurance initiatives by suggesting improvements for testing processes and tools to enhance efficiency.

## Skill Requirements
- Bachelor’s degree in Computer Science, Information Technology, or a related field.
- Minimum of 3 years of experience in manual testing, with a strong focus on mobile application and API testing.
- Familiarity with mobile testing tools such as Appium, TestFlight, or similar.
- Experience in manual testing of RESTful APIs and knowledge of tools like Postman or SoapUI.
- Strong problem-solving skills and a detail-oriented mindset, with the ability to work independently or as part of a team.
- Excellent verbal and written communication skills, particularly in articulating testing processes and results.

## Other Requirements
- Experience in Agile/Scrum methodologies, with an understanding of agile QA practices.
- Knowledge of performance and load testing tools is a plus.
- ISTQB certification or equivalent QA credentials preferred.
- Familiarity with CI/CD processes and tools used in deployment pipelines is advantageous.
