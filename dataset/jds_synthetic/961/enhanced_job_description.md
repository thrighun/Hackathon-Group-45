## Job Title
Embedded Software Engineer - IoT Solutions

## Location
Hyderabad

## Client Industry
Technology

## Detailed Responsibilities
- Develop and implement software solutions for Internet of Things (IoT) devices using C and C++ programming languages.
- Design firmware and software architecture tailored for low-power and resource-constrained environments.
- Collaborate closely with product teams to identify user requirements and translate them into functional software designs.
- Integrate communication protocols (e.g., MQTT, CoAP) to ensure seamless connectivity between IoT devices and cloud platforms.
- Conduct thorough testing and validation of software applications to guarantee reliability and performance in real-world scenarios.
- Create and maintain technical documentation for software design, APIs, and system-level architecture.
- Engage in code refactoring and optimization to enhance existing software products and improve maintainability.

## Skill Requirements
- Bachelor’s degree in Computer Engineering, Computer Science, or a related field.
- 4-6 years of experience in embedded software development, particularly in IoT applications using C and C++.
- Strong background in low-level programming and hardware-software integration.
- Familiarity with various IoT communication protocols and standards.
- Experience in using software development tools for embedded systems, such as JTAG debuggers and oscilloscopes.
- Strong analytical skills with the ability to troubleshoot complex issues.
- Proven ability to work as part of a multi-disciplinary team and communicate effectively with both technical and non-technical stakeholders.

## Other Requirements
- Experience with additional languages such as JavaScript or Go is a plus.
- Knowledge of cloud platforms (e.g., AWS, Azure) and edge computing concepts.
- Familiarity with DevOps practices and tools, including CI/CD pipelines.
- Relevant certifications in IoT or embedded systems development are preferred.
