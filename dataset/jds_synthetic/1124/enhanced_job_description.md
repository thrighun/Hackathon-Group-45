## Job Title
Frontend Engineer (Vue.js & Bootstrap)

## Location
Remote 

## Client Industry
E-commerce 

## Detailed Responsibilities
- Design and develop engaging and responsive web applications utilizing Vue.js and Bootstrap for a seamless user experience.
- Collaborate with designers and product teams to translate wireframes and mockups into interactive features.
- Ensure applications are optimized for performance, security, and cross-browser compatibility.
- Integrate with back-end services and RESTful APIs to unlock advanced functionalities.
- Conduct thorough code reviews, debugging, and unit testing to maintain high coding standards.
- Engage in agile ceremonies, working closely with product owners to refine requirements into actionable tasks.
- Stay informed about the latest front-end technologies and industry trends to apply best practices in development.

## Skill Requirements
- Bachelor’s degree in Software Engineering, Web Development, or a related discipline.
- Solid experience as a Frontend Engineer, with a portfolio showcasing Vue.js projects.
- Proficient in HTML5, CSS3, and JavaScript (ES6+); experience with Bootstrap is essential.
- Familiarity with state management tools (e.g., Vuex) and modern JavaScript frameworks.
- Experience with version control platforms like GitHub or GitLab.
- Strong analytical skills with an aptitude for problem-solving and attention to detail.
- Competent verbal and written communication skills, with the ability to work collaboratively in a team.

## Other Requirements
- Previous experience in the e-commerce sector or with similar consumer-focused applications.
- Hands-on experience with Agile development methodologies.
- Knowledge of web performance optimization techniques and tools.
- Understanding of SEO best practices as they relate to web development.
- Familiarity with accessibility (a11y) standards and responsive design principles.
