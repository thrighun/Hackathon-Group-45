## Detailed Responsibilities
- Design and implement automated tests for web and mobile applications to enhance software quality.
- Collaborate with development teams to integrate automation into the software development lifecycle.
- Evaluate product requirements and create comprehensive test plans based on specifications.
- Execute automated test scripts and analyze results to identify defects and performance issues.
- Develop and maintain the automation testing framework to streamline testing processes.
- Prepare detailed reports documenting testing results, defects, and recommendations for improvements.
- Participate actively in agile ceremonies and deliver insights for continuous process improvements.
- Stay updated on advancements in testing technologies and methodologies.

## Skill Requirements
- Bachelor’s degree in Computer Science, Information Technology, or a related discipline.
- Ideally, 4+ years of experience in automation testing within a software development context.
- Proficiency in using automation testing tools like Selenium, TestNG, or Appium.
- Strong coding abilities in programming languages such as Java, C#, or Python.
- Good analytical skills and a keen eye for detail.

## Other Requirements
- Familiarity with CI/CD practices and tools such as Git, Jenkins, or Travis CI.
- Experience with cloud services such as AWS or Azure for building test environments.
- Knowledge of performance testing tools like JMeter or Gatling is a plus.
