## Detailed Responsibilities
- Develop and enhance high-performance backend services within a microservices architecture using the Spring Framework.
- Collaborate with front-end developers and stakeholders to ensure seamless integration and optimal performance of applications.
- Optimize server-side logic and implement security protocols to safeguard applications and data.
- Conduct system design assessments to improve application scalability and performance.
- Mentor junior engineers and participate in code reviews to promote coding standards and best practices.
- Maintain version control systems and thorough documentation to ensure technical specifications are current.
- Engage in continuous learning and apply new technologies to enhance development processes and application capabilities.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or a related discipline.
- 3-6 years of experience in Java backend development, particularly with the Spring Framework.
- Strong knowledge of microservices architecture and RESTful APIs.
- Proficiency in database management systems, both SQL and NoSQL (e.g., PostgreSQL, MongoDB).
- Familiar with Agile methodologies and DevOps practices.
- Excellent debugging and problem-solving abilities with a collaborative team spirit.

## Other Requirements
- Experience with cloud services like AWS or Azure is highly desirable.
- Familiarity with container orchestration tools such as Docker and Kubernetes is an advantage.
- Knowledge of CI/CD practices and tools (e.g., Git, Jenkins) is preferred.
