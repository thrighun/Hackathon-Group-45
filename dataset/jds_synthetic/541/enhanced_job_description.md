## Job Title
Senior Data Engineer – Cloud Architecture & Machine Learning

## Location
Remote / Hybrid

## Client Industry
Information Technology / Data Solutions Provider

## Detailed Responsibilities
- Design and implement scalable data pipelines and ETL processes to support the ingestion and transformation of large datasets across various sources.
- Collaborate with data scientists and analysts to build robust machine learning models, ensuring data accuracy and integrity throughout the model lifecycle.
- Architect cloud-based data solutions using platforms such as AWS, Azure, or Google Cloud to enable efficient data storage and retrieval.
- Optimize data processing workflows and storage solutions for performance, cost-effectiveness, and scalability, employing best practices in data engineering.
- Monitor and troubleshoot data pipeline performance, resolving issues proactively to ensure high availability and reliability of data services.
- Conduct code reviews and implement best practices in data engineering and software development, promoting a culture of quality and innovation.
- Stay updated with the latest advancements in data engineering tools, frameworks, and machine learning techniques to leverage new opportunities for optimization.
- Mentor junior data engineers and foster an environment of knowledge sharing and professional growth within the team.

## Skill Requirements
- Bachelor’s or Master’s degree in Computer Science, Data Science, Engineering, or a related field.
- Significant experience (5+ years) in data engineering, with a strong portfolio demonstrating expertise in data pipeline development.
- Proficient in programming languages such as Python or Scala, with a solid understanding of data manipulation libraries and frameworks.
- Experience with cloud architecture, including data storage solutions (e.g., S3, BigQuery) and infrastructure as code (IaC) tools.
- Familiarity with machine learning concepts and frameworks (TensorFlow, PyTorch) to support model integration and deployment.
- Strong knowledge of database systems (SQL and NoSQL) and data warehousing principles.
- Excellent analytical, problem-solving, and communication skills, with the ability to work collaboratively in a dynamic team environment.

## Other Requirements
- Certifications in data engineering, cloud platforms (AWS, Azure), or machine learning are a plus.
- Knowledge of containerization (Docker) and orchestration tools (Kubernetes) for managing data applications.
- Experience with data visualization tools (Tableau, Power BI) to support business intelligence initiatives.
- Passion for continuous learning and a strong drive for innovation in data solutions.
