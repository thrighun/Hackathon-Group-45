## Job Title
Full Stack Java Developer

## Location
Remote/On-site options available

## Client Industry
Technology Solutions

## Detailed Responsibilities
- Develop dynamic web applications utilizing Java and the Spring framework for both front-end and back-end functionalities.
- Collaborate with UI/UX designers to implement user-friendly interfaces that enhance user experience.
- Engage with product managers to translate business requirements into technical specifications.
- Conduct code reviews to ensure best practices and high performance throughout the codebase.
- Optimize applications for speed and scalability, leveraging both client-side and server-side technologies.
- Provide ongoing maintenance and enhancement for existing applications, ensuring they meet evolving business needs.
- Stay informed about industry trends and emerging technologies to continuously improve application performance and reliability.

## Skill Requirements
- Bachelor’s degree in Computer Science, Software Engineering, or similar field.
- Minimum of 3 years of experience in full stack development using Java and Spring framework.
- Profound knowledge of front-end technologies including React, Angular, or Vue.js.
- Strong understanding of RESTful APIs and microservices architecture.
- Familiarity with database management systems, such as MySQL or MongoDB.
- Excellent analytical and problem-solving capabilities.
- Strong interpersonal and communication skills, with a focus on collaboration.

## Other Requirements
- Experience with containerization technologies like Docker or Kubernetes is a plus.
- Knowledge of CI/CD pipelines and automated testing frameworks.
- Ability to work in an Agile development environment.
