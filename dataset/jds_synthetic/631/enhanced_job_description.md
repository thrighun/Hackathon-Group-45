## Detailed Responsibilities
- Develop and maintain firmware for IoT devices ensuring optimal performance on RTOS platforms.
- Collaborate with cross-functional teams to analyze user requirements and define project specifications.
- Implement communication protocols and data processing algorithms tailored for IoT applications.
- Perform rigorous testing, validation, and debugging of software to ensure high reliability and security.
- Engage in continuous integration and deployment practices to streamline software releases.
- Document architecture, modules, and interfaces of embedded software systems for compliance and future maintenance.

## Skill Requirements
- Bachelor's degree in Computer Engineering, Software Engineering, or a related discipline.
- At least 4 years of experience in embedded software development using C/C++.
- Proficient in RTOS concepts and IoT communication protocols such as MQTT, CoAP, and HTTP.
- Experience with tools for code analysis, version control, and continuous integration (e.g., Git, Jenkins).
- Strong troubleshooting and debugging skills with an emphasis on embedded environments.

## Other Requirements
- Familiarity with cloud platforms and data analytics for IoT solutions.
- Understanding of security best practices for embedded systems.
- Willingness to stay current with trends in IoT and embedded systems technology.
