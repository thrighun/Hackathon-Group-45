- Create and manage data pipelines for high-volume data ingestion and processing from multiple sources, ensuring data quality and consistency.
- Leverage cloud technologies to deploy and scale data solutions, optimizing for efficiency and performance.

- Minimum of 8+ years of relevant experience in data engineering with a focus on AI and machine learning projects.
- Strong programming skills in Python, SQL, and Scala, along with experience in data processing tools such as Apache Spark.
- Proficient in utilizing various cloud platforms (AWS, GCP, Azure) for data storage and processing.
- Excellent analytical and troubleshooting skills, with a strong orientation towards results.
