- Develop and maintain web applications using JavaScript frameworks (React, Angular) and server-side technologies (Java, Ruby on Rails).
- Collaborate effectively with UX/UI designers to implement user-centric designs and optimize application performance.
- Write and maintain efficient, reusable code, and conduct code reviews to promote high-quality software.
- Monitor application performance and troubleshoot issues to enhance functionality and user experience.
- Participate actively in agile ceremonies and contribute to project planning and estimation.
- Stay abreast of the latest web development trends and incorporate best practices into projects.

- Strong experience in front-end technologies, primarily in React or Angular, and back-end programming using Java or Ruby on Rails.
- Proficiency in RESTful APIs and integrating with various data sources.
- Understanding of web performance optimization techniques and cross-browser compatibility.
- Bachelor's degree in Computer Science, Software Engineering, or a related discipline.
- Strong analytical and debugging skills.

## Other Requirements

- Experience with version control systems, preferably Git.
- Excellent communication skills and an ability to work collaboratively in a fast-paced environment.
- Previous experience in a startup or agile technology environment is a plus.
