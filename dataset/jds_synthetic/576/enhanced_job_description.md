## Detailed Responsibilities
- Oversee the design, development, and deployment of full-stack web applications using Java and Angular, ensuring seamless integration of front-end and back-end components.
- Lead a team of developers in creating microservices-based architectures, promoting coding best practices and high-quality standards throughout the development lifecycle.
- Collaborate with product managers, UX/UI designers, and QA teams to gather requirements, refine application features, and enhance user experience.
- Implement CI/CD pipelines and leverage cloud services to facilitate automated testing and deployment, ensuring faster time-to-market for application releases.
- Mentor and coach junior developers, providing guidance on technical challenges and fostering a collaborative environment for innovation and learning.
- Stay informed about emerging technologies and industry trends to propose enhancements and drive continuous improvement within the development team.
- Contribute to architectural discussions and decisions, ensuring alignment with best practices for scalability, security, and performance.

- Strong proficiency in Java and Angular, with a proven record of developing complex web applications in a full-stack environment.
- In-depth experience with microservices architecture, RESTful API design, and cloud platforms (such as AWS or Azure).
- Familiarity with DevOps practices and tools for CI/CD, automated testing, and version control (e.g., Jenkins, Git).
- Excellent problem-solving abilities and attention to detail, with a strong understanding of software development methodologies (Agile/Scrum).
- Exceptional communication skills, capable of articulating technical concepts to a non-technical audience and collaborating effectively with cross-functional teams.
- Bachelor’s or Master’s degree in Computer Science, Software Engineering, or related technical field.

## Other Requirements
