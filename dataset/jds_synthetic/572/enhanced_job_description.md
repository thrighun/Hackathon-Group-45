## Detailed Responsibilities
- Design, develop, and maintain dynamic web applications using React for the frontend and Node.js for the backend.
- Collaborate with UX/UI designers to create user-friendly interfaces and optimize application performance.
- Utilize MongoDB for database management and ensure data integrity through efficient schema design.
- Implement RESTful APIs and integrate third-party services to enhance application functionality.
- Participate in Agile ceremonies, including sprint planning and retrospectives, to ensure project alignment and progress.
- Conduct thorough testing and debugging of applications to ensure a high-quality user experience.

## Skill Requirements
- Bachelor's degree in Computer Science, Software Engineering, or a related field.
- 4 - 8 years of experience in full stack web development.
- Proficiency in React, Node.js, Express, and MongoDB.
- Strong understanding of both frontend and backend technologies and their integration.
- Excellent analytical and problem-solving abilities.
- Strong communication skills and ability to work collaboratively in a team-oriented environment.

## Other Requirements
- Familiarity with Docker and containerization concepts.
- Experience working with cloud services such as AWS or Google Cloud Platform.
- Understanding of CI/CD pipelines and version control tools like Git.
